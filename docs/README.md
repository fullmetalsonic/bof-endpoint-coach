# 문서 구조 안내

문서는 역할별로 나눈다. `governance`는 **무엇이 언제 왜 바뀌었는지**, 나머지 폴더는 **현재 기준과 상세 내용**을 관리한다. 같은 내용을 여러 문서에 복사하지 않고, 기준 문서로 링크한다.

| 폴더 | 관리 대상 | 대표 문서 |
| --- | --- | --- |
| `governance/` | 누적 원장, 문서·파일 관리 규칙 | `누적이력관리.md`, `문서관리_규칙.md` |
| `product/` | v0 범위, 보안, 운영 기본·결정·이력 기반 참고 기준·검증/승인 계획 | `v0_운영기본기준_2026-08-22.md`, `종점참고예상_검증및승인계획_초안.md` |
| `domain/` | 취련 흐름, 데이터, 단위, 기준값, 설비·조업 조건, 계수, 품질·이력·백업복원·시간경과·종점 참고 계산식 규칙 | `종점참고계산식_초안.md`, `설비_조업조건_프로필_초안.md` |
| `ui/` | 화면 기능 구조, 동시 차지 전환, 시각 규칙, 화면별 설계 | `동시진행_차지_전환규칙_초안.md` |
| `design/` | 디자인 기준선, 설계·상태·검토 템플릿 | `01_디자인기획안_v0.md` |
| `screenshots/` | 공개 README와 구현 검증에 쓰는 합성 DEMO 화면 | `dashboard-ko.png`, `dashboard-en.png`, `settings-ko.png` |
| 루트 문서 | 실제 조작 순서와 안전 경계를 담은 한영 사용 설명서 | `user-guide.md` |
| `releases/` | 공개 버전별 한영 릴리스 설명과 검증·제한사항 | `v0.2.0.md`, `v0.1.0.md` |
| `research/` | 국내·해외 기술 조사, 종점 계산 구조·계수 근거, 자료 카탈로그·추적표 | `취련_기술조사_2026-08-22.md`, `종점계수_문헌근거매트릭스_2026-08-22.md`, `catalog/` |
| `audits/` | 기능·데이터·안전성·구현 준비도·구상 완성도·계산 구현 검증 결과 | `v0_구상완성도_점검_2026-08-22.md`, `문헌시나리오_계산구현검증_2026-08-22.md` |
| `templates/` | CSV 예시 및 공통 기록 양식 | `차지기록_입력예시.csv` |

## 새 문서를 만들 위치

- 제품 범위·우선순위·보안: `product/`
- 데이터 항목·단위·강종군·게이트: `domain/`
- 화면 구성·문구·상태·반응형: `ui/`
- 디자인 원칙·시안 검토·화면 설계 양식: `design/`
- 구현 화면·기준안 비교와 고정된 화면 매핑: `design/02_v0.1_구현매핑_2026-08-22.md`
- 공개 버전의 변경점·검증·안전 제한: `releases/`
- 외부 자료의 요약·색인·적용 검토: `research/`
- 점검 결과·미해결 위험·검증 보고: `audits/`
- 변경 결정의 날짜별 기록: `governance/누적이력관리.md`

파일 생성·이동·중요한 내용 변경은 `governance/문서관리_규칙.md`를 따른다.
