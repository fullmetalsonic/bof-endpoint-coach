# 문서 구조 안내

문서는 역할별로 나눈다. `governance`는 **무엇이 언제 왜 바뀌었는지**, 나머지 폴더는 **현재 기준과 상세 내용**을 관리한다. 같은 내용을 여러 문서에 복사하지 않고, 기준 문서로 링크한다.

| 폴더 | 관리 대상 | 대표 문서 |
| --- | --- | --- |
| `governance/` | 누적 원장, 문서·파일 관리 규칙, 디버그 재발방지와 개발 검증 체크리스트 | `누적이력관리.md`, `문서관리_규칙.md`, `디버그_재발방지_대장.md`, `개발검증_체크리스트.md` |
| `product/` | v0 범위, 보안, 운영 기본·결정·이력 기반 참고 기준·검증/승인 계획·후속 우선순위 | `v0_운영기본기준_2026-08-22.md`, `P1_P2_후속기능_목록_2026-08-23.md`, `v0.7_최소입력_선택형_투입코치_기획안_2026-08-24.md` |

## 새 문서를 만들 위치

- 제품 범위·우선순위·보안: `product/`
- 데이터 항목·단위·강종군·게이트: `domain/`
- 화면 구성·문구·상태·반응형: `ui/`
- 디자인 원칙·시안 검토·화면 설계 양식: `design/`
- 구현 화면·기준안 비교와 고정된 화면 매핑: `design/02_v0.1_구현매핑_2026-08-22.md`
- 공개 버전의 변경점·검증·안전 제한: `releases/`
- 외부 자료의 요약·색인·적용 검토: `research/`
- 점검 결과·미해결 위험·검증 보고: `audits/`
- 세부 화면의 명칭·단위·입력 예시·주의사항: `manual/`
- 변경 결정의 날짜별 기록: `governance/누적이력관리.md`
- 반복 오류의 원인·증거·영구 차단책: `governance/디버그_재발방지_대장.md`
- 개발·배포 전 고정 검증 순서: `governance/개발검증_체크리스트.md`

파일 생성·이동·중요한 내용 변경은 `governance/문서관리_규칙.md`를 따른다.
