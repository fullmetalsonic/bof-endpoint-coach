# v0.2.2 확장 실사용 기능 검증

검증일: 2026-08-22  
대상: 취련 코치 v0.2.2 후보  
목적: 화면만 반응하는 시연이 아니라 작업자 DEMO에 필요한 입력·진행·저장·복구가 실제 데이터 상태까지 이어지는지 검증

## 1. 판정

**기능 DEMO 배포 후보: PASS**  
**실제 BOF 종점 정확도·현장 조업 사용: 검증 전**

이 판정은 수동 입력형 도구의 기능 완결성에 한정한다. 설비 제어, 안전 인터록, 표준작업, 분석실 결과, 출강 승인 또는 취련사의 판단을 대체한다는 뜻이 아니다.

## 3. 검증 방법

### A. 단위·도메인·표시 시험

- 16개 테스트 파일, 71개 테스트
- 50개 결정론적 가변 장입 시나리오에서 C·온도 계산의 유한값·범위 안전성 확인
- 산소 증가 시 정적 C 예상이 역방향으로 상승하지 않는지 확인
- 샘플 C 보정량과 종점 C 이동량 일치 확인
- 빈 목표, 단위 환산, 설정 범위, 단계·샘플 시간, 백업 위변조·의미 오류 확인

### B. 실제 브라우저 조작

각 브라우저에서 독립 저장소로 아래 9개 시나리오를 반복했다.

1. 빈 목표 강종 추가·저장·신규 차지 대시보드 유지
2. t·ppm 환산, G0→G8, 체크포인트 감소 차단, 샘플·분석·재취련·출강·후처리, 새로고침 보존
3. 두 진행 차지의 상태 분리와 G0 초안 삭제
4. 실제 ZIP 다운로드·초기화·같은 파일 복원·XLSX 다운로드
5. 작업자 변경·진행 차지 취소·보관·금일 현황·초기화 복구
6. 미래·시작 전·중복 차지 차단
7. 상단 메뉴 6개와 설정 탭 7개의 실제 화면 전환·설정 저장
8. 합성 DEMO 2개 차지 실제 개별 삭제·Data Ledger 장식용 새로고침 부재
9. 배포 단일 HTML을 `file://`로 직접 실행·입력·새로고침·IndexedDB 복원·외부 HTTP 요청 없음

## 4. 남은 제한과 DEMO 관찰 항목

- 실제 완료 차지가 없으므로 C·온도 오차, 격외 방지율, 재취련 감소 효과는 판정할 수 없다.
- 문헌 저·고 시나리오는 통계적 신뢰구간이 아니다.
- P·Mn·Si·S 종점 예상은 현장 승인식이 없어 비활성이다.
- 재료 조성은 보존하지만 합금 수율 계산에는 연결되지 않는다.
- 계수 프로필을 변경했을 때 과거 화면 계산을 불변 스냅샷으로 고정하는 기능은 아직 없다.
- PLC·HMI·SCC·MES·LIMS 연동은 없다.

따라서 작업자 DEMO에서는 조작 흐름, 입력 편의, 누락 경고, 실제 완료 차지와 참고 예상의 차이를 수집해야 한다. 현장 승인 전에는 출강 판단 근거로 사용하지 않는다.
