## 반복 검증에서 발견하고 고친 문제

1. 상단 `다음 행동`이 중앙 동적 안내보다 오래된 정적 문구를 표시했다. 같은 `getStageWorkflow` 결과를 사용하도록 통일했다.
2. Data Ledger의 일반 경고가 실제 현재 작업과 달랐다. 동적 현재 작업명을 표시하도록 통일했다.
3. 현재 입력과 다음 단계 전환이 모두 파란색이라 주 행동이 두 개처럼 보였다. 조기 전환을 흰색 보조 버튼으로 낮췄다.
4. 기초값 저장 직후 계산 시각이 최근 입력 시각보다 과거로 보였다. 저장 재렌더 시점의 현재 시각으로 계산하도록 수정했다.
5. 첫 1920×1080 비교에서 하단 설명이 고정 입력바와 겹치고 18px 세로 스크롤이 생겼다. 품질행·작업 안내판 열 폭·하단 여백을 조정해 한영 모두 `scrollHeight = innerHeight = 1080`으로 맞췄다.
6. 기존 종단 회귀시험의 `분석 결과 입력` 선택자가 새 중앙 버튼과 하단 버튼을 동시에 찾았다. 실제 의도한 중앙 실행 버튼으로 선택자를 구체화하고 재시험했다.
