# v0.3.0 정정·이력 관리와 화면 흐름 감사

감사일: 2026-08-23  
대상: 취련 코치 v0.3.0 후보  
목적: 오입력 복구 기능이 단순 버튼이 아니라 원본 보존, 현재값 재계산, 공정 단계 정합성, 백업·보고서까지 실제로 이어지는지 확인한다.

## 결론

P0 정정 기능은 `정정·이력 관리` 한 묶음으로 구현했다. 대시보드의 최근 분석, 전체 차지 타임라인, 한 단계 복귀, 출강 후 정정, 분석 채택, 예상 대 실제값, 차지별 기준 스냅샷이 같은 데이터 모델을 사용한다.

이 버전은 현장 정확도를 주장하는 버전이 아니다. 정정 전후 계산 재현성과 작업 흐름을 검증하는 버전이다.

## 화면 흐름 감사

### 1. 발견 가능성

- 대시보드 제목 오른쪽의 `마지막 단계 전환 취소`는 일반 현재 작업 버튼과 색·위치를 분리했다.
- 최근 분석 표 각 행에 `수정·무효`, 표 제목에 `전체 이력·정정`을 배치했다.
- G7·G8에서만 전체 이력 상단에 `출강 기록 정정`을 표시한다.
- `종점 실제값`은 출강 전에는 숨기고, 출강 이후에만 분석 행에서 사용할 수 있다.

### 2. 판단 순서

정정창은 `대상 → 영향받는 후속 기록 수 → 실제 시각·값 → 사유 → 적용` 순서를 유지한다. 작업자가 사유와 값 검증을 통과하기 전에는 적용 버튼이 활성화되지 않는다.

### 3. 복구 가능성

- 방금 값이 틀리면 현재 단계에서 값만 수정하거나 무효 처리한다.
- 단계 버튼을 잘못 눌렀으면 한 단계만 복귀한다.
- 몇 단계 전 값이 틀리면 공정 단계를 되감지 않고 과거 기록만 정정한다.
- 출강 이후에는 일반 복귀 대신 별도 출강 정정을 사용한다.

### 4. 정보 보존

화면은 현재 유효값만 보여 주는 데 그치지 않고, 원본 `정정됨`, 대체 `유효`, 제외 `무효`, 채택 분석, 종점 실제값을 함께 보여 준다. 최근 분석 표는 계산에 채택되지 않은 과거 분석도 숨기지 않는다.

## 검증 중 발견·수정한 문제

| 발견 | 원인 | 수정 |
| --- | --- | --- |
| `취소` 테스트가 단계 취소 버튼까지 잡음 | 접근성 이름 부분 일치 | 일반 취소 버튼을 정확 일치로 검증해 서로 다른 기능임을 고정 |
| 분석값만 고쳐도 분석 시각이 샘플보다 수백 ms 빠르게 변함 | `datetime-local`의 분/초 정밀도 변환 중 원본 ms 손실 | 시각 필드를 수정하지 않았으면 원본 ISO 시각을 그대로 보존하고 모든 실제 시각 입력은 초 단위 표시 |
| 비채택 과거 분석이 최근 표에서 Pending으로 보임 | 계산용 채택 투영값을 이력 표시에도 사용 | 이력 표는 각 샘플의 최신 유효 분석, 계산은 명시적 채택 분석을 사용하도록 분리 |
| 샘플 무효 후 연결 분석 이벤트가 남을 수 있음 | 샘플과 분석 이벤트의 상태 갱신 분리 | 샘플·분석 결과·분석 이벤트를 함께 무효 처리하고 참조 무결성 검사 추가 |
| 출강 시각 정정이 이미 입력된 G6·G7 기록을 가로지를 수 있음 | 출강 시작·종료 단계만 확인하고 전후 이벤트 시각은 비교하지 않음 | 마지막 G6 입력보다 빠르거나 첫 G7 후처리보다 늦은 출강 시각을 차단하고 경계 시험 추가 |
| 과거 기록 시각 정정이 당시 허용되지 않은 단계에 들어갈 수 있음 | 현재 단계의 버튼 허용 여부만 사용 | 정정 시각의 과거 단계를 다시 계산해 해당 단계에서 가능한 기록 종류인지 검사 |
| 출강 정정 브라우저 시험이 정상 차단에서 멈춤 | 시험값을 `datetime-local` 분 단위로 잘라 1초 정정이 최대 59초 정정으로 변함 | 시험도 화면과 같은 초 단위로 입력하고 Chromium·Chrome·Edge에서 출강 정정 흐름 재통과 |

## 자동 검증 범위

- 도메인: 수정·무효·채택·한 단계 복귀·출강 정정·예상/실제 비교·설정 스냅샷
- 방어: 빈 사유, 0~100% 초과 성분, 분석/샘플 역행, 출강 전후 기록 교차, 당시 단계에서 불가능한 기록, 누적 산소 앞뒤 순서, 음수, 참조 끊김
- 저장: 백업 0.3.0 왕복, 구버전 복원, SHA-256·행 수·스키마·수치 변조 차단
- 브라우저: 1920×1080, 한영 화면, G0→G8, 다중 차지, 백업·복원, 수정·무효·복귀, 출강 정정·실제값 지정, 단일 HTML

## 남은 위험과 후속

- 실제 현장의 조업 중단·재개 정책과 출강 후 분석 승인 절차는 취련사·품질 담당 확인이 필요하다.
- 표시명은 인증 계정이 아니므로 누가 수정할 수 있는지 통제하지 못한다.
- 설정 차이 보기, 기준 발행, 백업 재검증 상태, 저장 실패 비상 내보내기는 P1이다.
- PC 시계 이상 탐지, 교대 인계 요약, 유사 차지·원인 통계는 P2다.

후속 항목은 [P1·P2 목록](../product/P1_P2_후속기능_목록_2026-08-23.md)에 유지한다.
