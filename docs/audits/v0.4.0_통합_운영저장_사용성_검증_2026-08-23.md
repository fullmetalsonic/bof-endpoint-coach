## 결론

앞선 감사의 저장·복구 P0와 화면·사용성 P1을 하나의 변경으로 보강했다. 가장 위험했던 두 창의 `마지막 저장 우선` 덮어쓰기는 저장 revision을 IndexedDB 읽기-쓰기 트랜잭션 안에서 비교해 차단했다. 다른 창의 저장을 감지한 창은 읽기 전용이 되며, 비상 백업 후 최신 저장소를 다시 읽을 수 있다. 이 동작은 개발 서버뿐 아니라 실제 전달 형태인 `file://` 단일 HTML 두 창에서도 재현시험을 통과했다.

IndexedDB 초기 읽기 실패는 빈 작업공간으로 전환하지 않고 안전 정지 화면을 표시한다. 저장 실패·충돌 중에는 조업 입력을 잠그고 재시도·비상 백업·최신 상태 불러오기를 제공한다. 저장 진행·장애 상태에서 창을 닫으면 브라우저 이탈 경고를 요청한다.

신규 차지, 이벤트, 단계 전환, 정정, 설정 입력은 폼·차지·기준 버전별 로컬 초안으로 보존된다. 사용자는 복구된 초안을 계속 입력하거나 명시적으로 버릴 수 있다. 설정 저장은 실제 변경과 변경 사유가 있을 때만 가능하고 새 버전, 이전 버전, 작업자, 시각, 사유, 필드별 차이를 남긴다.

## 독립 검토에서 추가로 고친 사항

- 초기 수정 뒤 기존 시험이 `설정 변경 사유`, `초안 버리기`, 표준 정정 사유 선택창을 알지 못해 7건 실패했다. 각 실패를 재현해 기존 의미를 유지하도록 버튼 이름과 접근성 이름을 정리하고 시험 절차를 새 규칙에 맞췄다.
- 작업공간 초기화가 저장소를 먼저 지운 뒤 새 상태를 저장하던 경로를 발견했다. 초기화도 현재 revision과 비교해 새 상태를 원자적으로 저장하도록 바꿨다.
- HTTP 환경만으로는 실제 오프라인 전달 형태를 증명할 수 없어 단일 HTML 두 창 충돌시험을 추가했다.
- 새 백업이 파일을 만들었다는 사실만 확인하지 않도록, 다운로드 전에 같은 Blob을 복원 경로로 재읽어 검증하도록 바꿨다.
- 설정 저장 뒤 새 설정 버전으로 화면이 다시 열리며 화면 내부 성공 알림이 사라질 수 있는 경로를 발견했다. 알림을 앱 공통 상태로 옮겨 새 버전 화면에서도 저장 완료와 의미가 보이게 했다.
- 로고와 주 메뉴 버튼이 모두 `대시보드`로 읽히던 이름 중복을 `대시보드로 이동`과 `주요 메뉴`로 구분했다.
- 강종별 품질 목표 입력의 반복된 `최소`·`최대` 접근성 이름을 품질 항목과 결합해 `C 최소`, `온도 최대`처럼 고유하게 읽히도록 했다.

### 강점

- 대시보드의 `현재 해야 할 일`과 파란 주 행동 버튼이 수동 입력의 다음 위치를 명확히 가리킨다.
- 품질 막대와 Data Ledger가 수치 상태와 입력·계수 근거를 동시에 보여 준다.
- 설정 저장은 변경 사유와 버전 이력을 요구하고, 저장 성공을 새 화면에서도 확인할 수 있다.
- 확대 화면에서 전체 화면을 단순 축소하지 않고 헤더와 본문을 재배치한다.

### UX·접근성 위험과 기회

- 진행 차지가 더 많아지면 탭의 직접 고정과 위험 우선 정렬이 필요하다. 현재는 최신성·확인 수·위험 수까지만 제공한다.
- 이력과 보고서 화면은 1920px에서 하단 여백이 크지만, 핵심 조작이 상단에 모여 있어 현재 단계에서는 구조적 차단이 아니다.
- 화면에서 보이는 명암·크기·재배치와 키보드 Escape·초점 복귀는 확인했지만 실제 화면낭독기, Windows 고대비, 보호구 착용 조건은 별도 현장 시험이 필요하다.
- 최종 단일 HTML은 자동화된 `file://` 두 창 시험을 통과했다. 현재 감사용 내장 브라우저는 보안 정책상 `file://` 직접 열기를 허용하지 않아 이번 화면 캡처는 같은 소스의 로컬 개발 실행본으로 수행했다.

## 남은 검증 경계

- 실제 회사 PC의 파일 다운로드·IndexedDB/localStorage 허용 정책, quota, 보안 프로그램, 강제 종료·정전 복구는 현장에서 확인해야 한다.
- 브라우저 `beforeunload` 경고는 브라우저 정책에 따라 문구나 표시 여부가 달라질 수 있으므로 정식 백업을 대신하지 않는다.
- 화면낭독기, Windows 고대비, 보호구·조명·거리 조건의 실제 작업자 평가는 수행하지 않았다.
- 완료 차지 실데이터가 없으므로 종점 C·온도 정확도, 경고 적중률, 유사 차지 통계는 검증하지 않았다.
- 탭 직접 고정, 설정 발행·중지 승인 워크플로, 대량 이력 성능 기준은 후속 P1·P2에 남긴다.
