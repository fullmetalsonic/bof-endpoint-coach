# v0 구상 완성도 점검

점검일: 2026-08-22  
범위: 문서상 기능·데이터·설정·검증 구조. HTML 구현, 실제 공정 계수, 현장 사용성은 점검 대상이 아니다.

## 결론

**수치 종점 참고예상 중심 v0.1은 계산식·설정·화면 구현 설계를 시작할 만큼 구체화됐다.**

다만 현장 계수·가상 손계산·그림자 검증이 아직 없으므로, 실제 배포 전에는 수치 출력의 검증이 남아 있다. 이력 기반 보정은 v0.2로 둔다.

## 권장 구현 경계

### v0.1 — 지금 설계·구현 가능한 범위

- 차지 생성·동시 전환·G0~G8 이벤트/샘플/분석 기록
- 강종·재료·설비/조업 조건 프로필·영향인자·단위 설정
- 정적 수지 및 샘플 이후 보정식으로 종점 C·온도 수치 참고예상, 항목별 계산 근거·불확실성 범위 표시
- 유사 차지 이력·참고 범위, CSV 백업/복원, XLSX 보고서
- 미승인 계수·필수 입력이 없는 항목만 `예상 계산 불가`로 표시하며, 다른 계산 가능 항목은 정상 출력

### v0.2 — 검증 뒤 추가할 범위

- 이력 보정·그림자 예상·승인된 예측 규칙 버전

## 비판적 주의점

- 영향인자를 많이 기록한다고 예측 정확도가 자동으로 올라가지 않는다. 초기 화면에는 계산식·계수 선택·계산 가능 조건에 연결되는 인자만 둔다.
- 설비 사양, 설비 상태, 실제 조업값을 한 화면/한 표에 섞으면 비교와 재현이 깨진다. 프로필·상태·이벤트를 분리한다.
- 공개 논문 수치나 다른 제철소의 계수를 기본값으로 넣으면 안 된다.
- 데이터가 충분해도 목표 기준 자동 변경, 자동 재학습, 설비 제어·작업 지시는 v0 범위가 아니다.
