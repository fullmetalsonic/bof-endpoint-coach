# 취련 코치 v0 기능 감사

감사일: 2026-08-22  
감사 범위: 현재의 요구사항·데이터 정의·관리 게이트·설정 화면·보안·연구 카탈로그 문서. HTML 구현물은 아직 없으므로 실행/보안/계산 정확도 테스트는 대상이 아니다.

## 결론

**현 상태는 설계 초안으로는 진행 가능하지만, HTML 구현 시작 전 P0 항목을 요구사항에 확정해야 한다.**

- 문서 설계: 조건부 PASS
- HTML 구현: N/A (아직 없음)
- 실제 계산 정확도: 미검증
- 실제 현장 사용성: 미검증
- 자동 제어 안전성: N/A (v0 범위 밖)

## 확인된 강점

| 항목 | 상태 | 근거 |
| --- | --- | --- |
| 수동·로컬 보조도구 범위 | PASS | 외부 연동·자동 제어를 제외하고 CSV 중심으로 정의 |
| 차지 이력의 시점 분리 | PASS | 샘플 채취 시각과 분석 수신 시각을 분리 |
| 재료·단위·수율 관리 | PASS | 기준값과 실제 차지 입력을 분리, 원본/환산값 보존 |
| G0~G8 관리 게이트 | PASS | 시작부터 출강·결과 보정까지의 흐름 정의 |
| 기준값 승인/버전 보존 | PASS | 초안·검토·승인·중지와 과거 버전 보존 정의 |
| 국내·해외 연구 카탈로그 | PASS | 38건의 서지·링크·활용도 보관 |

## 구현 전 반드시 확정할 P0 항목

| ID | 발견 사항 | 위험 | 필요한 기능/결정 |
| --- | --- | --- |
| P0-01 | 강종군은 추가 가능해야 하나, 기존 문서에 CRUD 규칙이 부족했음 | 과거 차지 기준이 바뀌거나 중복 강종 생성 | 추가·복제·새 버전·중지·삭제 제한·중복 검사를 명시. 설정 초안에 반영함 |
| P0-02 | CSV 백업 가져오기의 검증·중복 처리·되돌리기 기준이 없음 | 공용 PC에서 이력 유실·중복·잘못된 병합 | 가져오기 전 미리보기, 스키마 버전 검사, 오류 행 목록, `새로 추가/건너뜀/충돌` 선택, 실패 시 전체 취소를 정의 |
| P0-03 | XLSX 내보내기는 사용자 요구이나 v0 범위 문서에 명시되지 않음 | 기대한 작업자 보고 기능 누락 | CSV는 복원 원본, XLSX는 읽기 전용 사람이 보는 보고서로 범위를 확정 |
| P0-04 | 계산 가능 조건의 기계적 규칙이 부족함 | 미승인·만료·누락 기준으로 참고값이 표시될 위험 | 강종 목표, 재료 기준, 단위/환산, 필수 최신 분석 중 하나라도 불충족이면 계산 대신 사유 표시 |
| P0-05 | 공용 PC에서 설정 승인/CSV 가져오기를 누가 했는지 남기는 최소 장치가 부족함 | 기준값 무단 변경·원인 추적 불가 | v0은 역할명·시각·사유 확인을 강제. 정식판은 사내 계정/권한으로 전환 |

## 권장 구현 순서

1. P0-01~P0-05를 문서로 확정한다.
2. 설정 화면(강종군·재료·단위·게이트)과 승인 버전만 먼저 구현한다.
3. 차지 이벤트 입력과 G0~G8 누락 체크를 구현한다.
4. CSV 내보내기/안전한 가져오기, XLSX 보고서를 구현한다.
5. 현장 전문가와 가상 데이터로 한두 차지 흐름을 검토한다.
6. 그 뒤에만 참고 물질/열수지 계산을 활성화한다.

## 감사 한계

- 실제 차지 데이터, 실제 조업 표준, 설비 화면, 회사 보안 정책을 받지 않았으므로 계산식·임계값·현장 입력 시간은 검증하지 못했다.
- HTML이 없어 브라우저 호환성, IndexedDB 복원, CSV/XLSX 생성, 계산 정확성, 권한 우회 가능성은 검증하지 못했다.
