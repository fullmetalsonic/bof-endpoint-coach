## 2. 구현 계산 범위

- C: 산소 기준조건 환산, 초기 C, Si·Mn·P·Fe 산화 산소, PCR, 슬래그 FeO를 분리한 저·기준·고 물질수지.
- 온도: 용선 현열, C·Si·Mn·P·Fe 반응열, 용강·슬래그·CO/CO₂ 배가스 엔탈피와 열손실률을 이용한 축약 열수지.
- 최신 채택 샘플: 분석 입력 시 누적 산소 스냅샷을 저장하고, 샘플 시점에서 계획 종점까지 문헌 모델 변화량을 실제 C·온도에 더함.
- P·Mn·Si·S: 현장별 종점 계산식이 없으므로 계속 비활성.

## 4. 남은 한계와 위험

1. 문헌 저·고 범위는 통계적 정확도나 신뢰구간이 아니다.
2. 실제 차지, 독립 손계산, 현장 표준 계산표와 비교하지 않았으므로 조업용 정확도는 미검증이다.
3. 축약 열수지는 수분, 석회석 분해, 광석·냉각재 상세 조성, 내화물, 저취가스, 시간별 열손실을 아직 포함하지 않는다.
4. 샘플 이후 자재 투입·재취련·랜스 조건은 이벤트로 보존되지만 동적 보정항에 아직 연결되지 않았다.
5. 같은 계수 프로필이 바뀌면 과거 차지를 다시 열 때 새 값으로 재계산된다. 공식 적용 전 차지별 계산 결과 고정 또는 불변 프로필 버전 기능이 필요하다.

## 5. 결론

초기 스마트 계산기의 문헌 기본선과 수정·승인 우선순위는 구현·검증됐다. 현재 출력은 공개 문헌 기반 참고예상이며, 실제 현장 적용 단계로 승격하려면 독립 손계산과 완료 차지 그림자 검증이 필요하다.
