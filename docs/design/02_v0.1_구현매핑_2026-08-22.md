# v0.1 디자인 구현 매핑

기준: 사용자가 선택한 전문 Data Ledger형 시안과 `01_디자인기획안_v0.md`.

## 고정된 화면 골격

```text
헤더·내비게이션
합성 DEMO/검증 전 배너
진행 차지 탭 + 현재 차지 요약
좌측 G0~G8 | 중앙 다음 행동·품질 막대·분석표 | 우측 Data Ledger
하단 6개 고정 입력 버튼
```

이 골격은 기능 추가 때도 유지한다. 설정·보고서·이력은 별도 화면에 두고 진행 차지 입력을 방해하지 않는다.

## 시안에서 유지한 요소

- 흰색/밝은 회색 업무 화면, 짙은 남색 텍스트, 파란 선택 상태
- 목표 범위 녹색, 주의 황색, 위험 적색
- 현재값 검은 점, 예상값 흰 점, 문헌 시나리오 반투명 범위, 최소/최대 세로 기준선
- 두 점이 가까워도 겹치지 않도록 예상 라벨은 막대 위, 실측 라벨은 막대 아래에 표시
- 카드 장식보다 표·경계선·정보 계층 중심의 고밀도 화면
- G0~G8 단계 레일, Data Ledger, 하단 번호·아이콘·문구 버튼
- 이모티콘 대신 Phosphor 한 종류의 선형 아이콘 사용

## v0.1에서 추가한 요소

- 여러 동시 차지 탭과 `신규 차지`
- C·온도 외 P·Mn·Si·S 실측/목표 행
- 합성 DEMO 데이터·문헌 기본 시나리오·현장 검증 전 배너
- 계산식·계수·설비 프로필과 실제/계획 입력 표시
- 강종·재료·단위·설비·계수 설정 화면
- 계수 설정의 `문헌 원본 / 현장 수정값 / 실제 적용값 / 근거 ID` 표와 `문헌 기본 / 사용자 수정·미승인 / 현장 승인값` 상태

## 화면 변경 규칙

1. 현재값·예상값·목표값을 같은 의미처럼 합치지 않는다.
2. 새 품질 행은 실제값, 목표, 계산 가능 조건, 단위, 자릿수를 함께 정의한다.
3. 정보가 늘어도 상단 요약·G0~G8·Data Ledger·하단 행동의 위치는 임의로 바꾸지 않는다.
4. 긴 영문·긴 강종명 상태를 1280px에서 확인한다.
5. 화면 변경 뒤 기준 이미지와 같은 1280×912 상태로 나란히 비교하고 `app/design-qa.md`에 결과를 남긴다.
