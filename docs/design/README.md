# 디자인 기준선

이 폴더는 취련 코치 v0의 화면이 구현 과정에서 지나치게 단순해지거나, 실제 연동 기능이 있는 것처럼 과장되는 것을 막기 위한 디자인 기준선이다.

## 적용 순서

1. 새 화면 또는 큰 화면 변경 전 `01_디자인기획안_v0.md`를 확인한다.
2. 화면 단위 설계는 `templates/화면설계서_템플릿.md`를 복제해 작성한다.
3. 상태·문구·색상은 `templates/상태표현_템플릿.md`의 형식을 따른다.
4. 현장 검토 결과는 `templates/화면검토기록_템플릿.md`로 남긴다.
5. 결정된 변경은 반드시 상위 원장 `../governance/누적이력관리.md`에도 추가한다.

## 현재 상태

- 기준 화면: PC용 `현재 차지` 화면
- 시각 방향: 전문 데이터 레저
- 구현: 아직 시작하지 않음
- 현장 기준값·계산식: 미확정, 현장 승인 필요

## 해석 우선순위

서로 충돌하면 아래 순서로 적용한다.

1. 안전·현장 표준작업·회사 보안 정책
2. 승인된 강종군/재료/게이트 기준값
3. `01_디자인기획안_v0.md`
4. `../ui/UI_시각규칙_초안.md`
5. 개별 화면 설계서와 검토 기록
