# 상태·문구·색상 정의 템플릿

> 강종군별 임계값 자체가 아니라, 화면이 그 값을 어떻게 표현할지를 정하는 표다.

## 공통 상태표

| 상태 코드 | 사용자 표시명 | 의미 | 색상 | 함께 표시할 정보 | 허용 행동 예 | 금지 표현 |
| --- | --- | --- | --- | --- | --- | --- |
| `IN_RANGE` | 목표 범위 내 | 승인 기준의 범위 안 | `#1F7A4D` | 실제값·단위·목표 범위·시점 | 다음 확인 계속 | 안전 확정 |
| `NEAR_LIMIT` | 상한/하한 접근 | 승인된 접근 조건 충족 | `#B7791F` | 어느 한계인지·여유값·시점 | 재샘플 검토 / 기준 확인 | 즉시 조업 지시 |
| `OUT_OF_RANGE` | 목표 범위 이탈 | 실제값이 승인 범위 밖 | `#C53B3C` | 실제값·범위·벗어난 방향 | 재샘플/재취련 검토 기록 | 자동 조치 실행 |
| `MISSING` | 입력 확인 필요 | 필수 값/기준이 없음 | `#6B7280` | 부족 항목 이름 | 입력 화면 열기 | 정상으로 추정 |
| `STALE` | 시점 확인 필요 | 현장 승인 신선도 기준 초과 | `#B7791F` | 마지막 채취/입력 시각 | 최신 분석 확인 | 최신값처럼 표시 |
| `REFERENCE_ONLY` | 참고 예상 | 수동 입력 기준의 계산 참고값 | `#1554B8` | 계산 시각·기준 버전·입력 조건 | 참고값 검토 | 실제 분석값처럼 표시 |

## 접근성 확인

- [ ] `빨강/초록`을 구별하지 못해도 텍스트·수치·위치로 상태를 알 수 있다.
- [ ] 경고 문구가 사용자를 비난하거나 과도하게 불안하게 만들지 않는다.
- [ ] 단위와 기준 범위가 숫자 가까이에 있다.
- [ ] 예상값과 실제 분석값의 표식과 명칭이 다르다.
