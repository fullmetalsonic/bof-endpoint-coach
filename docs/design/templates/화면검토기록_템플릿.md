## 확인 시나리오

| 번호 | 시나리오 | 사용자가 해야 할 일 | 성공 기준 | 결과 |
| --- | --- | --- | --- | --- |
| 1 | 최신 분석값을 입력했다 | 목표 대비와 시점을 확인한다 | 실제값·단위·시점·기준을 찾을 수 있다 |  |
| 2 | 기준 또는 필수 입력이 없다 | 부족한 값을 찾는다 | 예상값을 실제값으로 오해하지 않는다 |  |
| 3 | 관리 항목이 5개보다 많다 | 추가 항목을 확인한다 | 핵심 항목과 추가 항목을 구분한다 |  |
| 4 | 출강 전이다 | 미결 확인 항목을 확인한다 | 이 화면이 출강 지시가 아님을 이해한다 |  |
