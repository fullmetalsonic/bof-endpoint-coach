# 취련 코치 v0 — 필요 데이터 체크리스트

이 도구의 목표는 자동 제어가 아니라, 차지별 수동 기록을 일관되게 남기고 **샘플·재샘플·추출을 검토할 근거**를 보여주는 것이다. 따라서 데이터는 아래 순서로 준비한다.

## A. 매 차지 필수 입력

이 항목만 있어도 차지 흐름과 결과를 나중에 비교할 수 있다.

| 데이터 | 입력 시점 | 단위/형식 | 왜 필요한가 |
| --- | --- | --- | --- |
| 차지 ID | 시작 | 현장 식별자 | 모든 기록을 한 차지로 묶음 |
| 강종군 | 시작 | 코드 또는 익명 그룹 | 목표값·기준값 선택 |
| 목표 성분 범위 | 시작 | `%` 또는 `ppm` | 현재 분석값과 비교 |
| 목표 온도 범위 | 시작 | `°C` | 추출 검토 기준 |
| 실제 투입 재료 | 투입 때 | 재료 코드 | 무엇이 들어갔는지 추적 |
| 실제 투입량·단위 | 투입 때 | kg/t 등 | 물질·열수지 참고 |
| 투입 시각 | 투입 때 | KST 시각 | 샘플/추출과의 순서 확인 |
| 샘플 ID·채취 시각 | 샘플 때 | ID·KST 시각 | 분석값이 어느 시점 공정 상태인지 확인 |
| 분석 결과 수신 시각 | 분석 수신 때 | KST 시각 | 결과 지연과 공정 진행을 구분 |
| 최신 분석 성분·온도 | 분석 수신 때 | 항목별 표준 단위 | 목표 비교·추출 검토 |
| 재취련/재샘플 여부·사유 | 발생 때 | 선택값+짧은 메모 | 실패·보정 근거 축적 |
| 실제 추출 시각·결과 | 완료 때 | KST·성분·온도 | 추천/판단을 결과와 비교 |

처음 화면은 이 중에서 "지금 해야 하는 입력"만 보여야 한다. 시작 때 모든 칸을 한꺼번에 보이면 입력 누락이 늘어난다.

## B. 계산 품질을 위한 기준값 관리

차지마다 반복 입력하지 않고, 권한 있는 사람이 기준값 화면에서 관리한다.

| 데이터 | 대상 | 설명 |
| --- | --- | --- |
| 재료 코드·분류·기본 단위 | 모든 재료 | 용선/스크랩/Flux/냉각재/합금철 등 |
| 대표 조성·조성 범위 | 용선·스크랩·합금철·Flux | 현장에서 관리하는 성분만 사용 |
| 분석 기준 | 조성값 | 습식/건식, 원소/산화물 등 |
| 수분·강열감량·입도 | 필요 재료만 | Flux·냉각재 등에서 유효 투입량 해석에 필요할 수 있음 |
| 회수율/유효율 | 합금철·가탄재 등 | 원소 함량과 별도로 관리 |
| 로트 ID·성적서 참조 | 가능한 재료 | 실제 로트값이 있을 때 대표값 대신 적용 |
| 출처·적용일·버전·승인 상태 | 모든 기준값 | 과거 계산을 재현하고 무단 변경 방지 |

## C. 입력 가능하면 가치가 큰 공정 데이터

회사 시스템 연동 없이도 작업자가 확인 가능한 범위에서 선택 입력한다. 이 데이터가 쌓이면 추출 검토의 근거가 더 좋아진다.

| 데이터 | 용도 | v0 처리 방식 |
| --- | --- | --- |
| 취련 시작/종료 시각 | 총 경과 시간 확인 | 수동 이벤트 |
| 누적 산소량·경과 시간 | 공정 단계 참고 | 값·단위·확인 시각 기록 |
| 랜스/산소/교반의 단계명 | 조업 조건 구분 | 수치가 아니라 단계명부터 선택 가능 |
| 중간 온도·중간 C/O | 반동적 보정 | 샘플 ID와 연결 |
| 슬래그 분석·관찰 | 탈인·슬래그 관련 해석 | 없으면 빈 값 허용 |
| 설비/노차/작업조 그룹 | 조건 차이 분석 | 개인 식별 없이 코드화 가능 |
| 이상 이벤트 | 데이터 제외·검토 근거 | 설비 이상/입력 누락/특수 조업 등 선택값 |

## D. 결과 평가 데이터

이 도구가 실제 도움이 되는지 판단하려면 최소한 아래 결과가 필요하다.

- 목표 대비 최종 C·Mn·P·S 등 관리 성분의 편차
- 목표 대비 최종 온도 편차
- 재샘플·재취련 발생 여부와 횟수
- 추출까지 걸린 시간
- 실제 투입량과 당시 기준값/참고 계산값의 차이
- 입력 누락률과 입력 시각 지연
- 작업자가 참고값을 수정했다면 수정 사유

원가나 수율은 정식 승인 전에는 선택 항목으로 둔다. 금액·생산 실적은 보안 민감도가 더 높을 수 있다.

## E. v0에서 받지 않아도 되는 데이터

- PLC 실시간 태그 전체
- HMI 화면 원본·스크린샷
- 전 직원 실명·개인 평가 정보
- 회사의 전체 강종 기준표·전체 원료 성적서
- 안전 인터록·설비 제어값

이 데이터들은 정식 도입과 권한·보안 검토가 끝난 뒤에만 별도 논의한다.

## 데이터 최소 세트 요약

```text
차지 ID + 강종군 + 목표 성분/온도
+ 실제 재료/중량/시각
+ 샘플 ID/채취시각/수신시각/분석값
+ 재취련·추출 결과
+ 당시 적용한 재료 기준값 버전
```

이 최소 세트가 먼저 안정되면, 누적 이력으로 "어떤 조건에서 목표 편차나 재취련이 늘었는지"를 볼 수 있다. 그 뒤에만 산소량·슬래그·설비 조건 같은 선택 데이터를 추가한다.
