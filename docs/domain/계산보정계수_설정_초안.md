# 계산·보정 계수 설정 초안

상태: `BOF-REF-CALC 0.2.0` 구현 기준. 이 문서는 현장 조업 권고값을 제공하지 않는다.

## 1. 목적

공개 이론의 일반식과 특정 현장의 실제 결과 사이에는 재료 조성, 산소 효율, 열손실, 슬래그 조건, 설비 상태 차이가 있다. 이 차이를 숨긴 상수로 코드에 넣지 않고, 현장 출처·적용 범위·승인 상태를 가진 계수로 관리한다. 계수는 종점 C·온도 등 특정 수치예상 식의 항에 직접 연결한다.

## 2. 계수 그룹

| 그룹 | 예시 | 적용 전 조건 |
| --- | --- | --- |
| 재료 유효성 | 재료별 조성, 수분, 금속수율, 원소 회수율 | 재료 기준값 승인 |
| 물질수지 | 산소 배분, 슬래그/금속 손실 관련 보정, 탄소 수지 가정 | 식·단위·출처·가상 손계산 승인 |
| 열수지 | 원료 온도 영향, 냉각재/스크랩 열영향, 열손실 보정 | 적용 설비/차지량 범위 승인 |
| 반동적 보정 | 샘플 뒤 실제 산소·투입·경과시간의 보정 계수 | 중간 샘플 단계·실제 이벤트 정의 승인 |
| 이력 보정 | 유사 차지 가중치, 예측 범위 산정, 제외 규칙 | 데이터 충분성·독립 검증·그림자 예상 통과 |

## 2-1. 근거등급과 값의 역할

계수 레코드는 숫자뿐 아니라 근거 성격을 저장한다.

| 등급 | 의미 | 승인 전 사용 |
| --- | --- | --- |
| A 물리·화학량론 | 기준조건과 반응식으로 재현 가능 | 계산 검증을 통과하면 사용 가능 |
| B 문헌 참고범위 | 공개 연구의 범위와 적용 조건이 있음 | 저·기준·고 민감도 시나리오만 허용 |
| C 현장 보정 | 설비·강종·조업 조건에 따라 달라짐 | 현장 승인 또는 이력 검증 전 비활성 |
| D 합성 DEMO | UI·코드 시험용 | DEMO 차지에서만 사용 |

문헌값이라는 이유만으로 승인 상태가 되지는 않는다. B등급 값은 `현장 승인값`이 아니라 `문헌 시나리오`로 표시한다. 상세 판정은 [종점계수 문헌 근거 매트릭스](../research/종점계수_문헌근거매트릭스_2026-08-22.md)를 따른다.

## 3. 계수 레코드 필수 필드

- 계수 코드·이름·설명
- 적용 계산 모듈과 입출력 항목
- 연결 계산식·변수명 또는 보정항 이름
- 값·단위·유효 자릿수·허용 입력 범위
- 적용 강종군·설비/조업 조건 프로필·재료 버전
- 출처: 현장 표준 / 승인 계산표 / 검증 이력 / 임시 가정
- 근거등급: A / B / C / D
- 출처 ID·원문 URL·원문 위치 또는 식 번호
- 출처 적용 조건: 전로 용량, 취련 방식, 강종/성분 범위, 장입비, 기준 온도·압력
- 값 역할: 고정 상수 / 문헌 시나리오 / 현장 설정 / 이력 보정 / DEMO
- 검증 방법·가상 시험 사례 ID·검증 결과
- 작성자 역할·검토자 역할·승인일·적용 시작/종료일·버전

## 4. 적용 우선순위와 상태 규칙

1. 문헌 원본값은 읽기 전용 `literatureValues`로 보존한다.
2. 사용자가 입력한 값은 `overrideValues`에 저장하고 원본값을 덮어쓰지 않는다.
3. 실제 계산 병합 우선순위는 `현장 승인 수정값 → 사용자 수정값 → 문헌 원본값`이다.
4. 수정값이 있으면 승인 전에도 계산에 사용하되 모든 결과·화면·보고서에 `사용자 수정 · 미승인`을 표시한다.
5. `현장 승인값`으로 바꾸려면 승인자/역할, 승인 근거, 승인 시각이 필요하다. 승인 뒤 숫자를 다시 바꾸면 승인은 자동 해제된다.
6. 수정값을 모두 지우면 즉시 문헌 기본 시나리오로 돌아간다.
7. A등급은 기준조건이 다르면 별도 값으로 계산하고, B등급은 단일 현장값으로 자동 승격하지 않는다.
8. 설정 저장 이벤트에는 당시 계수 프로필 전체 스냅샷을 작업 이력에 남겨 백업한다.
9. 현재 초기 버전은 같은 계수 프로필을 참조하는 과거 차지의 계산 결과를 자동 고정하지 않는다. 공식 적용 전에는 차지별 계산 결과 스냅샷 또는 불변 프로필 버전 생성 기능이 추가되어야 한다.

## 5. 초기 사용자 경험

처음에는 공개 문헌 시나리오가 채워져 있으며, 사용자는 필요한 항목만 수정한다. 화면은 다음 상태를 명확히 보여 준다.

- `문헌 기본`: 수정값 없음, 현장 정확도 미검증
- `사용자 수정 · 미승인`: 수정값을 계산에 사용, 현장 승인 아님
- `현장 승인값`: 승인자·근거·시각이 있는 수정값을 계산에 사용
- 각 항목의 `문헌 원본 / 현장 수정값 / 실제 적용값 / 근거 ID`

문헌 원본과 수정값은 백업·보고서에서 구분한다. 문헌 저·고 결과는 통계적 오차범위가 아니라 민감도 시나리오다.
