# 계산·보정 계수 설정 초안

상태: 값 미입력 설계안. 이 문서는 실제 계수값이나 조업 권고값을 제공하지 않는다.

## 1. 목적

공개 이론의 일반식과 특정 현장의 실제 결과 사이에는 재료 조성, 산소 효율, 열손실, 슬래그 조건, 설비 상태 차이가 있다. 이 차이를 숨긴 상수로 코드에 넣지 않고, 현장 출처·적용 범위·승인 상태를 가진 계수로 관리한다. 계수는 종점 C·온도 등 특정 수치예상 식의 항에 직접 연결한다.

## 2. 계수 그룹

| 그룹 | 예시 | 적용 전 조건 |
| --- | --- | --- |
| 재료 유효성 | 재료별 조성, 수분, 금속수율, 원소 회수율 | 재료 기준값 승인 |
| 물질수지 | 산소 배분, 슬래그/금속 손실 관련 보정, 탄소 수지 가정 | 식·단위·출처·가상 손계산 승인 |
| 열수지 | 원료 온도 영향, 냉각재/스크랩 열영향, 열손실 보정 | 적용 설비/차지량 범위 승인 |
| 반동적 보정 | 샘플 뒤 실제 산소·투입·경과시간의 보정 계수 | 중간 샘플 단계·실제 이벤트 정의 승인 |
| 이력 보정 | 유사 차지 가중치, 예측 범위 산정, 제외 규칙 | 데이터 충분성·독립 검증·그림자 예상 통과 |

## 3. 계수 레코드 필수 필드

- 계수 코드·이름·설명
- 적용 계산 모듈과 입출력 항목
- 연결 계산식·변수명 또는 보정항 이름
- 값·단위·유효 자릿수·허용 입력 범위
- 적용 강종군·설비/조업 조건 프로필·재료 버전
- 출처: 현장 표준 / 승인 계산표 / 검증 이력 / 임시 가정
- 검증 방법·가상 시험 사례 ID·검증 결과
- 작성자 역할·검토자 역할·승인일·적용 시작/종료일·버전

## 4. 활성화 규칙

1. 새 계수는 `초안`으로만 만든다.
2. 가상 입력과 승인된 손계산 결과가 일치해야 `검토 요청`이 가능하다.
3. 해당 강종군·설비 프로필에서 그림자 예상과 독립 검증을 통과해야 수치 종점 예상에 쓸 수 있다.
4. 적용 중인 계수가 만료·중지·누락이면, 해당 모듈은 `계산 불가: 계수 미승인`으로 표시한다.
5. 계수를 바꾸면 새 버전으로 만들고, 기존 차지와 과거 보고서의 결과는 당시 버전으로 재현한다.

## 5. 초기 사용자 경험

처음에는 계수 화면에 숫자를 채우도록 요구하지 않는다. 대신 다음 상태를 명확히 보여 준다.

- `정적 계산 준비 중: 재료 수율 계수 미승인`
- `샘플 보정 불가: 해당 설비 프로필의 산소 효율 계수 없음`
- `이력 보정 대기: 비교 가능 완료 차지 부족`

이후 현장 담당자가 승인한 값만 해당 계산 모듈에 연결한다.
