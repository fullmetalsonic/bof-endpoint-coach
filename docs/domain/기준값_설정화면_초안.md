# 기준값 설정 화면 초안

## 왜 별도 화면이 필요한가

취련 코치는 취련사의 판단을 보조하는 도구다. 따라서 개발자나 일반 사용자가 공정 수치를 코드에 고정하는 것이 아니라, 현장 전문가가 승인한 기준을 화면에서 등록·검토·버전 관리해야 한다.

차지 입력 화면은 매 차지의 사실(투입·샘플·분석·출강)을 기록한다. 설정 화면은 그 사실을 어떤 기준으로 비교·계산할지 관리한다. 두 역할을 섞지 않는다.

## 설정 화면의 7개 메뉴

| 메뉴 | 관리 대상 | 적용 대상 |
| --- | --- | --- |
| 1. 강종군 목표 | 관리 성분, 목표 범위, 온도 범위, 목표 출강량 | 강종군별 차지 |
| 2. 재료 기준값 | 원료/부원료/스크랩 조성, 단위, 분석 기준, 수율, 로트 정책 | 재료 선택·참고 계산 |
| 3. 관리 게이트 | G0~G8별 필수 입력, 경고 조건, 표시 문구, 확인 주체 | 차지 대시보드 |
| 4. 단위·환산 | 표준 단위, 허용 입력 단위, 환산식 버전, 변환 금지 조건 | 입력·CSV·계산 |
| 5. 설비·조업 조건 | 전로·랜스·저취 구성, 조업 패턴, 설비 상태·영향인자 정의 | 설비/조업 조건별 차지·비교군 |
| 6. 계산·보정 계수 | 재료/물질·열수지/샘플 보정/이력 보정 계수와 검증 상태 | 승인된 참고 계산 |
| 7. 버전·승인 | 작성자, 검토자, 적용일, 사유, 이전 버전, 상태 | 전체 설정 |

## 1. 강종군 목표 설정

강종의 실제 기밀 명칭을 쓰기 어렵다면 `강종군 A`, `저탄소군`, `고망간군`처럼 승인된 그룹명으로 시작할 수 있다.

필드 예:

- 강종군 코드·표시명
- 관리 항목 목록: C, Mn, P, S, 온도 등 현장이 선택한 항목
- 항목별 목표 방식(범위 / 상한만 / 하한만 / 목표값±허용차)과 단위
- 목표 온도 최소/최대와 단위
- 목표 출강량 범위
- 후공정 보정 가능 여부와 메모
- 적용 설비/조업 조건 그룹
- 기준 출처·작성자·검토자·적용일

목표값이 없는 성분은 0이나 빈 범위로 추정하지 않고 `관리 대상 아님`으로 명시한다.

각 관리 항목에는 `표시 순서`, `핵심 표시 여부`, `필수 입력 여부`, `분석값 연결 항목`을 함께 설정한다. 따라서 사용자는 같은 강종군에 필요한 관리 항목을 계속 추가할 수 있지만, 승인 전에는 차지 계산에 쓰이지 않는다.

### 강종군 추가·변경·중지 기능

사용자는 강종군을 계속 추가할 수 있어야 한다. 다만 이미 완료된 차지의 기준이 바뀌지 않도록 아래 규칙을 둔다.

- `새 강종군 추가`: 고유 코드·표시명·초안 상태로 생성한다. 목표값이 승인되기 전에는 계산에 사용할 수 없다.
- `기존 강종군 복제`: 비슷한 강종군의 관리 성분·단위만 복사하고, 목표 범위·적용 조건은 새 초안으로 다시 검토한다.
- `새 버전 만들기`: 승인된 강종군의 목표/경고 범위를 바꿀 때는 새 버전을 만든다. 기존 버전은 덮어쓰지 않는다.
- `중지(archive)`: 더 쓰지 않는 강종군은 새 차지 선택 목록에서는 숨기되, 과거 차지에서 삭제하지 않는다.
- `삭제 제한`: 이미 차지에 사용된 강종군·재료·환산 규칙은 물리 삭제하지 않는다.
- `중복 검사`: 강종군 코드 중복, 최소값이 최대값보다 큰 경우, 관리 단위 미지정, 목표 범위 누락을 저장 전에 막는다.

## 2. 재료 기준값 설정

재료마다 다음을 관리한다.

- 재료 코드·표시명·분류
- 기본 계량 단위와 허용 입력 단위
- 조성값, 조성 범위, 분석 기준(습식/건식·원소/산화물)
- 수분·강열감량·입도 등 필요한 품질 항목
- 합금 원소 회수율 또는 유효율
- 대표값/로트 실측값 적용 방식
- 분석 성적서 출처·적용일·만료일

이 메뉴의 조성값은 "정확한 실제값"이라고 단정하지 않는다. `현장 승인 대표값`, `로트 분석값`, `임시 가정` 상태를 분명히 표시한다.

## 3. 관리 게이트 설정

G0~G8 각각에 대해 다음을 설정한다.

- 필수 입력 항목: 예를 들어 G4에는 샘플 ID·채취 시각·분석값
- 경고 조건: 예를 들어 최신 분석 시점 확인 필요
- 표시 문구: `출강 검토`, `재샘플 검토`, `책임자 확인 필요`
- 확인 주체: 취련사/반장/품질 담당 등 현장 역할명
- 다음 게이트로 진행하는 데 필요한 확인 여부

처음에는 복잡한 수식 대신 **체크리스트와 누락 경고**만 설정해도 된다. 실제 수치 경고는 현장 검토 뒤 추가한다.

## 4. 단위·환산 설정

- 항목별 계산 표준 단위
- 사용자가 선택할 수 있는 입력 단위 목록
- 허용된 변환식과 버전
- 자동 변환 금지 항목
- CSV 열의 단위 표기 규칙

사용자는 변환식을 수정하는 대신, 허용된 목록에서만 단위를 선택한다. 원본값과 환산값은 모두 보관한다.

## 5. 설비·조업 조건 설정

전로 호칭 용량·취련 방식·랜스 프로필·저취 구성처럼 장기간 유지되는 사양은 이 메뉴에서 설정한다. 실제 장입량·실제 랜스 높이·누적 산소량·실제 교반가스처럼 차지마다 달라지는 값은 차지 이벤트에 기록한다.

- 전로 코드·방식·호칭 용량·적용 강종군
- 랜스 코드·노즐 구성 설명·허용 유량/높이 단계 템플릿·상태 기록 방식
- 저취/교반 구성·가스 종류·단계 템플릿
- 대기시간·내화물/랜스 경과 상태·비정상 조업의 기록/비교군 사용 여부
- 현장 특화 영향인자의 추가 정의, 필수 수준, 계산/비교군 사용 여부

세부 필드와 안전 경계는 [설비·조업 조건 프로필](설비_조업조건_프로필_초안.md)을 따른다.

## 6. 계산·보정 계수 설정

재료 수율, 물질·열수지, 샘플 이후 보정, 이력 보정에 쓰는 계수의 출처·적용 범위·검증·승인을 관리한다. 승인된 계수가 없으면 숫자 종점 예상은 출력하지 않는다.

세부 규칙은 [계산·보정 계수 설정](계산보정계수_설정_초안.md)을 따른다.

## 7. 버전·승인 흐름

```text
초안 작성 → 현장 전문가 검토 → 승인 → 적용 → 변경/폐기
```

| 상태 | 의미 |
| --- | --- |
| 초안 | 테스트/검토 중. 실제 차지 계산에 사용하지 않음 |
| 검토 요청 | 현장 전문가가 확인해야 함 |
| 승인 | 적용일 이후 차지에 사용 가능 |
| 중지 | 새 차지에는 사용하지 않음. 과거 이력은 유지 |

- 승인된 설정을 수정하면 덮어쓰지 않고 새 버전을 만든다.
- 차지 기록에는 당시 적용된 강종군·재료·게이트·환산 규칙의 버전을 자동으로 붙인다.
- 누가 무엇을 바꾸었는지와 사유를 남긴다.

공용 PC의 v0에 계정 연동이 없다면, 최소한 설정의 승인·중지·가져오기 작업에서 `확인자 역할명`, `수행 시각`, `사유`를 필수 기록한다. 이것은 인증을 대신하지 않으며, 정식 도입에서는 사내 계정·권한으로 전환한다.

## 사용자를 위한 첫 설정 흐름

취련사가 아닌 사용자가 처음부터 수치를 알아야 할 필요는 없다.

1. 빈 템플릿에서 강종군/재료명/현장 단위만 먼저 만든다.
2. 취련사·반장·품질 담당에게 목표 범위와 실제 관리 항목을 받는다.
3. 받은 값은 `초안`으로 입력한다.
4. 현장 검토자가 확인한 뒤에만 `승인`으로 바꾼다.
5. 승인된 최소 항목으로 한두 차지의 기록 흐름부터 시험한다.

## v0의 안전 원칙

- 설정값이 하나라도 필요한데 비어 있으면, 계산 결과 대신 `기준값 미승인`을 표시한다.
- 초안·만료·중지 기준값으로 실제 차지의 참고 계산을 하지 않는다.
- 자동으로 기준값을 학습·변경하지 않는다. 도구는 변경 후보만 보여 준다.
- 안전·설비 제어·조업 표준을 설정 화면에서 대체하지 않는다.
