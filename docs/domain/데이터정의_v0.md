# v0 데이터 정의

아래는 공용 PC에서 사람이 수동으로 기록할 수 있는 최소안이다. 모든 항목을 첫날부터 강제하지 않는다. 실제 현장 입력 가능 여부를 확인한 뒤 `필수`와 `선택`을 확정한다.

## 1. 차지 기본 정보

| 항목 | v0 | 설명 |
| --- | --- | --- |
| `heat_id` | 필수 | 차지를 구분하는 현장 식별자 |
| `started_at` | 권장 | 장입 또는 취련 시작 시각 |
| `steel_grade_group` | 필수 | 기밀을 피해야 하면 공개용 그룹명 사용 |
| `operator_alias` | 선택 | 개인 실명 대신 작업자 별칭 또는 공란 |
| `status` | 필수 | 진행중 / 추출완료 / 취소 |

## 2. 목표와 초기 상태

| 항목 | v0 | 설명 |
| --- | --- | --- |
| 목표 C·온도·P·S·Mn·Si 및 강종 특화 성분 | 강종별 선택 | 실제 현장에서 관리·분석 가능한 성분만 사용. 세부는 `품질관리항목_초안.md` 참조 |
| 목표 온도 범위 | 권장 | 단일값보다 최소·최대 범위 |
| 용선/스크랩/장입 총량 | 선택 | 계산을 하려면 단위와 측정시각 필수 |
| 초기 분석·온도 | 선택 | 직접 입력 가능한 값만 |

## 3. 이벤트 기록

모든 이벤트에 `event_time`과 `recorded_time`을 분리해 저장한다. 분석 결과는 채취 시점의 공정 상태를 의미하므로, 결과를 받은 시각만 기록하면 흐름 해석이 틀어질 수 있다.

| `event_type` | 예시 입력 |
| --- | --- |
| `addition` | 원료/부원료명, 중량, 단위, 투입 시각 |
| `sample_taken` | 샘플 번호, 채취 시각 |
| `analysis_received` | 샘플 번호, 분석 수신 시각, 성분, 온도 |
| `blow_checkpoint` | 취련 경과 시간, 누적 산소량 등 사용자가 확인 가능한 값 |
| `blow_pattern_change` | 실제/계획 구분, 풍량 또는 산소 유량, 적용 시작/종료 시각, 패턴명 |
| `reblow` | 재취련 시작/종료와 사유 |
| `tap` | 추출 시작/종료, 실측 온도·성분, 메모 |
| `exception` | 이상 징후·입력 누락·계산 미사용 사유 |

시간 경과형 참고 예상에 쓰는 취련 시작·풍량 패턴·투입·샘플·분석 시각 규칙은 `시간경과형_참고예상_입력규칙_초안.md`를 따른다.

## 4. 기준값과 보정값

계산에 쓰는 모든 값은 다음을 함께 저장한다.

- 적용 강종군·설비 조건
- 값과 단위
- 적용 시작일, 종료일
- 근거: 현장 승인 / 과거 이력 분석 / 임시 가정
- 승인자 또는 검토 상태
- 변경 사유

따라서 과거 차지를 다시 열었을 때, 당시 어떤 기준으로 참고 계산을 했는지 재현할 수 있다.

## 5. 원료·부원료·스크랩 기준값 관리

차지 입력 화면에 매번 조성을 다시 쓰면 오입력이 늘고, 나중에 왜 계산이 달랐는지 확인할 수 없다. 따라서 v0에는 별도의 **기준값 관리 화면**이 필요하다. 일반 작업자는 차지에서 재료를 선택하고 중량만 넣으며, 기준값 변경 권한이 있는 사람만 조성·수율·단위를 수정한다.

### 5-1. 재료 마스터의 공통 항목

| 항목 | 설명 |
| --- | --- |
| 재료 코드·표시명 | 예: 현장 관리명과 화면 표시명을 분리 가능 |
| 분류 | 용선 / 스크랩군 / 철원 / Flux·부원료 / 냉각재 / 합금철 / 기타 |
| 계량 단위 | kg 또는 t. 한 재료에는 하나의 기본 단위를 고정 |
| 성분 기준 | `as received`(입고 상태) 또는 건식 기준 등 분석 기준을 명시 |
| 대표 성분·범위 | 평균값만 아니라 가능한 경우 최소~최대 또는 최근 분석일도 기록 |
| 분석 출처·적용일 | 성적서/사내 기준/임시 가정, 적용 시작일과 변경 사유 |
| 상태·버전 | 사용중/중지, 기준값 버전. 과거 차지는 당시 버전을 유지 |

### 5-2. 재료군별 최소 성분

| 재료군 | 초기에 관리할 후보 | 이유 |
| --- | --- | --- |
| 용선·철원 | C, Si, Mn, P, S, 온도, 금속수율 | 물질·열수지의 기본 입력 |
| 스크랩 | 중량, 그룹, 대표 C/Mn 및 현장에서 관리하는 잔류 원소(Cu, Ni, Cr, Sn 등), 수분/이물 위험 여부 | 성분 유입과 안전·변동성 기록 |
| 석회·돌로마이트 등 Flux | CaO, MgO, SiO2, 수분·강열감량 등 현장 관리값 | 슬래그 형성과 유효 투입량의 맥락 |
| 냉각재·철광석 계열 | Total Fe 또는 금속 Fe, 산화물 기준, 수분, 필요 시 입도 | 열수지·산소 균형의 입력 후보 |
| 합금철·가탄재 | 목표 원소 함량, 회수율(수율), C/Si 등 동반 성분 | 최종 성분 보정의 실제 효과 반영 |

위 항목은 도구가 직접 제시하는 표준 조성이 아니다. **현장에서 이미 관리·승인한 항목만** 활성화하고, 없는 분석값은 빈 값으로 남긴다.

### 5-3. 차지 입력과 기준값의 역할 분리

```text
기준값 관리(가끔 변경)                 차지 기록(매 차지)
재료명·단위·대표 조성·수율·버전  →  재료 선택·실제 투입 중량·투입 시각·선택 로트
```

- 로트별 성적서를 알 수 있으면, 차지 기록에서 `lot_id`와 실제 분석값을 덧붙인다.
- 모르면 대표 조성을 사용하되 화면에 `대표값 사용`이라고 표시한다.
- 조성값과 회수율은 다르다. 합금 원소 함량이 100%에 가까워도 공정 중 산화·슬래그 손실 등에 따라 용강에 남는 비율은 별도의 현장 승인 수율로 관리해야 한다.

### 5-4. 단위·농도 표기 규칙

- 금속·슬래그 조성은 `%` 또는 `ppm` 중 하나를 항목별로 고정하고 화면에 항상 함께 표시한다.
- 온도는 `°C`, 중량은 `kg` 또는 `t`, 가스는 `Nm³` 등 현장 단위를 명시한다.
- `%`와 `ppm`, `kg`와 `t`, 습식과 건식 기준을 자동으로 섞거나 추정 변환하지 않는다. 변환을 지원한다면 원본값·원본단위·변환식을 함께 이력으로 남긴다.
- 입력값이 기준 범위를 벗어나면 "입력 확인"만 표시하고, 임의로 잘라내거나 평균값으로 바꾸지 않는다.

### 5-5. 단위 선택·환산 기능

작업자가 받는 계량표·분석표의 단위가 다를 수 있으므로, 각 숫자 입력 옆에 단위 선택을 둔다. 화면은 선택한 단위로 바로 보여 주되, 계산과 이력 비교에는 항목별 표준 단위를 사용한다.

| 입력 항목 | 허용 자동 환산 예 | 계산용 표준 단위 예 |
| --- | --- | --- |
| 질량 | `kg ↔ t` | kg 또는 t 중 프로젝트에서 하나 선택 |
| 농도 | `wt% ↔ ppm` | 성분별 `%` 또는 `ppm` |
| 온도 | `°C ↔ K` | °C |
| 시간 | 초 / 분 | 분 또는 초 중 하나 |

다음은 단위 기호가 비슷해도 자동 변환하지 않는다.

- 습식 기준 ↔ 건식 기준: 수분값과 적용 기준이 있어야 한다.
- 원소량 ↔ 산화물량: 화학식·분석 기준을 명시하고 승인된 환산식이 있어야 한다.
- 실제 부피 `m³` ↔ 표준부피 `Nm³`: 온도·압력 기준이 있어야 한다.
- 질량분율 `wt%` ↔ 부피분율: 밀도·상태 조건이 필요하다.
- 원소 함량 ↔ 회수율: 서로 다른 의미이므로 변환 대상이 아니다.

저장할 때는 환산값만 남기지 않고 아래를 모두 보관한다.

```text
original_value       # 작업자가 본 원래 숫자
original_unit        # 작업자가 선택한 단위
normalized_value     # 승인된 환산식으로 계산한 값
canonical_unit       # 계산·비교에 쓰는 표준 단위
conversion_rule_id   # 적용한 환산 규칙/버전
conversion_status    # 자동환산 / 입력확인필요 / 변환불가
```

따라서 나중에 "2.5 t를 2500 kg으로 환산한 것인지"와 "처음부터 2500 kg으로 입력한 것인지"를 구별할 수 있다. 단위 선택을 바꾸어도 원본 입력을 덮어쓰지 않으며, 변환 불가 항목은 계산에서 제외하고 이유를 표시한다.

## 6. 데이터 품질 검사

- 단위(kg, t, %, °C, Nm³)를 항목마다 고정해 혼용을 막는다.
- 음수, 비현실적으로 큰 값, 목표 범위 역전은 저장 전 확인한다.
- 분석값에는 샘플 번호와 채취·수신 시각 중 하나라도 없으면 "시점 불명"으로 표시한다.
- 변경·삭제는 사유와 시각을 기록한다. 원본을 단순 덮어쓰지 않는다.
- 계산 결과에는 사용한 입력값·기준값 버전을 함께 출력한다.
