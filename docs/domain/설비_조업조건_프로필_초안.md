# 설비·조업 조건 프로필 초안

상태: 현장 검토 전 개발 기본안. 이 프로필은 설비를 제어하지 않으며, 수동 입력·비교군 분류·승인된 참고 계산의 근거만 관리한다.

## 1. 목적

재료와 강종만 같아도 전로 크기, 취련 방식, 랜스, 저취 교반, 노체 상태가 다르면 종점 결과와 비교 가능성이 달라질 수 있다. 차지마다 바뀌지 않는 설비 정보는 별도 프로필로 관리하고, 차지마다 실제로 바뀌는 값은 이벤트로 기록한다.

## 2. 값의 위치 구분

| 구분 | 값의 성격 | 예시 | 저장 위치 |
| --- | --- | --- | --- |
| 설비 프로필 | 장기간 유지되는 사양 | 전로 코드·호칭 용량·취련 방식·랜스 모델·저취 구성 | 설정 화면 |
| 조업 패턴 템플릿 | 현장에서 허용한 기본 단계 | 단계별 산소 유량/랜스 높이/교반가스의 이름·단위·입력 허용 범위 | 설정 화면 |
| 설비 상태 | 시간이 지나며 바뀌는 조건 | 랜스 교체 뒤 경과 차지 수, 내화물 보수 뒤 경과 차지 수, 특수 조업 상태 | 차지 시작 조건 또는 체크포인트 이벤트 |
| 실제 조업값 | 해당 차지에서 일어난 사실 | 실제 용선/스크랩량, 누적 산소량, 실제 랜스 높이 구간, 실제 투입 시각 | 차지 입력·이벤트 |

`용탕 크기`는 하나의 고정 설정값으로 취급하지 않는다. 전로의 호칭 용량·기준 욕심은 설비 프로필에 두고, 실제 장입량·실제 용탕량 추정값은 차지별 사실로 기록한다.

## 3. 설비·조업 조건 프로필 필드

### 3-1. 전로·용탕 조건

- 설비 프로필 코드·표시명·적용 기간
- 전로 방식: 상취 / 복합취련 / 현장 정의 방식
- 호칭 용량, 현장 승인 기준 욕심 또는 장입량 범위, 표준 단위
- 필요 시 욕심/용탕 깊이 구분 코드 또는 현장 승인 구간
- 적용 가능한 강종군·조업 조건 그룹

### 3-2. 상취 랜스 프로필

- 랜스 프로필 코드·모델명 또는 현장 허용 식별명
- 노즐 구성 설명(예: 노즐 수·형식)과 현장 승인 사양 문서 참조
- 허용 산소 유량 단위·단계 템플릿·기본 랜스 높이 단계 템플릿
- 설치/교체 기준일 또는 기준 차지 번호, 사용 차지 수 기록 사용 여부
- 랜스 상태 입력 방식: 정상 / 점검 필요 / 교체 후 / 현장 정의 상태

랜스 세부 치수·설계 정보가 보안 대상이면 공개하지 않고 승인된 코드와 단계 템플릿만 기록한다.

### 3-3. 저취·교반 프로필

- 저취 사용 여부와 가스 종류(N2, Ar, 현장 정의)
- 취입구/교반 구성의 식별 코드
- 허용 유량 단위·단계 템플릿
- 실제 교반가스 입력의 필수/선택 여부

### 3-4. 조업 패턴·상태 조건

- 취련 단계명과 단계별 입력 가능 항목: 산소 유량, 랜스 높이, 교반가스, 예정 시간
- 실제/계획값의 우선순위 및 계획값 사용 시 표시 문구
- 대기시간, 이전 차지 종료/출강 조건, 내화물 보수 후 경과 상태의 기록 사용 여부
- 재취련, 슬로핑, 설비 이상, 비정상 장입 등 비교군에서 제외하거나 별도 분류할 사유 목록

## 4. 다른 영향인자 추가 규칙

초기 목록에 없는 영향인자도 설정에서 추가할 수 있다. 단, 초기 버전에는 종점 예상식의 입력·계수 선택·계산 가능 조건 중 하나로 연결되는 인자만 추가한다. 단순 메모나 기록 전용 인자는 화면에 만들지 않는다.

| 필드 | 의미 |
| --- | --- |
| 인자 코드·표시명 | 중복되지 않는 이름 |
| 분류 | 설비 사양 / 설비 상태 / 조업 조건 / 측정 품질 / 환경 / 현장 정의 |
| 적용 범위 | 어떤 설비·강종군·조업 조건 그룹에 적용되는지 |
| 입력 방식·단위 | 선택 목록, 숫자, 구간, 예/아니오, 메모 중 선택 |
| 필수 수준 | 필수 / 선택 / 특정 계산 모듈에서만 필수 |
| 계산 연결 | 계산식의 변수명, 계수 선택 조건 또는 계산 가능 조건 |
| 예상 항목 | C / 온도 / P 등 어느 종점 예상에 영향을 주는지 |
| 출처·승인·버전 | 왜 기록하는지와 적용 상태 |

계산 연결이 비어 있으면 저장할 수 없다. 새 인자는 계산명세·가상 검증·그림자 검증을 거쳐야 해당 종점 수치예상에 쓸 수 있다.

## 5. 초기 버전 우선순위

| 우선순위 | 인자 | v0 처리 |
| --- | --- | --- |
| A | 전로 코드/방식, 호칭 용량 또는 장입량 구간, 실제 장입량, 산소량·취련 시간, 실제 부원료, 채택 샘플·온도 | 기본 프로필 또는 차지 입력 |
| B | 랜스 코드/상태, 랜스 높이 구간, 저취 교반가스 구간, 대기시간, 내화물/랜스 경과 상태, 재취련·비정상 조업 | 선택 입력·비교군 분류 |
| C | 배가스, 슬래그 조성, 냉각수, 음향, 기상 등 연속·특수 계측 | 초기 버전 UI에서 제외. 향후 해당 값을 쓰는 계산식과 입력 경로가 승인될 때만 추가 |

## 6. 안전 규칙

- 프로필은 산소 유량·랜스 높이·교반가스의 **설비 제어값을 전송하거나 변경하지 않는다.**
- 입력 허용 범위는 데이터 오입력 확인용이며, 조업 허용 범위·안전 인터록을 대신하지 않는다.
- 사용 중인 설비 프로필·조업 패턴·영향인자 버전은 차지에 함께 저장한다.
- 프로필이 바뀌면 기존 차지를 덮어쓰지 않고 새 버전으로 만들며, 이력 비교군을 분리하거나 재검증 대상으로 표시한다.

관련 계산 원칙은 [종점 참고 계산식](종점참고계산식_초안.md)을 따른다.
