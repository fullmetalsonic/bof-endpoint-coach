# 시간 경과형 참고 예상 입력 규칙 초안

상태: 계산식 미정 전의 입력·시간·표시 계약. PLC/HMI와 연결하지 않고 취련사가 수동으로 입력한 사건과 PC 로컬 시간을 사용한다.

## 1. 이 기능이 하는 일

선택된 차지의 취련 시작 시각, 조업 패턴/풍량, 투입, 샘플 분석값을 시간축에 놓고, PC 시간이 흐르거나 입력이 바뀔 때 **참고 종점 예상 범위**를 다시 계산한다.

이것은 설비의 실제 풍량·산소량을 자동 수신하는 실시간 제어가 아니다. 화면에 보이는 값은 항상 `수동 입력 기준` 또는 `계획값 보완 포함`으로 표시한다.

## 2. 두 종류의 입력

| 종류 | 예 | 사용 원칙 |
| --- | --- | --- |
| 실제 사건 | 취련 시작, 실제 풍량 변경, 실제 누적 산소량, 부원료 투입, 샘플 채취, 분석 결과, 재취련 | 해당 사건이 일어난 실제 시각으로 기록. 계산에서 우선 사용 |
| 계획 사건 | 예정 풍량 구간, 예정 투입, 계획 조업 패턴 | 실제 사건이 아직 없는 구간을 보완. 화면에 `계획값 포함`으로 표시 |

같은 시간 구간에 실제와 계획이 겹치면 실제 입력을 우선한다. 계획값은 삭제하지 않고 `실제값으로 대체됨` 상태로 남긴다.

## 3. 시간 입력 규칙

| 시각 | 기본값 | 수정 가능 여부 | 용도 |
| --- | --- | --- | --- |
| 발생 시각 (`occurred_at`) | PC의 현재 현지 시각 | 가능 | 실제 사건 또는 계획이 효력을 갖는 시각 |
| 기록 시각 (`recorded_at`) | 저장 버튼을 누른 시각 | 불가 | 언제 입력했는지 보존 |
| 계산 기준 시각 (`calculated_at`) | PC의 현재 현지 시각 | 불가 | 예상값이 계산된 기준 시각 |

- 샘플 채취·부원료 투입·풍량 변경 입력창의 발생 시각은 현재 시각으로 미리 채운다.
- 사용자는 실제 발생 시각이 다르면 직접 바꿔 입력할 수 있다.
- 과거 시각, 입력 순서 역전, 같은 시각의 여러 이벤트는 허용하되 `시간 순서 확인`과 사유를 남긴다.
- 계획 사건은 현재보다 미래 시각을 허용하며, `계획`이라는 상태를 반드시 표시한다.

## 4. 조업 패턴·풍량 입력

`취련 체크포인트` 입력 안에 아래 하위 항목을 둔다. 별도의 자동 설비 제어 화면은 만들지 않는다.

| 항목 | 필수 여부 | 설명 |
| --- | --- | --- |
| 패턴 구분 | 필수 | 실제 / 계획 |
| 적용 시작 시각 | 필수 | 풍량 또는 패턴이 효력을 갖는 시각. 기본은 현재 시각 |
| 적용 종료 시각 | 계획이면 권장 | 다음 패턴 전까지의 구간. 비워 두면 다음 변경 또는 현재까지 |
| 풍량/산소 유량 | 현장에서 승인한 항목일 때 | 원본값·원본 단위·환산값·표준 단위를 함께 저장 |
| 실제 누적 산소량 | 선택 | 수동으로 확인 가능한 경우, 시간 적분 추정보다 우선 |
| 패턴명·메모 | 선택 | 현장 표기명과 특이 사항 |

풍량·산소량의 단위, 허용 단위, 환산식은 승인된 단위 규칙에 없는 경우 계산에 사용하지 않는다.

## 5. 시간 경과에 따른 계산 흐름

```text
현재 작업 대상 차지 선택
→ 취련 시작 시각부터 계산 기준 시각까지의 타임라인 구성
→ 실제 풍량/누적 산소량·투입·재취련 이벤트 우선 반영
→ 비어 있는 시간 구간은 계획 패턴이 있을 때만 보완
→ 가장 최근 채택 분석값과 그 이후 이벤트 연결
→ 승인된 이력/계산 규칙으로 종점 참고 범위 재계산
→ 실제·계획·분석 시점·계산 기준 시각을 함께 표시
```

- 차지가 `진행 중`이고 취련 시작 시각이 있을 때만, 화면은 10초마다 로컬 시간 기준으로 다시 계산한다.
- 사용자가 풍량·투입·샘플·분석·재취련·발생 시각을 저장하면 즉시 다시 계산한다.
- 차지가 출강 완료·취소 상태가 되면 시간 자동 갱신을 멈추고 마지막 계산 결과를 이력으로 보존한다.
- 계산식 또는 이력 기반 규칙이 승인되지 않았거나 필수 입력이 부족하면 숫자를 만들지 않고 `예상 계산 불가: 사유`를 표시한다.

## 6. 예상값의 표시 구분

| 표시 | 뜻 |
| --- | --- |
| 실제 분석값 | 채택된 샘플 분석 결과. 채취 시각과 결과 입력 시각을 함께 표시 |
| 현재 시점 추정 | 마지막 분석과 이후의 실제 사건을 기준 시각까지 전개한 참고값 |
| 종점 참고 예상 | 현재 입력과 승인된 이력/계산 규칙으로 계산한 종점 범위 |
| 계획값 포함 | 계산 구간 일부가 실제 입력이 아니라 계획 풍량/패턴에 의존 |
| 예상 중지 | 분석이 오래됐거나 필수 입력·승인 규칙이 없어 계산하지 않음 |

예상값은 단일 확정값보다 범위와 `참고` 문구를 우선한다. 목표 범위와 실제 분석값이 과거 이력·계획값 때문에 자동으로 바뀌는 일은 없다.

## 7. 화면 표시 원칙

- 화면 상단에 `계산 기준 시각 HH:MM:SS (로컬 시간)`과 `마지막 수동 입력 HH:MM:SS`를 나란히 표시한다.
- 품질 막대에는 실제 분석값(채워진 원), 현재 시점 추정/종점 참고 예상(빈 원)을 구분한다.
- 실제 사건만 사용했으면 `실제 입력 기준`, 계획을 포함했으면 `계획값 포함`, 이력 기반이면 `이력 참고`를 표시한다.
- 로컬 시간만 흐르며 자동 갱신 중인 상태를 `PC 로컬 시간 기준 갱신`으로 표시한다. `실시간 설비 데이터`라고 표현하지 않는다.
- 선택되지 않은 다른 차지는 계산하지 않거나 목록에 계산값을 노출하지 않는다.

## 8. 예시 흐름

```text
09:00  취련 시작 입력 (기본 현재 시각, 필요하면 수정)
09:05  실제 풍량 변경 입력 (발생 시각 기본 09:05, 수정 가능)
09:12  부원료 투입 입력 (실제 투입 시각 기록)
09:18  샘플 채취 입력
09:24  분석 결과 입력 → 채취 시각 09:18과 연결
09:24~ 시간 경과 → 10초마다 현재 시점/종점 참고 범위 갱신
09:30  실제 누적 산소량 입력 → 계획 기반 부분을 실제 입력으로 대체, 즉시 재계산
```

## 9. 활성화 조건과 한계

- 이력 기반 참고 예상은 `이력기반_참고예상_활성화기준_초안.md`의 데이터 품질 관문과 현장 검토를 통과한 뒤에만 활성화한다.
- 물질·열수지 계산을 추가하는 경우에도, 입력·출력·단위·반올림·제외 조건·검증 예시는 별도 계산 명세로 승인해야 한다.
- 이 규칙은 입력과 시간 흐름을 정의할 뿐, 실제 풍량 변화가 종점 성분에 미치는 공정 계수나 목표 수치를 정하지 않는다.
