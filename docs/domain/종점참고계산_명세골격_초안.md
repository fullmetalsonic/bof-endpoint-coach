# 종점 참고 계산 명세 골격 초안

상태: 설계 골격. 실제 계수·수식·강종별 허용값은 현장 승인 전까지 비어 있다.

## 1. 목적

수동 입력한 차지·조업·샘플 이력을 이용해, 계산 가능한 범위와 종점 참고값의 근거를 투명하게 보여 준다. 자동 제어, 투입 지시, 출강 확정은 하지 않는다.

## 2. 계산 모듈과 활성 조건

| 모듈 | 계산 시점 | 필수 입력 | 출력 | 비활성 사유 예시 |
| --- | --- | --- | --- | --- |
| 입력·단위 점검 | 모든 입력 직후 | 원본값·원본단위·기준 버전 | 환산값, 오류/누락 | 승인되지 않은 단위 변환 |
| 정적 기준 계산 | 취련 전 또는 초기 | 강종 기준, 차지량, 원료/부원료 조성·질량, 온도, 승인 계수 | 계산 가능 여부, 근거 목록, 승인된 경우 참고 범위 | 조성·수율·열수지 계수 없음 |
| 반동적 참고 보정 | 채택 샘플 또는 실제 이벤트 후 | 채택 분석/온도, 이후 실제 산소·투입·시각, 승인 계수 | 참고 범위, 실제/계획 사용 표시 | 채택 샘플 또는 보정 계수 없음 |
| 이력 보정 | 이력 기준 관문·승인 후 | 비교군, 승인 규칙 버전, 현재 입력 | 이력 기반 참고 예상 범위 | 유효 이력·승인 규칙 부족 |

## 3. 입력 우선순위

1. 채택된 실제 분석값·실제 발생 이벤트
2. 승인된 재료·강종 기준 버전
3. 계획 이벤트
4. 승인된 이력 참고값

같은 항목에서 우선순위가 낮은 값은 삭제하지 않고, 계산에 쓰지 않은 이유와 함께 남긴다.

## 4. 초기 기준선

`초기 기준선`은 목표 범위가 아니다. 후보 계산식의 성능을 비교하기 위한 값이다.

- 기준선 A: 같은 강종군·조업 조건군 완료 차지의 종점 중앙값·분포
- 기준선 B: 현재 차지의 최신 채택 샘플값

후보 계산식은 항목별 절대오차·편향·허용범위 적중률·예상 불가율에서 승인된 기준선보다 나아야 그림자 예상 후보가 된다.

## 5. 수치 출력의 안전 규칙

- 승인된 계수·기준 버전·필수 입력이 모두 없으면 숫자를 추정하지 않고 사유를 표시한다.
- 수치가 출력되면 `참고 예상`, 계산 기준 시각, 실제/계획 입력 사용 여부, 계산/이력 규칙 버전을 함께 표시한다.
- 목표 범위는 설정된 강종 기준값으로만 판단하며, 예측값 또는 이력으로 자동 변경하지 않는다.
- 수치 예상의 반올림 자릿수·단위는 품질 항목별 계산명세에 명시한다. 화면에서만 반올림하고 원본 계산값은 보존한다.

## 6. 다음에 채울 계산명세

계산 모듈별로 아래 내용을 별도 문서로 확정한다.

1. 입출력 항목·표준단위·발생 시각 기준
2. 식 또는 테이블 규칙과 계수의 출처·적용 강종군
3. 필수/선택 입력과 예상 불가 조건
4. 반올림·범위 산정·불확실성 표시
5. 가상 시험 사례와 승인된 손계산 결과
6. 그림자 검증의 허용오차·편향·적중률 합격 기준
