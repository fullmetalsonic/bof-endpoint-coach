# 종점 참고 계산식 초안

상태: 수치 종점 참고예상을 위한 계산 골격. 이 문서는 계수값을 제공하지 않으며, 승인된 계수가 없는 식은 화면에서 실행하지 않는다.

## 1. 초기 버전의 수치 출력 범위

초기 버전의 목표는 기록 자체가 아니라 **종점 C와 종점 온도의 수치 참고예상**이다.

| 항목 | 초기 수치예상 | 이유 |
| --- | --- | --- |
| 종점 C | 제공 대상 | 산소 투입·초기 C·중간 샘플·잔여 취련 조건과 직접 연결 |
| 종점 온도 | 제공 대상 | 초기 온도·반응 열·스크랩/냉각재·부원료·중간 온도와 연결 |
| 종점 P | 조건부 | 슬래그/탈인 관련 현장 계수·입력이 승인된 경우에만 활성화 |
| Mn, Si, S 등 | 조건부 | 해당 원소의 승인된 수지/보정식이 있는 강종군에만 활성화 |

목표 범위는 강종 설정값이고, 아래 식은 그 목표에 도달할 **예상 종점값**을 계산하는 별도 기능이다.

## 2. 공통 계산 원칙

- 질량은 표준 단위 `kg`, 성분은 질량분율 또는 `wt%`, 산소는 `Nm³`와 환산된 산소 질량을 함께 보관한다.
- 실제 입력은 계획 입력보다 우선한다. 실제 누적 산소량이 없을 때만 계획 산소량을 보완값으로 쓴다.
- 각 항목은 `정적 계산`과 `샘플 이후 보정` 중 계산 가능한 가장 최신 모듈을 쓴다.
- 계수·프로필·필수 입력이 하나라도 미승인이면 해당 항목은 수치를 내지 않고 `예상 계산 불가: 사유`를 표시한다.
- 계산 결과에는 중심값뿐 아니라 승인된 불확실성 범위와 계산 기준 시각·프로필·계수 버전을 붙인다.

## 3. 종점 C 계산 골격

### 3-1. 정적 기준 계산

초기 탄소량과 유효 산소량으로 종점 탄소를 계산한다.

```text
m_C,0 = Σ(장입 재료 질량 × 재료별 C 질량분율)
O_eff = O_투입 × η_O − O_기타반응보정
m_C,예상 = max(0, m_C,0 − β_C × O_eff)
C_종점,예상(%) = 100 × m_C,예상 / M_용강,예상
```

| 기호 | 의미 | 입력/설정 위치 |
| --- | --- | --- |
| `m_C,0` | 장입물에 포함된 초기 탄소 질량 | 차지 재료·조성 입력 |
| `O_투입` | 실제 또는 계획 산소 투입량 | 취련 체크포인트 |
| `η_O` | 산소 유효율 | 설비/강종별 승인 계수 |
| `O_기타반응보정` | C 이외 반응·슬래그·손실에 쓰인 산소 보정 | 승인된 물질수지 계수 |
| `β_C` | 유효 산소당 탄소 제거 보정계수 | 승인된 C 수지 계수 |
| `M_용강,예상` | 종점 예상 용강 질량 | 장입량·재료/슬래그 손실 계수 |

이 식은 반응 전체를 단순화한 계산 골격이다. `η_O`, `O_기타반응보정`, `β_C`, 용강 질량 보정은 전로·강종·조업 조건별 승인값이 필요하다.

### 3-2. 샘플 이후 반동적 보정

채택된 중간 샘플이 있으면 초기 장입 기반 계산보다 샘플을 우선한다.

```text
O_잔여 = O_종료기준 − O_현재누적
ΔC_잔여 = γ_C × O_잔여 / M_용강,예상
C_종점,예상(%) = max(0, C_채택샘플 − 100 × ΔC_잔여)
```

| 기호 | 의미 |
| --- | --- |
| `O_종료기준` | 해당 강종·설비 프로필의 승인된 목표 산소량 또는 승인된 종료 기준 |
| `O_현재누적` | 현재까지 실제 누적 산소량. 없으면 계획 사용 표시 |
| `γ_C` | 샘플 이후 잔여 산소의 탈탄 보정계수 |
| `C_채택샘플` | 명시적으로 채택된 최신 샘플의 실제 C 값 |

샘플 이후 부원료 투입·재취련·랜스/교반 조건이 보정식에 쓰인다면, 각 항목은 별도의 승인된 보정항으로 명시한다. 이름만 있는 영향인자를 암묵적으로 더하지 않는다.

## 4. 종점 온도 계산 골격

### 4-1. 정적 기준 계산

```text
Q_net = Q_산화반응 − Q_스크랩/냉각재 − Q_부원료 − Q_열손실
T_종점,예상 = T_기준 + Q_net / (M_용강,예상 × Cp_eq)
```

| 기호 | 의미 | 입력/설정 위치 |
| --- | --- | --- |
| `T_기준` | 초기 용선 온도 또는 승인된 기준 온도 | 차지 입력 |
| `Q_산화반응` | C·Si·Mn·P 등 반응열의 승인된 계산값 | 재료 조성·반응열 계수 |
| `Q_스크랩/냉각재` | 용해/승온에 쓰이는 열 보정 | 실제 투입량·재료 계수 |
| `Q_부원료` | 플럭스 등 부원료 열영향 | 실제 투입량·재료 계수 |
| `Q_열손실` | 대기시간·설비 상태·취련 시간 등을 반영한 손실 | 설비 프로필·승인 계수 |
| `Cp_eq` | 등가 열용량 | 설비/강종별 승인 계수 |

### 4-2. 샘플 이후 반동적 보정

```text
T_종점,예상 = T_채택샘플
              + κ_O × O_잔여
              + Σ(κ_j × 샘플 이후 실제 투입량_j)
              − κ_loss × 잔여시간
              + κ_profile
```

`κ_O`, `κ_j`, `κ_loss`, `κ_profile`은 각각 잔여 산소, 샘플 이후 재료, 시간 열손실, 설비/조업 조건의 영향계수다. 부호와 단위는 한 계산명세 안에서 고정하고, 해당 프로필에 승인된 경우에만 쓴다.

## 5. 설비·조업 조건의 계산 연결

전로 용량, 랜스 사양, 랜스 높이, 저취 교반가스 같은 값은 모두 화면에 수집하는 것이 목적이 아니다. 아래처럼 **식의 계수 선택 또는 명시적 보정항**으로 연결될 때만 초기 계산에 포함한다.

| 영향인자 | 계산에서의 역할 | 초기 처리 |
| --- | --- | --- |
| 전로 호칭 용량·장입량 구간 | `M_용강,예상`, 열손실/산소 효율 계수 선택 | 프로필 + 실제 장입량 |
| 랜스 모델·상태 | `η_O`, `γ_C`, `κ_profile` 계수 선택 | 랜스 프로필 |
| 실제 랜스 높이/유량 구간 | 산소 유효율·잔여 탈탄 보정항 | 실제 체크포인트 |
| 저취 교반가스 | 산소/탈탄/온도 보정 계수 선택 또는 보정항 | 프로필 + 실제 구간 |
| 대기시간·내화물/랜스 경과 상태 | `Q_열손실`, 프로필 보정 | 차지 조건 |
| 배가스·슬래그 연속 계측 | 별도 동적식의 입력 | v0 초기 계산에서 제외 |

## 6. 계산 실행 관문

각 예상 항목은 아래 순서로 판정한다.

```text
강종 목표·설비 프로필·재료 조성·계수 승인 확인
→ 필수 실제 입력 확인
→ 정적 계산 또는 샘플 보정 계산 선택
→ 단위/범위/계산 시각 검증
→ 수치 중심값 + 불확실성 범위 출력
```

종점 C와 온도를 같이 계산하더라도 둘 중 하나의 계수가 없으면 가능한 항목만 별도로 표시한다. `C 계산 가능 / 온도 계산 불가: 열손실 계수 미승인`처럼 원인을 분리한다.

## 7. 검증과 확장

- 가상 차지에서는 위 식의 각 항을 공개하지 않는 가상 계수로 채우고 손계산 결과와 대조한다.
- 실제 차지에서는 계산 시점의 입력 스냅샷과 예상값을 고정해 종점 실제값과 비교한다.
- P·Mn·Si·S 등은 원소별 수지 또는 보정식, 필수 입력, 검증 기준이 완성될 때만 활성화한다.
- 이력 기반 보정은 위 C/온도 계산의 잔차를 보정하는 후속 모듈이며, 계산식 자체를 자동으로 바꾸지 않는다.
