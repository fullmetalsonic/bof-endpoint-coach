# 종점 참고 계산식 초안

상태: `BOF-REF-CALC 0.2.0`에 구현된 공개 문헌 시나리오 기반 종점 참고예상 명세. 실제 BOF 차지 정확도와 현장 조업 적합성은 아직 검증되지 않았다.

## 0. 문헌계수 감사에 따른 정정

기존 v0.1.0 합성 계수식은 폐기하고, 공개 문헌의 물질·열수지와 저·기준·고 시나리오를 계산 가능한 기본선으로 구현했다.

- Nm³는 기준 온도·압력·산소 순도와 함께 저장한다.
- C 계산은 Si·Mn·P·Fe 산화, 미사용 산소, CO 후연소, 승인된 외부 산소원을 분리한다.
- `0.75 kg-C/kg-O₂`는 CO 생성의 이론 화학량론이며 실제 탈탄효율 기본값이 아니다.
- 온도 계산은 원소별 반응열, 재료별 현열·잠열, 슬래그·배가스, 열손실을 분리한다.
- PCR 0.10~0.22, 열손실 1.3~5.9%, 종점 슬래그 FeO 15~25 wt%는 공개 연구의 조건부 저·기준·고 시나리오다. 현장 승인값이나 통계적 신뢰구간으로 표시하지 않는다.
- 샘플 이후에는 임의의 탈탄·온도 계수를 쓰지 않고, 샘플 시점부터 계획 종점까지 문헌 모델이 계산한 변화량만 실제 샘플에 더한다.
- 계산값 우선순위는 `현장 승인 수정값 → 사용자 수정값(미승인 표시) → 보존된 문헌 원본값`이다.

상세 근거와 현재 DEMO 계수 판정은 [종점계수 문헌 근거 매트릭스](../research/종점계수_문헌근거매트릭스_2026-08-22.md)에서 관리한다.

## 1. 초기 버전의 수치 출력 범위

초기 버전의 목표는 기록 자체가 아니라 **종점 C와 종점 온도의 수치 참고예상**이다.

| 항목 | 초기 수치예상 | 이유 |
| --- | --- | --- |
| 종점 C | 제공 대상 | 산소 투입·초기 C·중간 샘플·잔여 취련 조건과 직접 연결 |
| 종점 온도 | 제공 대상 | 초기 온도·반응 열·스크랩/냉각재·부원료·중간 온도와 연결 |
| 종점 P | 조건부 | 슬래그/탈인 관련 현장 계수·입력이 승인된 경우에만 활성화 |
| Mn, Si, S 등 | 조건부 | 해당 원소의 승인된 수지/보정식이 있는 강종군에만 활성화 |

목표 범위는 강종 설정값이고, 아래 식은 그 목표에 도달할 **예상 종점값**을 계산하는 별도 기능이다.

## 2. 공통 계산 원칙

- 질량은 표준 단위 `kg`, 성분은 질량분율 또는 `wt%`, 산소는 `Nm³`와 환산된 산소 질량을 함께 보관한다.
- 계획 총 산소량은 종점 계산점으로 사용하고, 현재 실제 누적 산소량은 잔여 산소·잔여시간에 사용한다.
- 채택 샘플에 당시 누적 산소 스냅샷이 있으면 `샘플 기준 문헌 변화량 보정`, 없으면 `문헌 정적 계산`을 쓴다.
- 필수 입력이나 프로필이 없으면 C와 온도를 각각 `예상 계산 불가: 사유`로 처리한다.
- 계산 결과에는 기준 시나리오 중심값, 문헌 저·고 시나리오 범위, 계산 시각·식 버전·프로필·적용 근거·수정 필드를 붙인다.
- 문헌 저·고 범위는 정확도나 신뢰구간이 아니며, 실제 오차 범위는 완료 차지 검증 뒤 별도로 산정한다.

## 3. 종점 C 계산 골격

### 3-1. 정적 기준 계산

초기 탄소량과 유효 산소량으로 종점 탄소를 계산한다.

```text
m_C,0 = Σ(장입 재료 질량 × 재료별 C 질량분율)
O_C관련 = O_랜스 + O_외부공급
           − O_Si − O_Mn − O_P − O_Fe
           − O_미사용
m_C,예상 = max(0, m_C,0 − β_C(PCR) × O_C관련)
C_종점,예상(%) = 100 × m_C,예상 / M_용강,예상
```

| 기호 | 의미 | 입력/설정 위치 |
| --- | --- | --- |
| `m_C,0` | 장입물에 포함된 초기 탄소 질량 | 차지 재료·조성 입력 |
| `O_랜스` | 실제 또는 계획 산소 투입량을 기준조건으로 환산한 O₂ 질량 | 취련 체크포인트·단위 설정 |
| `O_외부공급` | 광석·산화물 냉각재 중 승인된 반응경로가 공급하는 유효 산소 | 재료 조성·실제 투입량·반응 가정 |
| `O_Si`~`O_Fe` | 원소별 산화에 쓰이는 산소 | 초기/종점 성분·슬래그/철손실 가정 |
| `O_미사용` | 배가스로 나가는 미사용 산소 | 현장 계측·승인 시나리오 |
| `β_C(PCR)` | CO/CO₂ 분율에서 계산한 탄소/O₂ 화학량론 | 물리식 + PCR |
| `M_용강,예상` | 종점 예상 용강 질량 | 장입량·재료/슬래그 손실 계수 |

이 식도 정적 근사다. 실제 원소 산화량, 미사용 산소, PCR, 용강 질량 보정은 전로·강종·조업 조건별 입력이나 승인 시나리오가 필요하다. 한 항이라도 결과를 지배하는데 값이 없으면 `시나리오 입력 필요`로 처리한다.

위 식은 `PCR 포함 방식`이다. 대안으로 CO 후연소 산소를 명시적으로 빼는 경우에는 `β_C(PCR)` 대신 CO 화학량론 계수만 사용한다. 두 방식을 한 계산에서 섞지 않는다. PCR의 분자·분모와 공기 유입 보정 기준도 프로필에 고정한다.

### 3-2. 샘플 기준 문헌 변화량 보정

채택된 중간 샘플과 샘플 시점 누적 산소 스냅샷이 있으면 아래처럼 문헌 모델의 변화량만 적용한다.

```text
C_종점,예상 = max(0,
  C_채택샘플
  + C_문헌모델(O_계획종점)
  − C_문헌모델(O_샘플시점))
```

| 기호 | 의미 |
| --- | --- |
| `O_계획종점` | 차지에 입력한 계획 총 산소량 |
| `O_샘플시점` | 분석 입력 때 함께 고정한 실제 누적 산소량 |
| `C_문헌모델(O)` | 같은 장입값·같은 시나리오에서 산소량만 O로 계산한 정적 C |
| `C_채택샘플` | 명시적으로 채택된 최신 샘플의 실제 C 값 |

샘플 시점 누적 산소가 없거나 계획 총 산소보다 크면 샘플 앵커를 쓰지 않는다. 샘플 이후 부원료·재취련·랜스/교반 영향은 아직 별도 동적 보정항으로 구현하지 않았으므로, 입력 이력은 보존하되 암묵적으로 계산에 더하지 않는다.

## 4. 종점 온도 계산 골격

### 4-1. 구현된 축약 정적 열수지

```text
Q_입력 = Q_용선현열 + Q_C/Si/Mn/P/Fe 산화반응
Q_손실 = 열손실률 × Q_입력
Q_출력(T) = Q_용강(T) + Q_슬래그(T+ΔT) + Q_CO/CO2 배가스(T_gas)
Q_입력 − Q_손실 = Q_출력(T_종점)
```

| 기호 | 의미 | 입력/설정 위치 |
| --- | --- | --- |
| `Q_용선현열` | 용선 질량·온도와 문헌 Fe 엔탈피식 | 차지 입력 + S44 |
| `Q_산화반응` | C→CO/CO₂, Si, Mn, P, Fe 산화량과 문헌 반응열 | 물질수지 + S44 |
| `Q_용강` | 예상 용강 질량과 문헌 Fe 엔탈피식 | 물질수지 + S44 |
| `Q_슬래그` | CaO 등가 플럭스·SiO₂·MnO·P₂O₅·FeO의 문헌 엔탈피식 | 물질수지 + S44 |
| `Q_배가스` | PCR로 나눈 CO·CO₂ 질량과 문헌 엔탈피식 | 물질수지 + S44 |
| `Q_손실` | 문헌 저·기준·고 열손실률 시나리오 | S12·S44 |

### 4-2. 샘플 기준 온도 변화량 보정

```text
T_종점,예상 = T_채택샘플
              + T_문헌모델(O_계획종점)
              − T_문헌모델(O_샘플시점)
```

이 방식은 근거 없는 `κ` 계수를 만들지 않는 대신, 문헌 열수지의 잔차를 그대로 가진다. 수분·석회석 분해·광석/냉각재·내화물·저취가스·배가스 실측·조업시간별 손실은 아직 미반영이므로 현장 승인 전 참고예상으로만 사용한다.

## 5. 설비·조업 조건의 계산 연결

전로 용량, 랜스 사양, 랜스 높이, 저취 교반가스 같은 값은 모두 화면에 수집하는 것이 목적이 아니다. 아래처럼 **식의 계수 선택 또는 명시적 보정항**으로 연결될 때만 초기 계산에 포함한다.

| 영향인자 | 계산에서의 역할 | 초기 처리 |
| --- | --- | --- |
| 전로 호칭 용량·장입량 구간 | `M_용강,예상`, 열손실/산소수지 시나리오 선택 | 프로필 + 실제 장입량 |
| 랜스 모델·상태 | 미사용 산소/PCR 시나리오, `γ_C`, `κ_profile` 계수 선택 | 랜스 프로필 |
| 실제 랜스 높이/유량 구간 | 산소 배분·잔여 탈탄의 현장 보정항 | 실제 체크포인트 |
| 저취 교반가스 | 산소/탈탄/온도 보정 계수 선택 또는 보정항 | 프로필 + 실제 구간 |
| 대기시간·내화물/랜스 경과 상태 | `Q_열손실`, 프로필 보정 | 차지 조건 |
| 배가스·슬래그 연속 계측 | 별도 동적식의 입력 | v0 초기 계산에서 제외 |

## 6. 계산 실행 관문

각 예상 항목은 아래 순서로 판정한다.

```text
강종 목표·설비 프로필·문헌 프로필 확인
→ 필수 실제 입력 확인
→ 현장 승인 수정값 / 사용자 수정값 / 문헌값 병합
→ 정적 계산 또는 샘플 변화량 보정 선택
→ 단위/범위/계산 시각 검증
→ 기준 시나리오값 + 문헌 저·고 시나리오 범위 + 근거 상태 출력
```

종점 C와 온도를 같이 계산하더라도 둘 중 하나의 필수 입력이나 계산 결과가 없으면 가능한 항목만 별도로 표시한다. `C 계산 가능 / 온도 계산 불가: 용선 온도 누락`처럼 원인을 분리한다.

## 7. 검증과 확장

- 가상 차지에서는 A등급 화학량론과 명시적인 B등급 문헌 시나리오 또는 D등급 합성값을 구분하고 손계산 결과와 대조한다.
- 실제 차지에서는 계산 시점의 입력 스냅샷과 예상값을 고정해 종점 실제값과 비교한다.
- P·Mn·Si·S 등은 원소별 수지 또는 보정식, 필수 입력, 검증 기준이 완성될 때만 활성화한다.
- 이력 기반 보정은 위 C/온도 계산의 잔차를 보정하는 후속 모듈이며, 계산식 자체를 자동으로 바꾸지 않는다.
