# 취련 격외 방지용 관리포인트 초안

## 목적과 경계

이 문서는 전로 취련사가 차지 시작부터 출강까지 확인해야 할 **관리 게이트(control point)** 를 정의한다. 여기서 `격외`는 목표 성분·온도·출강 조건이 범위를 벗어나 재취련, 과다 보정, 후공정 부담, 품질 저하가 생기는 상태를 뜻한다.

이것은 특정 제철소의 조업 표준이나 자동 제어 로직이 아니다. 각 게이트의 목표값·경고 범위·중지 기준은 회사 승인값을 설정 화면에 넣어야 한다.

## 전체 흐름

```text
G0 데이터/설비 준비
  → G1 장입·열/물질수지 계획
  → G2 초기 취련·슬래그 형성 확인
  → G3 중기 취련·탈탄/온도 추세 확인
  → G4 중간 샘플·예측 보정
  → G5 종점 샘플·출강 가능성 판정
  → G6 재취련/보정 판단
  → G7 출강 직전 확인·출강 이력
  → G8 결과 확정·다음 차지 보정
```

각 게이트는 `입력값 → 계산/비교 → 상태 표시 → 작업자 확인/기록` 순서로 작동한다. 이 도구가 설비 동작을 지시하거나 안전 인터록을 대체하지 않는다.

## G0. 데이터·설비 준비

| 구분 | 관리 포인트 |
| --- | --- |
| 확인값 | 차지 ID, 강종군, 목표 성분/온도/출강량, 적용 기준값 버전, 설비/조업 조건 그룹 |
| 계산/검사 | 필수 목표값 누락 여부, 단위·분석 기준 일치 여부, 이전 차지의 남은 데이터가 새 차지에 섞이지 않는지 |
| 경고 예 | `목표 P 미등록`, `온도 범위 없음`, `재료 기준값 만료`, `단위 확인 필요` |
| 기록 결과 | 시작 시각, 기준값 버전, 누락/예외 사유 |

**격외 예방 의미:** 목표와 기준이 불명확한 상태에서 계산을 시작하는 것을 막는다.

## G1. 장입·초기 계획

| 구분 | 관리 포인트 |
| --- | --- |
| 확인값 | 용선/스크랩/철원/Flux/냉각재의 계획·실제 투입량, 대표 조성 또는 로트값, 초기 용선 온도·성분 |
| 계산/비교 | 총 장입량, 목표 출강량 대비 질량 차이, 성분 유입량, 열수지 참고값, 부원료 유효성분 기준 비교 |
| 경고 예 | `실제 장입량 미입력`, `스크랩 로트 미확인`, `Flux 성분 기준 없음`, `계획-실제 차이 확인` |
| 기록 결과 | 재료·중량·단위·투입 시각·기준값/로트 버전 |

**격외 예방 의미:** 출발점의 질량·성분·열 조건이 틀리면 이후의 산소량·부원료·온도 판단도 함께 틀어진다.

## G2. 초기 취련·슬래그 형성 구간

| 구분 | 관리 포인트 |
| --- | --- |
| 확인값 | 취련 시작 시각, 초기 부원료 투입 완료 여부, 초기 조업 단계명, 관찰 가능한 이상 이벤트 |
| 계산/비교 | 계획 대비 경과 시간, 초기 투입 누락, 초기 Si/P와 등록된 Flux 계획의 연결 여부 |
| 경고 예 | `초기 Flux 투입 이력 없음`, `초기 분석값 오래됨`, `이상 이벤트 기록 필요` |
| 기록 결과 | 단계 시작/종료 시각, 추가 투입, 특수 조업·관찰 메모 |

**격외 예방 의미:** 공개 BOF 교육 자료상 초기 슬래그 형성과 온도 진행은 이후 탈인·정련 조건과 연결된다. v0은 이를 수치 제어하지 않고, 필요한 투입·시간 이력이 빠지지 않게 한다.

## G3. 중기 취련·탈탄/온도 추세 구간

| 구분 | 관리 포인트 |
| --- | --- |
| 확인값 | 취련 경과 시간, 사용자가 확인 가능한 누적 산소량, 중간 온도/샘플, 단계명, 추가 투입·이상 이벤트 |
| 계산/비교 | 최신 분석의 채취 시각 이후 경과 시간, 이전 샘플 대비 C·온도 변화, 목표까지의 잔여 차이, 데이터 신선도 |
| 경고 예 | `최신 분석이 오래됨`, `누적 산소량 단위 불명`, `중간 샘플 없이 종점 접근`, `온도 추세 확인 필요` |
| 기록 결과 | 중간 샘플·분석·추가 투입, 실제/계획 차이 |

**격외 예방 의미:** 공정은 시간에 따라 변하므로, 분석값을 현재값처럼 오인하지 않고 채취 시점 기준으로 해석한다.

## G4. 중간 샘플·예측 보정 게이트

| 구분 | 관리 포인트 |
| --- | --- |
| 확인값 | 샘플 ID, 채취 시각, 결과 수신 시각, C·온도와 강종별 관리 성분, 당시 투입/취련 이벤트 |
| 계산/비교 | 목표 대비 차이, 샘플 수신 지연, 기준값 기반 참고 물질/열수지 재계산, 데이터 신뢰도 |
| 상태 예 | `목표 범위 접근`, `재샘플 검토`, `온도 보정 검토`, `분석값/단위 확인 필요` |
| 기록 결과 | 참고 계산 결과, 작업자 수정값, 수정/미채택 사유 |

**격외 예방 의미:** 이 게이트가 v0의 핵심이다. 자동 종점 예측 대신, 새 분석값으로 기준 계산을 다시 하고 판단 근거를 남긴다.

## G5. 종점 샘플·출강 가능성 게이트

| 구분 | 관리 포인트 |
| --- | --- |
| 확인값 | 최신 샘플의 채취·수신 시각, 종점 성분·온도, 목표 범위, 이후 진행된 이벤트, 후공정 보정 가능 여부 |
| 계산/비교 | 목표 범위 충족 여부, 샘플 이후 경과 시간, 최신값의 유효성, 보정 시 예상 영향의 참고값 |
| 상태 예 | `추출 검토 가능`, `재샘플 검토`, `재취련 검토`, `후공정 보정 협의 필요` |
| 금지 표시 | `지금 즉시 출강`, `산소를 반드시 N분 더 취입` |

**격외 예방 의미:** 성분과 온도를 둘 다 보고, 샘플 결과가 현재 공정 상태를 충분히 대표하는지 확인한다.

## G6. 재취련·보정 판단 게이트

| 구분 | 관리 포인트 |
| --- | --- |
| 확인값 | G5 이탈 항목, 최신 분석의 신뢰도, 재취련/추가 투입 여부, 작업자 판단 사유 |
| 계산/비교 | 이탈 정도, 재취련 후 재샘플 필요 여부, 이후 성분·온도 목표에 미칠 수 있는 참고 영향 |
| 상태 예 | `재취련 후 재샘플 필수 확인`, `기준값 밖: 책임자/표준 확인`, `수동 계산 미사용 사유 기록` |
| 기록 결과 | 실제 조치, 시각, 조치 후 분석값, 결과 |

**격외 예방 의미:** 재취련은 단순 반복이 아니라 별도 의사결정으로 남겨야 같은 문제가 누적되는지 분석할 수 있다.

## G7. 출강 직전·출강 게이트

| 구분 | 관리 포인트 |
| --- | --- |
| 확인값 | 최종 확인값, 출강 시작/종료 시각, 출강량, 슬래그 혼입 관련 현장 확인 항목, 출강 중 추가 조치 |
| 계산/비교 | 목표 출강량 대비 차이, 최종 샘플의 시점/단위/범위 확인, 출강 완료 여부 |
| 경고 예 | `최종 분석 시점 확인`, `출강량 미기록`, `슬래그 관련 예외 기록 필요` |
| 기록 결과 | 출강 결과, 실제 성분·온도, 예외·인계 메모 |

**격외 예방 의미:** 출강 이후 후공정에서 발생한 문제를 전로 차지 이력과 연결할 수 있다.

## G8. 결과 확정·보정 학습

| 구분 | 관리 포인트 |
| --- | --- |
| 확인값 | 최종 성분·온도·출강량, 재취련/재샘플, 목표 대비 편차, 작업자 수정·예외 사유 |
| 계산/비교 | 강종군·재료 기준값 버전·조업 조건 그룹별 편차와 반복 패턴 |
| 결과 | 기준값 검토 후보, 입력 누락 개선 항목, 다음 차지에 적용할 승인 대기 보정안 |

**격외 예방 의미:** 자동 학습으로 기준값을 바꾸지 않고, 반복되는 편차를 검토 가능한 근거로 만든다.

## 화면과 계산의 최소 연결

| 화면 | G0~G8에서 쓰는 기능 |
| --- | --- |
| 차지 대시보드 | 현재 게이트, 누락 항목, 최신 분석과 목표 비교, 다음 확인 항목 |
| 이벤트 입력 | 장입·투입·샘플·분석·재취련·출강을 시각과 함께 기록 |
| 기준값 관리 | 재료 조성/단위/수율, 강종 목표 범위, 환산 규칙, 버전/승인 |
| 참고 계산 | 질량·성분·열수지의 차이와 계산 근거 표시 |
| 결과 분석 | 격외, 재취련, 재샘플, 목표 편차를 차지 이력과 비교 |

## 현장 확정이 필요한 항목

다음은 공개 연구나 일반식으로 정하지 않고, 해당 제철소의 표준과 취련사 인터뷰로 확정해야 한다.

1. 강종군별 실제 관리 성분과 목표/경고/중지 범위
2. 각 게이트에서 반드시 입력해야 하는 최소 항목과 입력 주체
3. "최신 분석이 오래됨"으로 보는 시간 기준
4. 재샘플·재취련·출강 검토 상태의 실제 표시 문구와 승인 흐름
5. 설비·노차·조업 방식별로 구분할 조건
6. 출강 이후 어떤 후공정 결과까지 전로 이력에 연결할지
