# 출강 검토 품질관리 항목 초안

상태: 화면 정보 구조 기준. 실제 활성 항목·목표 범위·경고값은 강종군별 현장 승인 후에만 적용한다.

## 1. 목적

출강 검토 화면이 C·온도·P·Mn 같은 소수 예시만 보여 주어 품질 정보를 지나치게 단순화하지 않게 한다. 다만 모든 원소를 한꺼번에 경고 막대로 늘어놓아 판단을 흐리지 않도록, **기본 품질·강종 특화 품질·공정 보조 정보**를 분리한다.

## 2. 화면 기본 품질 후보

아래 여섯 항목은 일반적인 화면 구성의 **후보**다. 고정 기본값이나 조업 표준값이 아니다.

| 그룹 | 항목 | 화면 역할 | 표시 방식 |
| --- | --- | --- | --- |
| 종점 성분 | C | 목표 성분 검토 | 목표 범위 막대 |
| 열 상태 | 온도 | 출강 온도 검토 | 목표 범위 막대 |
| 제한 성분 | P | 상한 또는 범위 검토 | 목표 범위 막대 |
| 제한 성분 | S | 상한 또는 범위 검토 | 목표 범위 막대 |
| 주요 합금 성분 | Mn | 목표 범위 검토 | 목표 범위 막대 |
| 주요 합금 성분 | Si | 목표 또는 상한 검토 | 목표 범위 막대 |

활성화된 항목이 여섯 개보다 적으면 빈 행을 만들지 않는다. 회사 분석표에 없는 항목이나 그 강종에서 관리하지 않는 항목도 표시하지 않는다.

## 3. 강종 특화 확장 품질표

강종군 설정에서 필요한 항목을 추가하면 `성분 상세` 표에 행 또는 열로 나타난다. 아래는 후보 분류이며, 실제 사용 여부는 분석 가능 여부와 승인 기준에 따른다.

| 분류 | 항목 후보 | 화면 규칙 |
| --- | --- | --- |
| 합금 성분 | Cr, Ni, Mo, V, Ti, Nb, B, Al 등 | 해당 강종에서 목표·상한·하한이 승인된 항목만 표시 |
| 잔류/불순물 | Cu, Sn, As 등 | 스크랩 영향 또는 품질 제한 기준이 있을 때만 표시 |
| 청정도·가스 | N, H, Total O 등 | 회사 분석 체계와 관리 기준이 있을 때만 표시 |
| 기타 현장 관리 성분 | 현장 승인 항목 | 코드·단위·목표 방식·표시 순서를 설정에서 정의 |

확장 항목은 기본 품질 여섯 행 아래에 2열 요약표로 먼저 보이고, 항목이 많으면 `성분 상세 펼치기`로 전체 표를 연다. 모든 확장 항목에 막대를 강제하지 않는다. 목표/한계가 승인된 항목만 범위 막대를 쓴다.

## 4. 공정 보조 정보와 품질 성분의 분리

다음 정보는 품질 성분과 같은 표에 합산하거나 단일 점수로 만들지 않는다. 필요 시 우측 `공정·입력 참고` 패널 또는 최근 이력표에 둔다.

| 구분 | 예시 | 용도 |
| --- | --- | --- |
| 데이터 신선도 | 샘플 채취 시각, 분석 입력 시각, 마지막 저장 시각 | 분석값을 현재 판단에 써도 되는지 확인 |
| 취련 진행 | 경과 시간, 누적 산소량, 재취련 횟수 | 입력 이력과 계산 근거 확인 |
| 부원료·합금 투입 | 투입명, 중량, 시각, 기준값 버전 | 참고 예상값의 근거 확인 |
| 슬래그/설비 관련 | 현장에서 수동 입력·승인한 값 | 별도 공정 검토. 품질 성분의 대체값 아님 |

## 5. 표시 우선순위

```text
기본 품질 6개: C · 온도 · P · S · Mn · Si
    ↓
강종 특화 품질: 해당 차지에서 활성화된 합금·잔류·청정도 항목
    ↓
공정·입력 참고: 시점, 진행, 투입, 근거
```

- 기본 품질은 6행을 모두 보여 전문적인 검토 밀도를 유지한다.
- 강종 특화 항목은 사용자가 추가한 순서와 중요도에 따라 표시한다.
- 실제 분석값, 참고 예상값, 목표 범위, 단위, 채취/입력 시점, 적용 기준 버전을 함께 표시한다.
- 분석값이 없으면 값 대신 `분석 미입력`으로 표시한다. 0 또는 평균값을 임의 표시하지 않는다.

## 6. 설정 항목

각 품질 항목에는 아래 설정이 필요하다.

| 설정 | 설명 |
| --- | --- |
| 항목 코드·표시명 | 예: `C`, `온도`, 현장 표기명 |
| 분류 | 기본 품질 / 강종 특화 / 공정 참고 |
| 단위 | `%`, `ppm`, `°C` 등 |
| 목표 방식 | 범위 / 상한만 / 하한만 / 목표값±허용차 |
| 표시 우선순위 | 기본 6행 또는 확장 품질표의 순서 |
| 필수 여부 | 출강 검토 전 반드시 확인할지 여부 |
| 분석 가능 여부 | 현장에서 이 항목을 실제로 입력할 수 있는지 |
| 적용 기준 버전 | 어느 승인 기준으로 비교하는지 |

## 7. 범위와 한계

- 공개 자료의 조성값·임계값·회수율을 기본값으로 입력하지 않는다.
- 항목이 많아도 `정상/위험` 단일 점수로 합치지 않는다.
- 이 화면은 출강·재취련·산소 투입을 자동으로 지시하지 않는다.
- 실제 항목과 목표는 취련사·품질·현장 책임자가 승인해야 한다.
