# 취련 코치 v0.5.0 초상세 처음사용자 설명서

이 문서는 취련 코치를 처음 보는 작업자가 화면 명칭, 단위, 버튼, 예상값, 오차, 보정계수를 다른 의미로 오해하지 않도록 만든 화면별 설명서입니다. 영문 화면의 주요 명칭도 괄호 안에 함께 적었습니다. 모든 화면과 수치는 합성 DEMO이며 실제 회사·설비·강종·작업자를 나타내지 않습니다.

> **안전·품질 경계:** C·온도·P·Mn·Si·S 값은 공개 문헌식과 합성 DEMO 계수로 계산한 참고예상입니다. 실제 현장 정확도는 검증되지 않았습니다. 설비 제어, 안전 인터록, 표준작업, 실험실 분석, 출강 승인 또는 취련사의 판단을 대체하지 않습니다.

## 1. 3분 안에 전체 구조 이해하기

1. 처음 열면 작업자 표시명과 `빈 작업으로 시작` 또는 `DEMO로 체험`을 선택합니다.
2. `기준 정보`에서 강종 목표, 재료 성분·단위, 설비, 계산계수를 확인합니다.
3. `신규 차지`에서 G0 기초값을 입력합니다.
4. 이후에는 대시보드 중앙의 파란 `현재 해야 할 일` 버튼을 먼저 봅니다.
5. 실제 발생 시각과 실제값을 저장하면 안내와 예상값이 자동 갱신됩니다.
6. 잘못 입력하면 원본을 삭제하지 말고 `전체 이력·정정`에서 수정 또는 무효 처리합니다.
7. 출강 후 확정 분석을 `종점 실제값`으로 지정하면 오차대장에 예상−실측 비교가 쌓입니다.
8. `학습 · 계수`는 충분한 같은 조건의 실제 오차가 모였을 때 검토용 보정 후보를 만듭니다. 자동 적용하지 않습니다.
9. 교대·브라우저 초기화 전에는 `분석 · 리포트`에서 CSV ZIP 백업을 저장합니다.

## 2. 공통 표시와 단위

### 2.1 입력 중요도 표지

| 표시 | 영문 | 뜻 | 미입력 시 |
| --- | --- | --- | --- |
| 필수 | Required | 식별·저장에 반드시 필요한 값 | 저장 버튼 비활성 또는 오류 표시 |
| 계산 핵심 | Calculation core | 6개 종점 참고예상 계산의 기본 조건 | 일부 또는 전체 예상이 `–` |
| 정확도 권장 | Recommended for accuracy | 알고 있다면 실제값을 넣어야 문헌 대체값 의존을 줄이는 항목 | 계수 프로필의 문헌값 사용 가능 |
| 선택 | Optional | 현장에 값이 있을 때만 기록 | 공란 허용 |

### 2.2 단위 사전과 내부 환산

| 기호·단위 | 영문 | 뜻과 환산 | 혼동 금지 |
| --- | --- | --- | --- |
| kg | kilogram | 내부 질량 기준 | t와 숫자를 그대로 섞지 않음 |
| t | tonne | `1 t = 1,000 kg` | 280 t 입력은 내부 280,000 kg |
| g | gram | `1,000 g = 1 kg` | 소량 첨가재용 |
| % / wt% | mass percent | 같은 질량 농도로 처리 | 0.05%는 5%가 아님 |
| ppm | parts per million | `10,000 ppm = 1%` | 500 ppm = 0.05% |
| °C | degrees Celsius | 섭씨 온도 | K가 아님 |
| Nm³ | normalized cubic metre | 설정된 기준 온도·압력으로 환산한 기체 체적 | 실제 배관 체적 m³와 다름 |
| Nm³/min | normalized cubic metres per minute | 1분당 표준상태 산소 유량 | 누적 산소량 Nm³와 다름 |
| m | metre | 랜스 높이. 기준점은 현장 표준 확인 | 절대 위치로 임의 해석 금지 |
| min | minute | 소요·잔여·재취련 시간 | 실제 시각과 다름 |
| C | Carbon | 탄소 농도 | % 기준 |
| Si | Silicon | 규소 농도 | % 기준 |
| Mn | Manganese | 망간 농도 | % 기준 |
| P | Phosphorus | 인 농도 | % 기준 |
| S | Sulfur | 황 농도 | % 기준 |
| T | Temperature | 온도 | °C 기준 |

### 2.3 색과 도형

| 표시 | 뜻 |
| --- | --- |
| 녹색 선 | 강종에 설정한 목표 범위 |
| 검은 점 | 최신 채택 실측값 |
| 흰 점 | 현재 종점 참고예상값 |

| 주황·빨강 | 확인 필요 또는 목표 이탈. 자동 출강 판정이 아님 |

| 문헌 기본 | 현재 계산계수 상태 | 수정·승인 상태에 따라 바뀜 |

### 4.3 G0~G8 단계

| 단계 | 한글 / English | 기록 목적 |
| --- | --- | --- |
| G0 | 장입 / Charge | 용선·스크랩·초기 부원료·계획 산소 기초값 |
| G1 | 송풍 시작 / Blow start | 실제 시작 시각과 첫 조업값 |
| G2 | 용해 초기 / Early blow | 초기 체크포인트·필요 시 샘플 |
| G3 | 용해 중기 / Mid blow | 샘플→분석→체크포인트 |
| G4 | 용해 후기 / Late blow | 후기 샘플로 종점 예상 갱신 |
| G5 | 정련 / Refining | C·온도가 있는 채택 샘플로 G6 준비 |
| G6 | 출강 검토 / Tap review | 최종 확인 후 출강 기록 |
| G7 | 출강 / Tapping | 후처리 자재·최종 분석 |
| G8 | 후처리 / Post-treatment | 완료·오차검증·정정이력 확인 |

단계 카드를 클릭한다고 임의로 단계를 건너뛰지 않습니다. 현재 단계의 중앙 안내나 `다음 단계` 버튼에서 실제 전환 시각을 기록해야 합니다.

### 4.4 중앙 현재 해야 할 일

중앙은 `입력 → 확인 → 단계 전환` 순서를 고정합니다.

- 큰 제목: 지금 해야 할 한 가지 행동입니다.
- `2/4`: 이 단계의 완료 항목 수/전체 항목 수입니다.
- 큰 파란 버튼: 현재 행동 입력창을 엽니다.
- 진행 순서: 완료, 현재, 권장, 대기 상태를 구분합니다.
- 품질 종합 판정: 목표가 설정된 6개 항목을 함께 봅니다. C·온도만 안전하다고 전체 안전으로 표시하지 않습니다.
- 다음 단계: 실제 공정이 바뀌었을 때만 기록합니다.
- 기초 입력값 확인·수정: 차지 번호·시작 시각을 제외한 G0 값을 정정합니다.

### 4.5 주요 품질 목표 및 예상

| 행 | 기본 단위 | 예상모델 역할 | 초기 문헌 신뢰도 표시 |
| --- | --- | --- | --- |
| C | % | 산소 물질수지와 채택 샘플 이후 변화량 | 중 |
| 온도 | °C | 열수지와 채택 샘플 이후 변화량 | 중 |
| P | % | 슬래그 조성·온도 기반 분배식 | 중 |
| Mn | % | 온도·슬래그 산화 상태 기반 분배식 | 낮음 |
| Si | % | 원소수지·산화 시나리오 | 중 |
| S | % | 슬래그 황분배 경험식 | 매우 낮음 |

`현재(실측)`은 최신 채택 분석입니다. `예상(종점)`은 현재 입력과 계수버전을 사용한 참고값입니다. 예상이 범위 안이어도 출강 가능을 뜻하지 않습니다. `목표 상한 ≤ 0.020`은 최대값만 설정한 단측 기준이며, 빈 최소값을 0으로 오해하지 않습니다.

## 5. 중간 샘플 오차 읽기

![중간 샘플 모델 오차](screenshots/v0.5.0/05-sample-residuals.png)

| 열 | 뜻 |
| --- | --- |
| 시각/샘플 | 분석이 입력된 시각과 샘플 ID |
| 산소 진행률 | `샘플 시점 누적 산소 ÷ 계획 총 산소 × 100` |
| 궤적 기대값 | 종점만 맞춘 값이 아니라 해당 산소 진행시점 문헌 궤적값 |
| 실측 | 사용자가 입력한 분석값 |
| 오차 | `실측 − 궤적 기대값`. 양수는 실측이 더 높음 |
| 종점 반영 | 최신 채택 분석만 `반영`, 그 외는 `비교만` |

여러 샘플의 오차를 모두 누적하지만, 현재 종점 재고정에는 최신 채택 분석 하나만 사용합니다. 오래된 샘플까지 동시에 종점에 더해 이중 보정하지 않습니다.

## 6. 신규 차지 G0 입력

![신규 차지 입력](screenshots/v0.5.0/09-new-heat-input.png)

### 6.1 식별·적용 기준

| 필드 | 영문 | 중요도 | 예 | 저장 차단 |
| --- | --- | --- | --- | --- |
| 차지 번호 | Heat ID | 필수 | `H-260823-001` | 빈 값·중복 |
| 강종 | Grade | 필수 | `DEMO-LC` | 프로필 없음 |
| 설비 프로필 | Equipment profile | 필수 | `BOF-A` | 프로필 없음 |
| 계수 버전 | Coefficient profile | 필수 | `COEF-LIT-001` | 프로필 없음 |
| 시각 | Started at | 필수 | 실제 장입 시각 | 미래 시각 |
| 예상 소요시간 | Expected duration | 선택 | `40 min` | 0 이하 |

차지를 만들면 강종·설비·계수의 당시 내용을 차지 안에 스냅샷으로 보존합니다. 이후 전역 설정을 바꿔도 이미 진행 중인 차지의 근거가 몰래 바뀌지 않습니다.

### 6.2 장입·초기 조업값

| 필드 | 단위 선택 | 중요도 | 의미 | 입력 예 |
| --- | --- | --- | --- | --- |
| 용선 중량 | kg/t/g | 계산 핵심 | 전로 장입 용선 질량 | `250 t` |
| 용선 탄소 | %/wt%/ppm | 계산 핵심 | 용선 초기 C | `4.50 %` |
| 용선 Si·Mn·P·S | %/wt%/ppm | 정확도 권장 | 각 원소 초기농도 | `Si 0.60 %` |
| 용선 온도 | °C | 계산 핵심 | 장입 시 실제 온도 | `1,350 °C` |
| 스크랩 중량 | kg/t/g | 계산 핵심 | 장입 스크랩 질량 | `30 t` |
| 스크랩 탄소 | %/wt%/ppm | 계산 핵심 | 대표 C | `0.10 %` |
| 스크랩 Si·Mn·P·S | %/wt%/ppm | 선택 | 공란이면 0으로 계산 | 알 때만 입력 |
| 초기 부원료 | kg/t/g | 정확도 권장 | G0에 이미 들어간 flux 합계 | `8,000 kg` |
| 계획 총 산소 | Nm³ | 계산 핵심 | 종점까지 계획한 총 산소 | `13,000 Nm³` |
| 누적 산소량 | Nm³ | 선택 | G0 현재까지 실제 누적 | 보통 0 |
| 랜스 높이 | m | 선택 | G0 당시 실제값 | `2.0 m` |
| 산소 유량 | Nm³/min | 선택 | G0 당시 실제값 | `650 Nm³/min` |

용선 Si·Mn·P·S를 비우면 계수 프로필의 문헌 대체값을 사용하고 Data Ledger의 `문헌값 대체 입력` 수가 증가합니다. 알고 있는 실제값을 넣는 것이 우선입니다.

## 15. 계산·보정계수와 날짜별 복구

![계수 버전 이력과 복구](screenshots/v0.5.0/08-settings-coefficient-history.png)

### 15.1 계수 상태 우선순위

`현장 승인 수정값 → 사용자 수정·미승인값 → 보존된 문헌 원본값` 순서로 실제 계산값을 정합니다. 사용자 수정값도 저장하면 계산에 사용되지만 `미승인`을 명확히 표시합니다.

### 15.2 학습 보정 오프셋

C·P·Mn·Si·S 오프셋 단위는 `%p`, 온도 오프셋 단위는 `°C`입니다. 예를 들어 P 문헌예상이 0.015%이고 오프셋이 +0.002%p이면 화면 참고예상은 0.017%입니다.

### 15.3 저장과 복구

1. 값을 바꾸고 변경 사유를 입력합니다.
2. `설정 저장`을 누르면 현재 프로필이 날짜·작업자·사유와 함께 과거 버전으로 보관됩니다.
3. 새 버전 ID가 현재값이 됩니다.
4. 과거 행의 `초안으로 복구`는 현재 기록을 덮어쓰지 않고 과거 값을 새 설정 초안으로 복사합니다.
5. 복구 사유를 입력해 다시 저장하면 또 하나의 새 버전이 생깁니다.

CSV ZIP의 `coefficient_versions.csv`에는 현재·과거 버전이 함께 들어갑니다. 잘못된 학습값을 넣어도 이전 날짜 버전을 선택해 새 버전으로 복구할 수 있습니다.

## 16. 학습 · 계수 추천 화면

![학습 오차대장과 추천 후보](screenshots/v0.5.0/03-learning-ledger.png)

### 16.1 선순환 구조

```text
문헌 모델 예상
→ 출강 후 종점 실제값 지정
→ 오차(실제−예상) 누적
→ 같은 강종·설비·계산식·계수버전끼리 분리
→ 검토용 오프셋 후보
→ 작업자가 설정 초안에서 검토
→ 변경 사유와 승인 상태를 정해 새 계수버전 저장
→ 새 차지에서 다시 오차 검증
```

### 16.2 데이터 충분성 단계

| 같은 그룹의 실제 오차 행 수 | 화면 단계 | 허용 해석 |
| ---: | --- | --- |
| 1~9 | 오차 기록 단계 | 학습 금지, 사례 누적 |
| 10~29 | 편향 방향 참고 | 계속 높게/낮게 치우치는지 참고 |
| 30~49 | 임시 추천 후보 | 설정 초안으로 가져와 검토 가능, 현장 승인 근거 부족 |
| 50~69 | 검증표본 대기 | 독립 검증용 추가 표본 확보 |
| 70 이상 | 독립 검증 가능 | 앞쪽 n−20개 학습, 최신 20개 검증 |

DEMO 행은 개수가 많아도 현장 승인 추천에 사용할 수 없습니다. 과거 계수버전의 오차는 현재 버전과 섞지 않으며, 과거 버전 후보는 현재 설정 초안으로 가져갈 수 없습니다.

### 16.3 추천값 해석

- 현재: 해당 계수버전에 이미 들어 있던 오프셋
- 추천 변화량 Δ: 학습구간 오차의 양끝 10%를 제외한 절사평균
- 추천: `현재 오프셋 + Δ`
- 검증 MAE: 보정 전/후 독립 검증 평균절대오차
- 설정 초안으로: 추천을 자동 저장하지 않고 기준 정보의 편집 초안으로 전달

실제 적용 전에는 표본 분포, 강종·설비 변경, 센서·분석법 변경, 이상치 원인을 검토해야 합니다. 목표범위 자체를 자동 변경하지 않습니다.

### 17.2 Excel 9개 시트

`Heat summary`, `Events`, `Analysis`, `Corrections`, `Predictions`, `Residual ledger`, `Calibration candidates`, `Coefficient versions`, `Read me`를 만듭니다. 사람의 검토·보고용이며 원본 백업은 CSV ZIP입니다.

## 20. English quick field reference

- **Do this now:** the single next recommended action for the selected heat.
- **Current actual:** latest adopted analysis result.
- **Endpoint estimate:** public-literature reference result after the selected coefficient offset and latest adopted-sample anchoring.
- **Scenario range:** literature low/base/high sensitivity range, not a statistical confidence interval.
- **Residual:** actual minus predicted.
- **Adopted analysis:** the analysis anchoring the current endpoint estimate.
- **Actual endpoint:** confirmed post-tap analysis used for model validation.
- **Correction candidate:** review-only offset suggestion; never auto-applied.
- **Coefficient version:** dated immutable calculation basis. Restore copies an old version into a new draft.
- **CSV ZIP:** integrity-checked restore package.
- **XLSX:** nine-sheet human-readable report, not a restore file.
- **Safety boundary:** C, temperature, P, Mn, Si, and S are unvalidated public-literature reference estimates. Always prioritize plant standards, laboratory results, interlocks, tap authorization, and operator judgment.
