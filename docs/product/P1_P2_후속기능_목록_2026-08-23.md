# 정정·운영 안정성 P1·P2 후속 기능 목록

상태: v0.3.0에서는 문서화만 하고 구현하지 않음  
원칙: P0 정정·이력 관리의 검증이 끝난 뒤 현장 우선순위에 따라 별도 묶음으로 진행한다.

## P1 — 다음 기능 후보

| ID | 기능 | 필요한 이유 | 완료 조건 |
| --- | --- | --- | --- |
| P1-01 | 설정 버전 차이 보기 | 현장 수정 전후 강종·설비·계수 변경을 빠르게 검토 | 차지 스냅샷과 현재 설정의 필드별 차이·수정자·시각 표시 |
| P1-02 | 기준 버전 발행·중지 | 공용 설정을 단순 덮어쓰기하지 않고 재현 | 초안/사용 중/중지 상태와 참조 중 삭제 금지 |
| P1-03 | 백업 복원 점검 상태 | 파일은 있어도 복원 불가능한 상황 방지 | 마지막 백업 시각·건수·해시·실제 읽기 검사 결과 표시 |
| P1-04 | 저장 실패 비상 내보내기 | 브라우저 저장 실패 시 현재 차지 유실 완화 | 자동 저장 실패 감지와 즉시 다운로드 가능한 복구 파일 |
| P1-05 | 표준 정정 사유 목록 | 자유 문구 편차를 줄여 후속 분석 가능 | 현장 승인 사유 목록 + 기타 자유 메모, 기존 이력 호환 |

## P2 — 이력과 운영 경험이 쌓인 뒤

| ID | 기능 | 시작 조건 | 주의 |
| --- | --- | --- | --- |
| P2-01 | PC 시계 이상 탐지 | 여러 시각 오류 사례가 확인될 때 | 공정 시각을 자동 변경하지 않고 경고만 표시 |
| P2-02 | 교대 인계 요약 | 교대 시 실제 필요한 항목을 취련사와 합의했을 때 | 진행 차지·미완료·최근 정정·백업 상태 중심 |
| P2-03 | 유사 과거 차지 조회 | 동일 조건의 완료 차지가 충분하고 데이터 품질 기준 통과 | 자동 투입·자동 추천 금지, 참고 비교만 제공 |
| P2-04 | 정정·예외 원인 통계 | 표준 사유와 충분한 표본 확보 | 상관관계를 원인으로 단정하지 않음 |
| P2-05 | 데이터 품질 대시보드 | 실제 사용 주기와 책임자가 정해진 뒤 | 누락률·분석 지연·단위 오류·복원 성공률을 분리 표시 |

## P0와의 경계

v0.3.0은 각 차지에 시작 당시 설정 스냅샷을 보존하므로, 이후 공용 설정 변경이 진행·완료 차지 예상값을 소급 변경하지 않는다. 다만 설정의 정식 발행·버전 비교·승인 워크플로는 P1이다.

P1·P2를 시작할 때는 이 문서에서 해당 항목을 별도 요구사항·검증 문서로 분리하고, 이 목록에는 상태와 연결 문서만 남긴다.
