# 취련 코치 v0.1 구현 현황

상태: 공개 합성 DEMO 초기버전. 실제 현장 정확도 검증 전.

## 1. 구현 목적

회사 시스템과 연동하지 않는 공용 PC에서 취련사가 수동 입력한 값으로 종점 C·온도를 참고 예상하고, 계산 근거·데이터 시점·기준 버전·차지 이력을 함께 확인한다.

## 2. 구현된 핵심 흐름

1. 강종·재료·설비·계수 기준을 확인하거나 추가한다.
2. `신규 차지`에서 용선·스크랩·초기 부원료·계획 산소·산소 유량·랜스 조건을 입력한다.
3. 여러 진행 차지를 탭으로 전환한다.
4. 자재·샘플·분석·체크포인트·재취련 이벤트를 실제 발생 시각으로 기록한다.
5. 최신 채택 샘플과 실제/계획 입력을 이용해 C·온도 종점 참고값을 갱신한다.
6. 출강 결과를 기록하고 CSV 백업 ZIP 또는 XLSX 보고서를 만든다.

## 3. 모듈 경계

| 모듈 | 책임 |
| --- | --- |
| `app/src/calculation/` | 정적/샘플 보정 종점 계산, 목표 대비 상태 |
| `app/src/domain/` | G0~G8 다음 행동·미완료 확인, 설정 정합성 |
| `app/src/components/` | 대시보드·입력 모달·하단 행동·설정 편집기 |
| `app/src/hooks/` | 로컬 상태·자동 저장·실시간 시계 |
| `app/src/storage/` | IndexedDB·CSV 인코딩/파싱 |
| `app/src/reports/` | SHA-256 CSV 백업·복원, XLSX 보고서 |
| `app/src/units/` | 질량 단위 kg 표준화 |
| `app/src/i18n/` | 한국어·영어 화면 문구 |

## 4. 계산 활성 범위

- C: 정적 물질수지 또는 최신 채택 샘플 이후 보정
- 온도: 정적 열수지 또는 최신 채택 샘플 이후 보정
- 예상 잔여시간: `잔여 산소량 / 입력 산소 유량`, 유량이 없으면 사용자가 입력한 잔여시간
- P·Mn·Si·S: 실측·목표 비교만 구현. 종점 계산식 미설정 상태를 명시
- 재료: `flux` 분류 중량만 v0.1 열수지 입력에 연결. 조성은 이력·설정에 보존하지만 합금 수율 계산에는 미연결

## 5. 저장·복원

- 브라우저 IndexedDB 자동 저장
- UTF-8 CSV 7종과 SHA-256 `manifest.csv`를 포함한 ZIP 전체 백업
- 복원 전 파일 존재와 해시 검증
- XLSX는 Heat summary, Events, Analysis, Read me 시트로 분리
- 실제 회사 데이터는 Git 저장소 밖의 승인된 위치에서만 보관

## 7. 남은 현장 결정

- 실제 강종 목표와 승인 이력
- 전로·랜스·저취·재료 프로필
- C·온도 계수의 독립 손계산과 가상 차지 검증
- 실제 완료 차지 그림자 검증의 합격 기준
