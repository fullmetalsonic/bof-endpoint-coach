# v0.5 학습형 종점예상 구현 명세

상태: 구현 기준 확정. 공개 문헌 기본모델과 합성 시험을 대상으로 하며 실제 BOF 정확도는 현장 그림자 운전 전까지 미검증이다.

## 1. 목적

작업자가 차지·샘플·분석·출강 결과를 계속 기록하면 다음 두 순환이 독립적으로 작동한다.

1. **차지 내 보정**: 최신 유효 샘플을 기준점으로 같은 차지의 종점 예상값을 다시 계산한다.
2. **차지 간 학습**: 완료 차지의 종점 예상 오차를 비교군별로 누적해 보정계수 후보를 추천한다.

목표 성분 범위는 강종 기준이며 학습으로 자동 변경하지 않는다. 추천값도 사용자의 검토·승인 전에는 계산에 적용하지 않는다.

## 2. 표시 용어

| 용어 | 의미 |
| --- | --- |
| 목표 범위 | 사용자가 설정한 강종별 허용 최소·최대 |
| 문헌 최초예상 | 공개 문헌·물질수지·열수지로 계산한 종점값 |
| 샘플 보정예상 | 최신 유효 샘플과 샘플 시점 모델값의 차이를 반영한 종점값 |
| 실측 | 채택된 분석 결과 |
| 잔차 | 같은 계산 시점의 `실측 - 예상` |
| 종점 오차 | 채택한 실제 종점 분석값과 출강 전 고정 예상값의 차이 |
| 계수 추천 | 누적 종점 오차로 만든 검토 후보. 자동 적용값이 아님 |

## 3. 계산 계층

```text
입력·단위 정규화
→ 장입 및 유효 자재 투입 집계
→ 슬래그 조성 시나리오
→ C·온도·Si·P·Mn·S 문헌 종점모델
→ 최신 유효 샘플 앵커
→ 승인된 비교군 보정계수
→ 결과 범위·근거·신뢰등급 표시
```

### 3.1 성분별 문헌 기본선

- `C`: 산소 물질수지. Si·Mn·P·Fe 산화와 CO/CO2 후연소를 분리한다.
- `온도`: 물질수지와 연결된 축약 열수지.
- `Si`: Si 원소수지와 공개 문헌의 종점 완전 산화 가정을 기본선으로 사용한다.
- `P`: 예상 슬래그의 CaO/SiO2, MgO, 전철분과 예상 온도를 사용하는 문헌 M1 분배식에 P 원소수지를 결합한다.
- `Mn`: MnO/금속 Mn 분배식과 Mn 원소수지를 결합한다. 문헌 적용 조건 차이 때문에 낮은 신뢰등급과 넓은 민감도 범위를 사용한다.
- `S`: 슬래그/금속 S 분배와 S 원소수지를 결합한다. BOF 산화성 조건에서 탈황이 제한되므로 가장 낮은 신뢰등급으로 표시한다.

P·Mn 계산은 강종 목표값을 입력으로 사용하지 않는다. 목표값은 계산 완료 후 상태 비교에만 사용한다.

### 3.2 다중 샘플 규칙

- 모든 유효 분석의 예상·실측·잔차를 시간순으로 보존한다.
- 현재 종점 계산에는 가장 최근에 **채택된 유효 분석**만 앵커로 사용한다.
- 샘플 잔차를 서로 더하지 않는다. 새 샘플이 들어오면 그 샘플을 새 기준점으로 다시 계산한다.
- 무효·정정·채택 변경 시 원본을 삭제하지 않고 영향받는 예상 스냅샷을 새로 만든다.

## 4. 계수 이력과 날짜별 복구

계수 버전에는 다음을 저장한다.

- 버전 ID, 생성 시각, 생성 작업자, 적용 강종군·설비군
- 문헌 원본값, 사용자 수정값, 승인된 실제 적용값
- 추천을 만든 학습 데이터 기간·차지 수·제외 수·검증 기간
- 성분별 편향, MAE, 중앙절대오차, 목표 허용범위 적중률
- 상태: `문헌 기본 / 추천 후보 / 사용자 수정 미승인 / 현장 승인 / 중지 / 복구본`
- 이전 버전 ID와 변경 사유

과거 버전은 삭제하지 않는다. 과거 버전으로 복구할 때도 기존 레코드를 덮어쓰지 않고 `복구본` 새 버전을 만든다. 전체 CSV ZIP 백업에는 현재 계수와 모든 계수 버전·추천·승인 이력을 포함하고 SHA-256과 행 수를 검증한다.

## 5. 누적 학습 관문

| 같은 비교군의 유효 완료 차지 | 허용 기능 |
| ---: | --- |
| 1~9 | 개별 오차 원장만 표시 |
| 10~29 | 편향 방향과 데이터 품질 경고 표시 |
| 30~49 | 임시 후보 계산. 적용·승인 불가 |
| 학습 50 이상 | 보정 후보 생성 가능 |
| 이후 시점 독립 검증 20 이상 | 기존 승인 버전과 성능 비교 가능 |
| 합격 기준과 현장 승인 완료 | 새 계수 버전 적용 가능 |

같은 차지의 여러 샘플을 여러 독립 차지로 세지 않는다. 취소·무효·종점 실제값 미지정·필수 입력 누락·다른 강종군/설비군/기준 버전은 제외하거나 별도 비교군으로 분리한다.

## 6. 초기 추천 알고리즘

v0.5의 자동 추천은 과적합 위험이 낮고 설명 가능한 **성분별 편향 보정값**으로 제한한다.

```text
종점 오차 = 실제 종점값 - 출강 전 예상값
후보 보정값 = 학습 집합 종점 오차의 절사 평균과 중앙값을 함께 계산
후보 예상 = 문헌·샘플 예상 + 승인된 보정값
```

극단값은 숨겨서 삭제하지 않고 별도 표시한다. 시간순 학습/검증 분리에서 기존 버전보다 MAE·편향·적중률이 개선되지 않으면 추천하지 않는다. 산소량·부원료·랜스 조작 권고는 v0.5 범위 밖이다.

## 7. 화면 수용 기준

- 품질 막대의 C·온도·P·Mn·Si·S에 실제값, 문헌 최초예상, 샘플 보정예상, 목표 범위, 예상 범위를 구분한다.
- 계산 근거, 신뢰등급, 필수 입력 누락 사유를 숫자 가까이에 표시한다.
- 학습 화면에서 비교군, 데이터 단계, 제외 사유, 오차 추이, 추천 근거, 현재/후보 계수 차이를 확인한다.
- 계수 이력에서 날짜·버전을 선택해 상세 비교하고 복구본을 만들 수 있다.
- 추천 적용은 변경 사유와 사용자 확인이 필요하며, 적용 후 새 차지에만 사용한다.

## 8. 검증 기준

- 논문식 전사값을 독립 손계산과 대조한다.
- 질량보존, 단위환산, 0·결측·경계·비정상 슬래그 조성에서 실패 안전성을 시험한다.
- 최신 샘플 채택, 과거 샘플 정정·무효, 출강 정정에서 재계산과 원본 이력이 보존되는지 시험한다.
- 같은 차지가 학습과 검증에 동시에 들어가지 않는지 시험한다.
- 계수 버전 생성·복구·전체 백업·복원 후 계산 결과가 동일한지 시험한다.
- 합성 시험 PASS는 실제 현장 정확도 PASS로 표시하지 않는다.
