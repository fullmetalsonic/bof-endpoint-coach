# v0.7 최소입력·선택형 투입 코치 기획안

상태: **제품 기획 확정 / 1~3단계 개발 승인 / 4단계 보류**  
기준일: 2026-08-24  
상위 목표: [오프라인 AI 취련 코치 제품 목표](AI_취련코치_제품목표_2026-08-23.md)  
직전 기준선: v0.6.1 종점예상·학습·JSON·비상복구 카드

## 1. 한 문장 목표

> 작업자가 평소에는 기존대로 빠르게 조업하고, 필요할 때만 자신의 예상 투입량·시각과 취련 코치의 참고안을 비교하며, 권고 화면을 사용하지 않아도 실제 투입과 종점 결과가 쌓이면 독립 투입 모델의 성능을 개선할 수 있게 한다.

v0.7은 작업자에게 입력창을 많이 추가하는 버전이 아니다. 기존 차지·재료·조업·샘플·종점 데이터를 재사용하고, 작업자가 새로 입력해야 하는 값은 가능한 한 `재료·량·시각`으로 제한한다.

## 2. 현재 기능 중 그대로 재사용할 것

### 2.1 이미 있는 재료·부원료 설정

현재 재료 설정에는 다음 항목이 있다.

- 재료 코드와 한글·영문 이름
- 분류: `Flux`, `Coolant`, `Alloy`, `Scrap`, `Other`
- 기본 입력 단위: `kg`, `t`, `g`
- 금속 성분: C·Si·Mn·P·S
- 산화물 조성: CaO·MgO·SiO2·Al2O3·FeO·Fe2O3·MnO·P2O5

현재 자재 투입 기록은 등록 재료, 실제 투입량, 단위, 실제 투입 시각과 당시 재료 조성 스냅샷을 보존한다. 이 구조를 새 투입 코치의 기준정보와 실제값 원장으로 재사용한다.

### 2.2 이미 있는 차지 상태 입력

- 강종 목표 C·온도·P·Mn·Si·S
- 용선·스크랩량과 성분·온도
- 초기 부원료 합계
- 계획·누적 산소량, 산소 유량, 랜스 높이
- G0~G8 실제 단계 시각
- 샘플 채취·분석·재취련·출강
- 종점예상 스냅샷과 확정 종점 실제값

작업자가 같은 값을 투입 코치 화면에 다시 적게 하지 않는다.

## 3. 제품 원칙

### 3.1 권고는 선택사항이며 G단계를 막지 않는다

- `투입 코치`를 한 번도 열지 않아도 기존 G단계 흐름을 그대로 진행할 수 있다.
- 투입 코치의 누락·미확인·미채택은 단계 전환 차단 사유가 아니다.
- 기존 G5 종점 검토 샘플처럼 현재 안전한 흐름에 이미 필요한 게이트는 유지하되, 새 투입 권고 때문에 필수 게이트를 추가하지 않는다.
- 숙련 작업자가 수기 계산·경험으로 판단하면 `권고 사용 안 함`을 누르거나 그냥 지나갈 수 있다.
- `이번 차지에서 접기`를 선택하면 위험 경고가 아닌 일반 권고 알림은 반복하지 않는다.

### 3.2 평상시 추가 입력은 0~2회로 제한한다

권고를 조회만 할 때는 새 입력이 0개여야 한다. 현재 차지 상태로 자동 계산한다.

실제 자재를 넣었을 때는 기존 입력창에서 다음만 입력한다.

1. 재료 선택
2. 실제 투입량

실제 시각은 현재 로컬 시각이 기본이며 필요할 때만 수정한다. 재료 조성·단위·설비·강종 목표는 설정과 차지 스냅샷에서 가져온다.

작업자 계획과 비교하고 싶을 때만 다음을 선택 입력한다.

1. 내 예상 투입량
2. 예정 시점: `지금`, `로컬 시각`, `취련 경과`, `누적 산소` 중 하나

### 3.3 한 번에 한 가지 주 행동만 보여준다

투입 코치는 여러 재료의 숫자를 한꺼번에 나열하지 않는다. 대시보드에는 다음 중 하나만 주 상태로 표시한다.

- `현재 권고 없음`
- `투입 검토`
- `추가 산소 검토`
- `샘플 결과 후 재계산`
- `입력 부족으로 계산 보류`
- `서로 충돌하는 목표 확인`

모델 후보가 여러 개면 1개 주안과 최대 1개 대안만 표시한다. 상세 비교는 작업자가 `비교 보기`를 누를 때 펼친다.

### 3.4 단일값이 아니라 범위와 근거를 보여준다

- 투입량: 예 `850~1,050 kg`
- 권장 시간대: 예 `취련 5:30~6:40`, `누적 산소 7,500~8,100 Nm³`
- 로컬 예상 시각: 현재 유량과 진행상태를 이용한 보조 표시
- 예상 영향: 종점 C·온도·P·Mn·Si·S와 계산 가능한 슬래그·열수지 항목
- 신뢰 상태: `문헌 시나리오`, `현장 후보`, `현장 검증`, `계산 보류`
- 주요 가정·누락값·모델·계수버전

## 4. 가장 단순한 작업 흐름

### 4.1 권고를 사용하지 않는 숙련 작업자

```text
G단계 이동
→ 경험·수기 계산으로 판단
→ 실제 투입이 있으면 재료·량만 기록
→ 실제 시각은 현재값 사용
→ 계속 조업
```

이 경우에도 취련 코치는 해당 시점의 `그림자 권고`를 백그라운드에 저장한다. 출강 후 실제 결과가 확정되면 그림자 권고, 실제 투입, 결과를 비교할 수 있다.

### 4.2 빠르게 참고만 하는 작업자

```text
대시보드의 투입 코치 한 줄 확인
→ 필요하면 비교 보기
→ 코치 참고안 확인
→ 닫고 기존 조업 계속
```

조회 여부와 무관하게 권고는 실제 투입으로 기록되지 않는다.

### 4.3 자신의 계산과 비교하는 작업자

```text
내 계획 입력: 재료·예상량·예정 시점
→ 코치안과 차이 확인
→ 내 계획 유지 / 코치안 참고 / 보류
→ 실제 투입 때 기존 자재 투입 기록
```

`코치안 참고`는 계획 상태일 뿐 실제 이력이 아니다. 실제 투입 버튼을 눌러 저장해야 실제값이 된다.

## 5. 화면 구성

### 5.1 대시보드 소형 카드

품질 예상과 다음 행동 사이에 `투입 코치` 소형 카드를 둔다.

| 위치 | 표시 |
| --- | --- |
| 왼쪽 | 현재 상태: 권고 없음·검토·보류·충돌 |
| 중앙 | 주안 1개: 재료/산소, 권장 범위, 시간대 |
| 오른쪽 | `비교 보기`, `내 계획`, `이번 차지에서 접기` |

화면을 복잡하게 만들지 않도록 기본은 한 줄 높이로 접어 둔다. 현재 권고가 없거나 계산할 수 없으면 숫자 표를 만들지 않는다.

### 5.2 비교 서랍

`비교 보기`를 누르면 화면 오른쪽 또는 중앙 모달에 다음만 표시한다.

| 항목 | 내 계획 | 코치 참고안 | 차이 |
| --- | --- | --- | --- |
| 재료·조작 | 작업자 선택 | 모델 주안 | 동일/다름 |
| 투입량 | 입력값 | 권장 범위 | 범위 안/낮음/높음 |
| 시점 | 입력값 | 권장 시간대 | 빠름/범위 안/늦음 |
| 예상 영향 | 선택 표시 | C·온도·P·Mn·Si·S | 변화 방향 |
| 상태 | 작업자 계획 | 문헌/현장 후보/검증 | 근거 수준 |

버튼은 다음 네 개로 제한한다.

- `내 계획 유지`
- `코치안을 계획으로 복사`
- `샘플 후 다시 보기`
- `닫기`

`코치안을 계획으로 복사`해도 실제 투입은 생성하지 않는다.

### 5.3 시간선

상세 화면에서만 다음 세 표시를 같은 축에 놓는다.

- 작업자 예정 시점
- 코치 권장 시간 범위
- 실제 투입 시점

시간축에는 로컬 시각만 쓰지 않고 `로컬 시각 / 취련 경과 / 누적 산소`를 함께 표시한다. 취련 중단·유량변경이 있으면 로컬 예상 시각을 다시 계산하고 `추정` 표시를 붙인다.

## 6. 작업자 입력을 줄이는 장치

### 6.1 설정은 한 번, 차지에서는 재사용

재료 조성은 재료 기준정보에 한 번 등록한다. 차지마다 다시 묻지 않는다. 강종 목표와 설비 조건도 기존 프로필을 사용한다.

새로 필요한 현장 설정은 고급 설정에 접어 둔다.

- 재료별 권고 사용 여부
- 현장 승인 최소·최대 투입량
- 사용할 수 있는 G단계·누적 산소 구간
- 유효 성분/회수율 또는 열영향 계수
- 필요 시 수분·강열감량·입도 구분

값이 없으면 문헌 시나리오 또는 계산 보류로 표시하며 임의의 현장값을 만들지 않는다.

### 6.2 빠른 입력

- 최근 사용 재료를 목록 위에 표시
- 현장 승인 즐겨찾기 재료 최대 4개
- 기본 단위를 재료 설정에서 자동 선택
- 실제 시각은 현재 시각으로 채움
- 숫자 입력 뒤 Enter로 저장 가능
- `최근 투입 반복`은 오입력 위험 때문에 즉시 복제하지 않고 재료·량을 채운 초안만 연다

### 6.3 계획 입력도 선택사항

작업자 계획을 입력하지 않아도 실제 투입 기록과 그림자 권고로 학습자료를 만들 수 있다. 다만 계획을 입력하면 `작업자 예상 대 모델 예상` 비교 품질이 높아진다.

예정 시각은 미래값을 허용하는 `계획` 데이터로 저장한다. 기존 실제 자재 투입 이벤트는 계속 미래 시각을 거부한다. 계획을 실제 사실처럼 바꾸거나 실제 이력에 자동 복사하지 않는다.

권고 사용은 선택사항이지만, 실제 투입 사실을 기록하지 않으면 그 투입의 양·시각 효과를 학습할 수 없다. 이 경우에도 G단계를 막지는 않고 완료 뒤 `투입 학습자료 부족`으로만 표시한다.

## 7. 독립 계산 모델

현재 종점 모델을 그대로 역산하지 않는다. 재료군과 산소를 독립 모델로 계산하고 공통 비교 계층이 결과만 조합한다.

### 7.1 표준 출력 계약

각 모델은 같은 형식의 참고안을 반환한다.

```text
조작 종류 / 재료 코드
권장량 범위
권장 시간 범위: 로컬·경과·누적 산소
예상 종점 영향
계산 가정과 누락값
신뢰 상태
모델·계수·재료·강종·설비 버전
생성 시각과 만료 조건
```

비교 화면은 계산식을 직접 알지 않고 이 표준 결과만 읽는다. 모델 하나를 교체해도 다른 모델과 화면을 함께 고치지 않게 한다.

### 7.2 모델 분리

| 모델 | 1차 역할 | 초기 표시 원칙 |
| --- | --- | --- |
| Flux | 생석회·돌로마이트 등 총량/범위와 슬래그 형성 참고 | 승인된 목표범위가 없으면 `문헌 시나리오` |
| Coolant/Ore | 냉각재·광석의 온도·외부 산소·슬래그 영향 | 재료별 열수지 전에는 효과 비교만, 직접 권고 보류 |
| Alloy/Carburizer | 목표 성분과 회수율 기반 필요량 | 별도 현장 수율이 없으면 명목 수지·낮은 신뢰 |
| Oxygen | 남은 산소 또는 재취련 산소 시나리오 | 부원료 대체가 아니라 별도 조작안, 승인 한도 필요 |
| Timing | 각 모델 결과를 허용 단계·용해/반응시간과 연결 | 한 점이 아닌 시간 범위 |
| Coordinator | 충돌 확인과 주안 1개·대안 1개 선정 | 계산 자체를 하지 않음 |

### 7.3 산소 모델 경계

- 산소는 부원료가 부족하다는 이유만으로 자동 대체하지 않는다.
- C·온도·P 등 여러 목표에 미치는 영향과 충돌을 함께 표시한다.
- 최신 샘플·누적 산소·유량·계수 신뢰가 부족하면 숫자 권고 대신 `샘플 후 재계산` 또는 `계산 보류`를 표시한다.
- 산소 참고안을 적용해도 기존 `재취련 기록`에 실제 추가 산소량을 별도로 입력해야 한다.
- 현장 승인 범위를 벗어난 산소량은 추천하지 않고 시나리오 경고만 표시한다.

## 8. 라이브 타임 원칙

로컬 시간이 흐르는 것만으로 반응이 진행됐다고 판단하지 않는다.

권고 상태는 다음 사건에서 갱신한다.

- 차지 시작·G단계 전환
- 누적 산소·유량·랜스 체크포인트
- 실제 자재 투입
- 샘플 채취·분석 수신·채택 변경
- 재취련
- 사용자가 `현재 상태로 다시 계산`을 누름

사건 사이에는 마지막 유량으로 로컬 예상 시각만 보간할 수 있다. 보간값은 `추정`으로 표시하고 누적 산소 실측처럼 저장하지 않는다.

권고는 다음 사건이 생기면 만료한다.

- 실제 투입 발생
- 새 샘플 분석 채택
- 단계 변경
- 누적 산소가 권고 생성값에서 승인된 허용차를 넘음
- 적용 기준·재료·모델 버전 변경

## 9. 사용하지 않아도 학습되는 그림자 운전

### 9.1 자동 그림자 권고

작업자가 화면을 열지 않아도 다음 시점에 계산 가능한 모델의 참고안을 자동 스냅샷으로 남긴다.

- G단계 전환 직후
- 체크포인트 저장 직후
- 실제 투입 직전 상태를 재구성할 수 있는 경우
- 샘플 분석 채택 직후
- 출강 전 최종 종점예상 고정 시점

그림자 권고는 실제 행동이 아니며 운영로그와 학습 원장에서 `shadow`로 구분한다.

### 9.2 학습에 꼭 필요한 최소 실제 기록

- 실제 재료·량·시각 또는 실제 추가 산소량
- 당시 단계·누적 산소 등 기존 조업 스냅샷
- 출강 전 예상 스냅샷
- 확정 종점 성분·온도

슬래그 분석, 수율, 재취련, 오버플로·슬로핑 등 추가 결과가 있으면 별도 품질항목으로 활용하되 초기 필수 입력으로 만들지 않는다.

### 9.3 두 개의 학습 루프

1. 기존 종점 루프: C·온도·P·Mn·Si·S 예상 편향 보정
2. 새 투입 루프: 재료별 량 영향·시각 영향·산소 영향 보정

두 루프의 계수와 버전을 섞지 않는다. 종점 모델 계수를 복구해도 투입 모델 계수는 임의 변경되지 않고, 반대도 같다.

### 9.4 단순 건수 외 데이터 충분성

같은 재료를 같은 시점·같은 양으로만 사용한 데이터는 많아도 시각 효과를 학습할 수 없다. 추천 단계는 다음을 함께 확인한다.

- 동일 강종군·설비군·재료·모델버전의 실제 차지 수
- 투입량 분포와 시간대/누적 산소 구간의 분포
- 필수 결과 누락률과 정정·무효 비율
- 최근 기간 독립 검증에서 기존 모델보다 개선됐는지
- 현장 승인 범위 안에서만 만들어진 후보인지

현재 종점 모델의 30/50/70건 관문은 참고할 수 있지만 투입 모델에는 분포·범위 관문을 추가한다. 추천값은 작업자 검토 전 자동 적용하지 않는다.

## 10. 자동저장·백업·비상복구·인쇄

### 10.1 자동저장과 JSON

다음을 기존 IndexedDB 자동저장과 전체 JSON 백업에 포함한다.

- 작업자 계획
- 그림자·조회 권고 스냅샷
- 채택·미채택·보류 결정
- 실제 투입·산소 이벤트 연결
- 투입 모델과 계수 모든 버전
- 학습 데이터셋·제외 사유·검증 결과
- 재료·강종·설비·현장 한도 기준지문

JSON 복원은 전체 검증 뒤 적용하며, 새 모델 필드가 있어도 구형 v0.6 백업을 읽을 수 있는 마이그레이션 규칙을 둔다.

### 10.2 비상복구 카드

모델 내부의 모든 계수를 인쇄하지 않는다. 재료 모델별 현재 적용 핵심값만 별도 카드로 만든다.

- 모델 ID·버전·신뢰 상태
- 적용 재료·강종·설비 범위
- 투입량 핵심 보정값
- 시간 핵심 보정값
- 열영향·회수율 등 해당 모델 핵심값
- 현장 최소·최대 한도 버전
- 재료·기준지문과 확인코드

수기로 복구하면 즉시 계산에 적용하지 않고 설정 초안으로 가져가 현재값과 비교한다. 비상카드는 학습 원본·차지 이력·검증 근거를 복구하지 못한다.

### 10.3 인쇄 보고서

한 차지 1페이지 요약을 제공한다.

- 작업자 계획
- 코치 참고안과 생성 시각
- 작업자의 선택
- 실제 투입량·시각
- 출강 전 예상과 확정 종점
- 적용 모델·계수·기준지문

화면을 캡처하지 않아도 종이로 비교 결과를 남길 수 있게 한다.

## 13. 검증 기준

### 기능

- 권고 사용·미사용·접기 어느 경우에도 허용된 G단계 이동이 동일하게 동작
- 계획·권고·실제값이 서로 덮어쓰지 않음
- 실제 자재 정정·무효 시 연결된 학습 데이터가 오래된 결과로 표시됨
- 로컬 시각·경과시간·누적 산소가 혼동되지 않음
- 모델 한 개 오류가 종점예상·다른 모델·단계전환을 중단시키지 않음

### 사용성

- 숙련 작업자는 기존 대비 추가 클릭 없이 권고를 무시할 수 있음
- 실제 투입은 재료·량 입력 후 저장 가능
- 첫 사용자도 `권고는 계획이며 실제 투입이 아니다`를 구분
- 대시보드에서 주 행동·권장범위·신뢰상태를 3초 안에 파악
- 1920×1080 100% 화면에서 기존 품질표와 G단계가 밀려나지 않음

### 계산·학습

- 각 모델은 같은 입력·버전에서 같은 결과를 재현
- 문헌값·현장 설정·학습 보정 기여를 분리 표시
- 데이터가 적거나 한쪽 범위에 몰리면 후보를 만들지 않음
- 시간순 독립 검증에서 기존 모델보다 나빠지면 추천하지 않음
- 실제 BOF 정확도는 완료 차지 그림자 운전 전까지 N/A로 표시

### 백업·복구

- 구형 v0.6 JSON 호환과 새 v0.7 전체 왕복
- 비상카드 수기입력은 초안으로만 복구
- 인쇄 결과에 계획·권고·실제·결과·버전이 모두 표시
- 손상·중복·미지 모델·기준지문 불일치 시 현재 상태를 변경하지 않음

## 15. 문헌 적용 경계

- [NPTEL Process Control BOF Steelmaking](https://archive.nptel.ac.in/content/storage2/courses/113104059/lecture20/20_2.htm)은 정적·반동적·동적 모델을 구분하고 공정모델이 실제 데이터로 뒷받침돼야 한다고 설명한다.
- [Dynamic Modeling and Simulation of BOF Operation](https://www.mdpi.com/2227-9717/8/4/483)은 산소·랜스·광석 등 시간에 따른 조업변수와 슬래그·열수지의 결합 필요성을 보여준다.
- [Incorporation of Control Parameters into a Kinetic Model](https://www.mdpi.com/2227-9717/13/10/3048)은 산소 유량·랜스 높이·용선량·플럭스량을 교정변수로 다루며 현장 데이터에 의한 보정 필요성을 보여준다.
- [Influence of lime particle and slag properties on lime dissolution](https://www.sciencedirect.com/science/article/pii/S2238785420319177)은 석회 입도·소성도·슬래그 상태가 용해에 영향을 주므로 보편 투입 시각 한 점을 그대로 권고할 수 없음을 뒷받침한다.

위 자료는 모델 구조와 영향인자의 근거다. 공개 수치를 특정 사업소의 실제 투입량·시각·산소량으로 자동 사용하지 않는다.

## 16. 기획 결론

v0.7의 성공 기준은 많은 기능이 아니라 다음 네 가지다.

1. 숙련자는 방해받지 않는다.
2. 필요한 작업자는 1~2번의 입력으로 자신의 계산과 코치안을 비교한다.
3. 권고를 사용하지 않아도 실제 투입·종점 결과로 그림자 모델을 평가한다.
4. 현장 데이터가 쌓이면 독립 모델별로 검증된 보정 후보를 만들되 자동 적용하지 않는다.

따라서 초기 화면에는 거대한 최적화 표가 아니라 `투입 코치 한 줄 + 필요할 때 비교 서랍`만 추가하는 방향을 기준으로 한다.
