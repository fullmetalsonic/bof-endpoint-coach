# v0 구현 전 결정 체크리스트

상태: 미결 항목 정리용. 이 문서는 공정 수치나 기준값을 정하는 문서가 아니라, 누가 무엇을 결정해야 하는지 정리한다.

## 먼저 알아둘 점

현재 단계에서 사용자가 직접 정할 필요가 없는 것은 실제 성분 목표, 수율, 재취련 기준, 출강 판단 수치다. 이 값들은 취련사·품질·현장 책임자가 승인해야 한다.

지금 먼저 정할 것은 **도구의 범위와 기록 방식**이다.

| 번호 | 결정할 내용 | 선택지 또는 질문 | 결정 주체 | 결정되면 만들 문서/기능 |
| --- | --- | --- | --- | --- |

| D02 | 한 PC의 동시 차지 수 | **여러 차지 목록으로 결정**. 선택된 한 차지만 입력 대상 | 취련사/현장 책임자 | 차지 전환·인계 규칙 |
| D03 | 차지 식별 방식 | 차지 ID 입력 방식, 중복 시 처리, 취소/재개 여부 | 현장 책임자 | 차지 상태·이벤트 규칙 |

| D09 | 입력 시각 규칙 | PC 시각 기준, 과거 시각 입력 허용, 시간 역전 경고 여부 | 현장 책임자 | 시간·이벤트 검증 규칙 |

## 권장 초기 선택안

공정 수치가 아직 없는 현재 조건에서는 아래처럼 시작하는 것이 가장 안전하다.

| 항목 | 권장 시작안 | 이유 |
| --- | --- | --- |
| D01 참고 계산 | 기록·목표 비교·누락 확인만 먼저, 계산은 비활성 | 근거 없는 수치가 현장 판단처럼 보이는 것을 방지 |
| D02 동시 차지 | 진행 중 차지 목록에서 클릭 전환, 현재 작업 대상 한 건에만 입력 | 실제 병행 조업을 지원하면서 오입력 방지 |
| D04 샘플 분석 | 샘플 ID별 분석 결과를 추가 기록하고, 채택 결과는 명시적으로 선택 | 재분석·정정 결과의 혼동 방지 |
| D05 품질 항목 | C·온도·P·S·Mn·Si를 후보로 두고 실제 활성 항목만 표시 | 정보 밀도와 현장 맞춤성의 균형 |
| D06 승인 | 기준값은 현장 책임자가 승인한 CSV/설정 파일만 반입 | 계정 없는 HTML을 권한 시스템처럼 오해하지 않음 |
| D07~D08 백업 | 차지 완료 시 CSV 내보내기 + 복원 전 새 백업 생성 | 공용 PC 저장소 손실 위험 완화 |
| D10 검증 | 기밀 없는 가상 차지 2건 | 입력·정정·복원·보고서 흐름을 먼저 확인 |
| D16 설비 프로필 | 전로/랜스/저취 정보는 코드·단계 템플릿부터, 세부 보안 사양은 참조 문서로 관리 | 차지 입력 부담과 설비 정보 노출을 함께 줄임 |
| D17 보정 계수 | 계수값이 없으면 수치 종점 예상 비활성, 입력·비교 기능은 사용 가능 | 공개 수치를 현장 계수처럼 쓰지 않음 |

이 표의 권장안은 공정 기준이 아니라, 초기 기능 범위를 안전하게 좁히기 위한 제안이다.
