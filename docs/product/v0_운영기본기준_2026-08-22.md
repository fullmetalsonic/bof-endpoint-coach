# v0 운영 기본 기준

상태: 개발 기본안. 실제 조업 목표·성분·수율·출강 판단 수치는 포함하지 않으며, 현장 승인 전까지 비워 둔다.

## 1. 적용 범위

- 공용 PC의 오프라인 HTML에서 수동 입력으로 사용한다.
- 여러 차지를 동시에 진행 상태로 관리한다. 다만 한 번의 입력·비교·게이트 조작은 목록에서 선택한 **현재 작업 대상 차지 1개**에만 적용한다.
- 자동 제어, 자동 출강 지시, 목표 기준 자동 변경은 하지 않는다.
- 기준값·데이터가 부족할 때는 수치를 추정해 채우지 않고 `입력 확인 필요` 또는 `참고 이력 부족`을 표시한다.

## 2. 차지 상태 기본값

| 상태 | 의미 | 허용 동작 |
| --- | --- | --- |
| 초안 | 차지 ID 또는 기본값 입력 중 | 저장·수정·취소 |
| 진행 중 | 이벤트 입력과 품질 비교 진행 | 이벤트 추가·게이트 재확인 |
| 출강 완료 | 출강 결과까지 기록됨 | 정정 이벤트·보고서·백업 |
| 결과 검토 | 후속 결과 또는 예외 검토 중 | 정정 이벤트·결과 메모 |
| 취소 | 실제 조업 대상이 아니거나 잘못 만든 차지 | 취소 사유 열람·복원 불가 |

- 완료 차지는 덮어쓰지 않는다. 잘못된 입력은 정정 이벤트로 남긴다.
- 새 차지는 진행 중 차지 목록에 추가한다. 강제 종료·취소가 필요하면 사유를 남긴다.

## 3. 입력·시간 기본값

- 모든 이벤트는 `발생 시각`과 `기록 시각`을 함께 저장한다.
- 기본 시간 표시는 PC의 현지 시간과 시간대 정보를 함께 저장한다. 시간대는 코드에 고정하지 않는다.
- 과거 시각 입력, 같은 시각의 복수 이벤트, 시간 역전은 저장을 막지 않고 `시간 순서 확인`과 사유 입력을 요구한다.
- 숫자는 원본값·단위·환산값·환산 규칙 버전을 보존한다.
- 단위, 필수 값, 허용 자릿수, 음수·범위 역전은 저장 전에 검사한다. 현장 기준이 없는 수치 상한/하한은 임의로 막지 않는다.

## 4. 기준값·승인 기본값

- 실제 차지 비교·참고 계산에는 승인 상태의 강종군·재료·게이트·환산 규칙만 사용한다.
- 승인 기준을 바꾸면 새 버전을 만들며, 과거 차지는 당시 버전을 유지한다.
- 계정 없는 v0의 역할명 기록은 보안 권한이 아니다. 설정 변경·승인·CSV 가져오기에는 역할명·시각·사유를 남긴다.
- 기준값 파일을 외부에서 가져오는 방식은 보안/현장 승인 전에는 활성화하지 않는다.

## 5. 저장·백업 기본값

- 진행 중 입력은 브라우저 로컬 저장소에 즉시 저장하고, 저장 성공/실패와 마지막 저장 시각을 화면에 보인다.
- 차지 상태가 `출강 완료`로 바뀌면 전체 CSV 백업 묶음 만들기를 안내한다.
- 백업 생성, 다운로드 요청, 승인 폴더 보관 확인, 선택 파일 재검증은 서로 다른 이벤트로 남긴다.
- v0 복원은 빈 브라우저 저장소에서만 스키마·해시·참조 관계 미리보기 후 전부 반영 또는 전부 취소한다. 기존 이력 덮어쓰기·자동 병합·삭제는 금지한다.
- 백업 파일의 실제 선택 검증 결과와 데이터 건수를 표시한다.

세부 파일 구성과 복원·이력 규칙은 `CSV_백업복원_계약_v0_초안.md`를 따른다.

## 6. 품질·공정 정보 기본값

- 품질 화면의 후보는 C·온도·P·S·Mn·Si이며, 실제 화면에는 강종군에서 활성화되고 분석 가능한 항목만 표시한다.
- 강종 특화 합금·잔류·청정도 항목은 `성분 상세`에 표시한다.
- 취련 시간·누적 산소·재취련·투입 이력은 품질 성분과 합산하지 않는 공정 참고 정보다.
- 목표 범위, 실제 분석값, 참고 이력/예상값, 데이터 시점, 기준 버전은 서로 구분해 표시한다.

## 7. 이력 기반 참고 기능의 단계

| 단계 | 기능 | 활성 조건 |
| --- | --- | --- |
| v0.0 | 이력 수집·검색·목표 비교 | 승인된 기준과 수동 입력만 필요 |
| v0.1 | 유사 과거 차지의 결과 범위 표시 | `이력기반_참고예상_활성화기준_초안.md`의 데이터 품질 관문 통과 |
| 이후 | 현재 입력 기반 참고 예상 범위 | 현장 검토·검증된 예측 규칙/버전 승인 |

- 과거 이력이 추가돼도 강종군의 목표 범위는 자동으로 바뀌지 않는다.
- 참고 기능은 `참고`, 적용 이력 데이터 기간·건수·버전·제외 사유를 함께 표시한다.
- 시간 경과형 참고 예상은 수동 입력 사건과 PC 로컬 시간만으로 갱신하며, 자동 설비 데이터 수신으로 표현하지 않는다. 입력·표시 규칙은 `../domain/시간경과형_참고예상_입력규칙_초안.md`를 따른다.

## 8. 구현 수용 기준

- [ ] 진행 중 차지 2건 이상을 전환하며, 각 차지의 초안→진행 중→출강 완료/취소 흐름을 분리해 기록할 수 있다.
- [ ] 모든 이벤트·품질 비교·게이트 조작이 현재 작업 대상 차지에만 저장된다.
- [ ] 원본/환산값, 기준 버전, 발생/기록 시각, 정정 이력이 보존된다.
- [ ] 저장 실패·복원 오류·이력 부족을 정상 상태처럼 보이지 않는다.
- [ ] 목표 기준·실측값·참고 이력·예상값을 같은 값처럼 표현하지 않는다.
- [ ] 실제 공정 수치가 없어도 가상 데이터로 입력·정정·CSV 백업/복원 흐름을 검증할 수 있다.

동시 진행 차지의 화면·전환·백업 세부 규칙은 `../ui/동시진행_차지_전환규칙_초안.md`를 따른다.
