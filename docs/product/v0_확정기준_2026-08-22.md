# 취련 코치 v0 확정 기준

확정일: 2026-08-22  
범위: HTML 구현 전 설계 기준. 이 문서는 공정 수치나 조업 표준을 정하지 않는다.

## 1. 제품 경계

- v0은 공용 PC에서 동작하는 로컬 HTML 보조도구다.
- 회사 시스템, PLC, HMI, MES, LIMS와 연결하지 않는다.
- 자동 제어·설비 제어·강제 투입·강제 출강 지시를 하지 않는다.
- 표시 결과는 `참고`, `검토`, `확인 필요`로 표현한다.

## 2. 강종군·기준값 관리 기준

- 사용자는 강종군을 계속 추가할 수 있다.
- 새 강종군은 고유 코드와 표시명을 가지고 `초안`으로 생성한다.
- `초안`, `검토 요청`, `승인`, `중지` 상태를 사용한다.
- 승인 전·만료·중지 상태의 강종군/재료/환산 규칙은 실제 차지 계산에 사용하지 않는다.
- 승인된 기준을 바꾸면 기존 값을 덮어쓰지 않고 새 버전을 만든다.
- 이미 차지에 쓰인 강종군·재료·환산 규칙은 삭제하지 않고 중지 처리한다.
- 차지에는 적용 당시의 강종군·재료·게이트·환산 규칙 버전을 붙인다.

## 3. 계산 허용 기준

아래 중 하나라도 만족하지 않으면 수치 참고 계산을 하지 않고, 부족한 항목과 이유만 표시한다.

1. 선택한 강종군의 목표 성분·온도 범위가 승인 상태다.
2. 사용한 재료의 단위·대표 조성·분석 기준·수율이 승인 상태다.
3. 입력값의 단위가 확인되었고 허용된 환산 규칙이 있다.
4. 필요한 분석값에는 샘플 ID와 채취 시각·수신 시각이 있다.
5. 적용된 관리 게이트가 승인 상태다.

계산을 하지 않아도 차지 이벤트 기록·CSV 백업·누락 체크는 가능하다.

## 4. 단위·데이터 정합성 기준

- 입력 화면은 원본값·원본단위·환산값·표준단위·환산 규칙·환산 상태를 보관한다.
- 자동 환산은 kg↔t, wt%↔ppm, °C↔K, 초↔분처럼 추가 공정 조건이 없는 경우로 한정한다.
- 습식/건식, 원소/산화물, m³/Nm³, 질량분율/부피분율, 원소 함량/회수율은 승인된 조건식 없이는 변환하지 않는다.
- 단위 누락, 범위 역전, 변환 불가, 시점 불명 값은 계산에서 제외하고 확인 사유를 남긴다.

## 5. CSV 백업·복원 기준

- CSV는 v0의 원본 백업·복원 형식이다. UTF-8, 스키마 버전, 열 이름, 단위 표기 규칙을 포함해야 한다.
- CSV 가져오기는 실제 반영 전 `파일 정보 → 스키마 검사 → 행별 오류/중복 미리보기 → 사용자 확인` 순서로 진행한다.
- 가져오기는 한 번에 전부 성공하거나 전부 취소한다. 일부만 조용히 반영하지 않는다.
- v0의 기본 충돌 정책은 **기존 이력 덮어쓰기 금지**다. 동일 식별자 충돌은 `건너뜀` 또는 `전체 취소`만 제공한다.
- 병합·교체·자동 중복 해결은 v0에서 제공하지 않는다.
- CSV 내보내기에는 내보낸 시각, 스키마 버전, 적용 기준값 버전을 포함한다.

## 6. XLSX 보고서 기준

- XLSX는 작업자가 보는 결과·이력 보고서 형식이다.
- XLSX는 복원 원본이나 계산 기준값의 입력 형식으로 사용하지 않는다.
- 보고서에는 차지 정보, 이벤트 타임라인, 목표 대비 결과, 적용 기준값 버전, 계산/환산 상태를 포함한다.
- 보고서에는 `참고용 — 현장 표준 및 작업자 판단 우선` 문구를 포함한다.

## 7. 공용 PC 변경 이력 기준

- 계정 기능이 없는 v0에서도 설정 승인·중지·CSV 가져오기 시 `역할명`, `수행 시각`, `사유`를 필수 기록한다.
- 이 기록은 인증·권한 제어가 아니라 변경 추적을 위한 최소 장치다.
- 정식 도입에서는 사내 계정, 권한, 감사 로그를 사용한다.

## 8. v0 완료 판정 기준

HTML 구현 후 아래가 모두 충족되어야 v0 기능 완료로 판단한다.

| 검증 항목 | 완료 기준 |
| --- | --- |
| 강종군 관리 | 추가·복제·새 버전·중지·삭제 제한·중복 검사가 동작 |
| 설정 승인 | 초안/검토/승인/중지 상태가 계산 허용 여부를 정확히 제어 |
| 차지 이력 | G0~G8 이벤트의 시각·입력 누락·적용 버전이 보존 |
| 단위 | 허용 변환은 정확하고, 금지 변환은 계산에서 제외 |
| CSV | 정상 백업/복원, 스키마 오류·중복·취소 시 원본 무결성 보장 |
| XLSX | 사람이 읽을 수 있는 보고서와 기준 버전·주의 문구 출력 |
| 안전 경계 | 자동 제어·강제 지시 문구가 없고 기준 미승인 시 계산하지 않음 |
| 현장 검토 | 가상 데이터로 차지 1~2건 흐름을 취련사/관련 담당자와 확인 |

## 9. 아직 정하지 않은 공정 항목

다음은 도구의 설정 화면에 입력할 대상이지만, 현장 전문가 확인 전에는 값·공식을 정하지 않는다.

- 강종군별 목표/경고/중지 성분·온도 범위
- 재료별 실제 조성·수분·수율·분석 기준
- G0~G8의 현장별 필수 항목과 승인 주체
- 최신 분석값의 유효 시간 기준
- 재샘플·재취련·출강 검토의 실제 판단 수치
