# 이력 기반 참고 예상 활성화 기준 초안

상태: 현장 검토 전 개발 기본안. 이 문서는 목표 기준을 자동 변경하는 규칙이 아니다.

## 1. 목적과 경계

과거 차지 이력을 사용해 현재 차지와 비슷한 사례의 결과 범위나 참고 예상 범위를 보여 준다. 결과는 취련사 판단을 보조할 뿐, 투입·재취련·출강을 지시하지 않는다.

- 강종군 목표 범위는 과거 데이터로 자동 변경하지 않는다.
- 이력 추가만으로 예측 규칙을 자동 갱신하지 않는다.
- 참고값에는 데이터 기간, 유효 건수, 기준/예측 버전, 제외 사유를 표시한다.

## 2. 비교 가능 차지의 기본 조건

아래 값이 모두 맞거나, 현장 승인된 비교 규칙에 따라 동등하다고 판단된 차지만 같은 비교군으로 쓴다.

1. 같은 강종군과 적용 기준 버전 계열
2. 같은 설비/조업 조건 그룹
3. 비교하려는 공정 단계와 같은 샘플 단계
4. 필요한 품질값·단위·샘플 시점이 유효
5. 취소·무효·미완료 차지가 아님

재료·스크랩 조건, 취련 진행, 재취련 여부는 비교군을 더 좁히는 선택 조건으로 사용한다. 값이 없으면 추정하지 않고 비교 근거에서 제외한다.

## 3. 데이터 품질 관문

| 단계 | 최소 조건 | 화면 동작 |
| --- | --- | --- |
| 이력 수집 | 완료 차지 1건 이상 | 이력 검색·열람만 가능 |
| 이력 비교 | 비교 조건을 만족하는 유효 차지 5건 이상 | 유사 차지 목록과 개별 결과만 표시 |
| 참고 범위 | 비교 조건을 만족하는 유효 차지 20건 이상, 필수 입력 완결률 80% 이상 | 중앙값·사분위 범위 등 결과 범위를 `참고`로 표시 |
| 그림자 예상 | 비교 조건을 만족하는 완료 차지 50건 이상, 필수 입력 완결률 90% 이상, 이후 시점의 독립 검증 차지 20건 이상 | 계산 결과를 저장·오차 비교만 하며 작업자 판단 화면에는 표시하지 않음 |
| 참고 예상 | 그림자 예상의 사전 정의된 합격 기준 통과 및 현장 승인 | 현재 입력 기준의 예상 범위를 `참고 예상`으로 표시 |

`5건·20건/80%·50건/90%·검증 20건`은 v0의 보수적 개발 시작 기준이며, 공정 정확도 보증값이 아니다. 서로 다른 조업 조건군의 차지를 합쳐 건수를 채우지 않는다. 현장 검토에서 더 엄격하게 바꿀 수 있다.

그림자 예상 단계에서는 한 차지의 여러 샘플 시점을 여러 독립 차지처럼 세지 않는다. 같은 차지에서 나온 모든 시점 기록은 학습 또는 검증 중 한쪽에만 넣는다.

## 4. 결과 표시 규칙

- 유사 차지 목록: 차지 ID 대신 허용된 익명 식별자, 결과 시점, 핵심 품질 상태, 재샘플/재취련 여부를 표시한다.
- 참고 범위: 단일 평균보다 중앙값과 분포 범위를 우선한다.
- 참고 예상: 실제 분석값과 다른 표식·문구를 쓰고, `참고 예상(이력 기반)`으로 표시한다.
- 비교군이 부족하거나 데이터 품질 관문을 통과하지 못하면 숫자 대신 `참고 이력 부족: 사유`를 표시한다.
- 결과가 목표 범위를 이탈해도 도구는 자동 조치나 확정 작업 지시를 하지 않는다.

## 5. 예측 규칙 버전 관리

1. 새 이력이 쌓이면 검토 대상 기간을 고정한 `검토 후보 데이터 집합`을 만든다.
2. 과거 시점의 기록으로 규칙을 만들고, 그보다 나중에 완료된 차지로만 검증한다. 임의 섞기나 같은 차지의 시점 분할은 하지 않는다.
3. 기준선(최근 유효 분석값, 유사 차지 중앙값 등)과 후보 규칙을 같은 검증 자료로 비교한다.
4. 차이·오차·편향·허용범위 적중률·예상 불가율·제외 조건·데이터 기간을 기록한다.
5. 합격 후보는 그림자 예상으로 운용해 결과를 추가 확인한다.
6. 현장 검토 후 승인된 규칙만 새 차지 화면에 적용한다. 새 이력이 들어와도 자동 재학습·자동 배포하지 않는다.
7. 과거 차지에는 당시 사용한 이력 데이터 집합과 규칙 버전을 붙인다.

검증 절차와 합격 기준의 상세는 [종점 참고 예상 검증 및 승인 계획](종점참고예상_검증및승인계획_초안.md)을 따른다.

## 6. 활성화 전 검증

- [ ] 비교군 조건과 제외 규칙이 문서화됐다.
- [ ] 가상 또는 승인된 비기밀 이력 데이터로 입력 누락·재분석·정정·복원 시나리오를 확인했다.
- [ ] 계산식의 단위·경계값·반올림·입력 부족 처리를 가상 사례와 독립 손계산으로 대조했다.
- [ ] 예상 규칙은 시간 순서 독립 검증과 그림자 예상의 사전 합격 기준을 통과했다.
- [ ] 참고 범위/예상의 정확도 평가는 현장 담당자가 검토·승인했다.
- [ ] 화면이 목표 기준·실측값·이력 참고값·참고 예상값을 구분한다.
- [ ] 예상 불가·이력 부족 상태를 정상값처럼 표시하지 않는다.
