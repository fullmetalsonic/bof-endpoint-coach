# 종점 참고 예상 검증 및 승인 계획 초안

상태: 현장 검토 전 개발 기본안. 실제 종점 계산식, 합격 오차, 강종별 공정 계수는 이 문서가 정하지 않는다.

## 1. 핵심 원칙

누적 이력이 없을 때는 **종점 예측 정확도**를 검증할 수 없다. 이 시기에는 계산의 논리와 입력 처리만 검증한다. 실제 예측 정확도는 완료된 실제 차지의 종점 결과와 비교할 때만 평가한다.

따라서 검증을 아래 두 종류로 분리한다.

| 구분 | 검증 대상 | 누적 실제 이력 전 가능 여부 | 합격의 의미 |
| --- | --- | --- | --- |
| 계산 검증 | 단위 환산, 수식 구현, 반올림, 입력 부족·정정·시간 처리 | 가능 | 구현한 계산이 승인된 명세와 같은 결과를 낸다 |
| 예측 검증 | 계산 시점의 예상값과 실제 종점 성분·온도 차이 | 불가 | 특정 현장·강종군·조업 조건에서 참고값으로 쓸 근거가 있다 |

계산 검증 통과는 공정 예측의 정확도 보증이 아니다. 목표 기준값은 과거 이력이나 예측 규칙으로 자동 변경하지 않는다.

## 2. 누적 이력 전: 계산식 검증

실제 데이터가 없어도 아래의 가상 차지 시험 세트는 만들 수 있다. 모든 값은 실제 현장 수치가 아닌 승인 전 검증용 가상값을 쓴다.

1. **정상 입력**: 필수 입력이 모두 있고 단위도 일치하는 경우
2. **단위 변환**: kg/t, wt%/ppm, min/s 등 승인된 변환만 필요한 경우
3. **경계값**: 목표 범위의 하한·중앙·상한, 반올림 자릿수 경계
4. **입력 부족**: 필수 성분, 질량, 발생 시각 또는 기준 버전이 없는 경우
5. **시간 축**: 실제 이벤트와 계획 이벤트가 섞이고, 실제값이 계획값을 덮는 경우
6. **정정·무효**: 잘못 입력한 투입·샘플·분석을 새 정정 이벤트로 바꾼 경우
7. **복원 재현**: 백업 후 복원해도 같은 입력 스냅샷과 결과가 나오는 경우

각 시험에는 입력 원본, 단위, 승인된 손계산 결과, 기대 상태, 계산식/환산/기준 버전을 함께 남긴다. 현장 담당자가 손계산 또는 승인된 Excel 계산표와 대조하고, 개발자는 자동 시험 결과를 보관한다. 실제 공정 계수나 목표값이 승인되기 전에는 결과를 `참고 계산 불가`로 표시한다.

## 3. 누적 후: 예측 정확도 검증

### 3.1 단계

```text
기록·비교
→ 데이터 집합 고정
→ 과거 자료로 후보 규칙 작성
→ 이후 완료 차지로 독립 검증
→ 그림자 예상
→ 현장 승인
→ 참고 예상 표시
```

- **기록·비교**: 종점 결과를 아직 예측에 쓰지 않고 유사 사례·참고 범위만 본다.
- **데이터 집합 고정**: 사용한 차지 ID(또는 허용된 익명 ID), 기간, 제외 사유, 기준 버전을 고정한다.
- **독립 검증**: 과거 자료로 만든 후보 규칙을 더 나중에 완료된 차지에 적용한다. 같은 차지의 여러 샘플 시점은 한쪽 집합에만 둔다.
- **그림자 예상**: 각 정해진 검사 시점에 예상값·입력 스냅샷·시각·규칙 버전을 저장하지만, 작업자 판단 화면에는 표시하지 않는다. 종점 확정 뒤에만 오차를 계산한다.
- **승인**: 현장 담당자가 기준선 대비 개선, 위험 사례, 결측률, 적용 범위를 검토해 승인한다.

### 3.2 비교 기준선

후보 규칙은 최소 하나의 단순 기준선보다 좋아야 한다. 기준선은 현장에 따라 아래 중 승인된 것을 쓴다.

- 가장 최근에 채택된 유효 분석값
- 같은 강종군·조업 조건군의 유사 차지 중앙값
- 계산식이 없다면 `예상 불가`를 내는 안전 규칙

복잡한 이력 규칙이나 모델이 단순 기준선보다 낫지 않으면 참고 예상으로 올리지 않는다.

### 3.3 기록할 지표

성분·온도별로 별도 평가하며, 서로 성격이 다른 값을 하나의 점수로 합치지 않는다.

| 지표 | 뜻 | 활용 |
| --- | --- | --- |
| 절대오차 중앙값·평균 | 예상과 실제 종점의 차이 크기 | 일반적인 오차 수준 확인 |
| 편향 | 계속 높게 또는 낮게 예상하는 경향 | 보정 필요 여부 확인 |
| 허용범위 적중률 | 현장 승인 허용오차 안에 실제가 들어온 비율 | 현장 사용 가능성 판단 |
| 예상 범위 포함률 | 예상 범위 안에 실제가 들어온 비율 | 범위가 지나치게 좁거나 넓은지 확인 |
| 예상 불가율·필수값 누락률 | 예측을 못 낸 비율과 원인 | 입력 부담과 적용 범위 판단 |
| 재샘플·재취련·격외 결과 | 예상 표시가 작업 흐름에 준 영향 | 안전성·효과는 현장 검토로만 해석 |

허용오차, 최소 적중률, 최대 편향은 강종군·품질 항목·검사 시점별로 현장 승인값을 설정 화면에서 관리한다. 외부 논문의 오류 수치를 그대로 합격 기준으로 쓰지 않는다.

## 4. 데이터 충분성 기본 관문

| 목적 | 최소 관문 | 아직 하지 않는 일 |
| --- | --- | --- |
| 사례 열람 | 완료된 유효 비교 차지 5건 | 평균·예상 제시 |
| 참고 범위 | 유효 비교 차지 20건, 필수 입력 완결률 80% 이상 | 종점 예측 표시 |
| 그림자 예상 후보 | 유효 비교 차지 50건, 필수 입력 완결률 90% 이상, 이후 시점 독립 검증 차지 20건 이상 | 작업자 화면에 예측 표시 |
| 참고 예상 승인 | 그림자 결과가 사전 정의된 합격 기준을 충족하고 현장 승인 완료 | 목표 기준 자동 변경·자동 조치 |

위 `50건 + 이후 20건`은 **같은 강종군·기준 버전·설비/조업 조건 그룹** 안에서 세는 보수적 출발 기준이다. 큰 조업 변경, 분석 방법 변경, 기준 버전 변경, 재료 구성의 구조적 변경이 있으면 이전 이력을 그대로 합치지 않고 새 비교군 또는 재검증 대상으로 처리한다.

## 5. 예측 반영 방식

충분한 데이터가 쌓여도 새 기록을 즉시 자동 학습하거나 현재 차지의 예측을 조용히 바꾸지 않는다.

1. 새 완료 이력을 후보 데이터 집합에 추가한다.
2. 특정 기간을 고정해 후보 계산식/규칙을 다시 만든다.
3. 이후 시점의 독립 검증과 그림자 운용으로 기존 승인 버전·단순 기준선과 비교한다.
4. 합격·현장 승인 때만 새 `규칙 버전`을 배포한다.
5. 각 차지에는 사용한 규칙 버전·데이터 집합 기간·예상 시각·입력 스냅샷을 남긴다.

이 방식이면 데이터가 누적될수록 더 나은 후보를 시험할 수 있지만, 과거 보고서의 재현성과 현재 작업의 판단 근거는 유지된다.

## 6. 구현 전 결정이 필요한 값

- 강종군·설비/조업 조건 그룹의 비교 규칙
- 종점 실제값의 정의와 채택 분석 결과
- 품질 항목별 검사 시점, 허용오차, 최소 적중률, 최대 편향
- 단순 기준선의 선택과 예상 범위 산정 방법
- 그림자 예상 결과를 검토·승인·중지할 현장 역할

계산식의 입출력·단위·반올림·불확실성·가상 시험값은 별도 `계산명세` 문서로 확정해야 한다. 이 계획은 그 명세를 실제 현장 결과로 어떻게 검증하고 배포할지 정한 것이다.

## 7. 공개 자료가 주는 한계

공개 BOF 제어 교육 자료는 물질·열수지 기반 정적 모델과 실제 데이터에 의한 검증의 필요성을 설명한다. 학술 연구에서는 이론 모델과 데이터 기반 기법을 함께 쓰기도 하지만, 생산 조건 차이로 다른 제철소에 그대로 적용할 수 없다고 명시한다. 따라서 이 도구의 계산식·정확도 기준은 반드시 해당 현장의 이력과 현장 검토로 검증한다.
