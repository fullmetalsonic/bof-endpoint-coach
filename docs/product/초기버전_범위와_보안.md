# 초기 버전 범위와 보안 원칙

## 제품의 역할

취련 코치는 설비를 제어하거나 작업 지시를 내리는 제품이 아니다. 취련사가 직접 입력한 차지 이력과 현장 분석값을 정리하고, 등록된 기준값에 따라 **추가 확인이 필요한 상태와 참고 계산 결과**를 보여주는 개인·팀용 보조도구다.

## v0에서 하는 일

- 차지 번호별로 목표값, 장입/투입, 샘플, 분석, 추출 시각을 기록한다.
- 현재 분석값과 목표값의 차이를 보기 쉽게 표시한다.
- 승인된 가정값을 사용해 물질수지 기반의 참고 투입량 또는 범위를 계산한다.
- `분석 결과 대기`, `재샘플 검토`, `추출 검토`, `목표 범위 이탈` 같은 체크 상태를 보여준다.
- 입력 이력과 결과를 CSV로 내보내고 가져온다. CSV는 백업·복원의 기준 형식이다.
- 작업자가 보는 결과는 XLSX 보고서로 내보낸다. XLSX는 복원 원본으로 사용하지 않는다.
- 기준값 변경자·변경 시각·사유를 남긴다.

## v0에서 하지 않는 일

- PLC, 랜스, 산소 유량, 교반 가스, 투입 설비를 제어하지 않는다.
- MES, LIMS, 계량·분석 장비에서 데이터를 자동 수집하지 않는다.
- 회사 기초 데이터나 CSV를 외부 서버로 전송하지 않는다.
- 단일 숫자를 "반드시 투입" 또는 "지금 반드시 추출"로 표시하지 않는다.
- 현장 안전 절차·조업 표준·권한 체계를 대체하지 않는다.

## 공용 PC 운용 원칙

1. HTML 파일은 승인된 사내 메일 또는 승인 저장소에서만 반입한다.
2. 외부 CDN·웹 글꼴·분석 도구·클라우드 동기화를 쓰지 않는다. HTML은 단독으로 동작해야 한다.
3. 브라우저 저장소(IndexedDB)는 편의 기능일 뿐이다. 브라우저 초기화·정책 변경에 대비해 승인된 위치에 CSV를 정기적으로 내보낸다.
4. 실제 회사 데이터가 든 CSV는 프로젝트 소스 폴더·개인 메일·개인 클라우드·외부 저장소에 복사하지 않는다.
5. 차지번호·강종 코드도 회사 기준상 민감할 수 있으므로, 정식 도입 전에는 보안 담당 부서의 판단을 받는다.

## 표시 문구 원칙

- 권고 앞에는 `참고`, `검토`, `확인 필요`를 붙인다.
- 경고는 설비 경고처럼 보이지 않게 `이 도구의 입력 기준 경고`임을 함께 표시한다.
- 입력값이 오래되었거나 누락되면 계산보다 먼저 `입력 시각/항목 확인 필요`를 보인다.

## 정식 제안으로 확장할 때의 기준

- 현장 입력 부담, 기록 누락률, 재샘플·재취련, 목표 편차 등 효과를 익명/승인된 방식으로 측정한다.
- 효과가 확인된 후에만 사내망 서버, 계정·권한, MES/LIMS/계량/PLC 연동, 감사 로그를 포함한 정식 제안서를 검토한다.
