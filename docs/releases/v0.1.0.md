# 취련 코치 v0.1.0 / BOF Endpoint Coach v0.1.0

## 한국어

공개 문헌의 계산 구조와 합성 DEMO 데이터로 만든 오프라인 우선 초기 버전이다.

### 주요 기능

- 진행 중인 여러 차지를 전환하며 G0~G8 조업 흐름 관리
- 수동 입력한 장입·산소·샘플·분석 값을 이용한 종점 C·온도 참고예상
- 강종, 원료·부원료, 단위 환산, 설비·조업 조건, 계산 계수 설정
- IndexedDB 자동 저장과 CSV ZIP 백업·복원
- 작업자 확인용 XLSX 보고서 출력
- 한국어·영어 화면 및 단일 오프라인 HTML 제공

### 반드시 확인할 제한

이 버전은 실제 제철소 공정제어 시스템이 아니라 **참고예상용 보조 도구**다. 공개본의 설비 조건·계수·차지 데이터는 합성 예시이며, 실제 조업에 사용하기 전에 현장 승인 계수와 과거 차지를 이용한 그림자 검증이 필요하다. 자동 제어·출강 지시·품질 보증 용도로 사용하면 안 된다.

## English

This is an offline-first initial release built from public calculation structures and synthetic demo data.

### Highlights

- Switch between multiple active heats and manage the G0-G8 operation flow
- Reference endpoint C and temperature estimates from manually entered charge, oxygen, sample, and analysis data
- Editable grade, material, unit-conversion, equipment, operating-condition, and coefficient settings
- IndexedDB autosave plus CSV ZIP backup and restore
- XLSX operator report export
- Korean and English UI with a distributable single-file offline HTML

### Verification

- ESLint: PASS
- Vitest: 17 tests across 9 files PASS
- Standard Vite and single-file builds: PASS
- Offline hosting and routing: 4 tests PASS
- `npm audit --audit-level=high`: 0 vulnerabilities
- Browser core flows and console: PASS with 0 errors and 0 warnings

### Important limitation

This release is a **reference estimation aid**, not a plant process-control system. Equipment conditions, coefficients, and heat data in the public build are synthetic examples. Site-approved coefficients and shadow validation against historical heats are required before operational use. Do not use it for automatic control, tapping commands, or quality assurance.
