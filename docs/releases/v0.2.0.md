# 취련 코치 v0.2.0 / BOF Endpoint Coach v0.2.0

배포일 / Release date: 2026-08-22  
계산식 / Formula: `BOF-REF-CALC 0.2.0`

## 한국어

### 주요 변경

- 기존 합성 상수식을 공개 문헌 기반 C 산소수지와 축약 열수지로 교체했다.
- PCR, 열손실률, 종점 슬래그 FeO를 저·기준·고 시나리오로 계산한다.
- 채택 샘플 당시 누적 산소를 저장하고, 샘플 시점부터 계획 종점까지의 문헌 모델 변화량을 실제 C·온도에 더한다.
- 문헌 원본은 보존하며 `현장 승인 수정값 → 사용자 수정값(미승인 표시) → 문헌 원본값` 순서로 적용한다.
- 계수 설정 화면에서 문헌 원본, 수정값, 실제 적용값, 근거 ID, 승인자·승인 근거·승인 시각을 관리한다.
- 대시보드, Data Ledger, XLSX 보고서와 CSV 백업에 계산 근거와 적용 상태를 함께 남긴다.
- 앱 버전과 백업 스키마 버전을 분리해 v0.1.0 백업 호환성을 유지한다.

### 공개 근거

계수와 계산 골격은 저장소의 자료 ID `S12`, `S15`, `S41`, `S43`, `S44`에 연결된다. 문헌 저·고 출력은 정확도나 신뢰구간이 아니라 입력 조건에 따른 민감도 시나리오다.

## English

### Highlights

- Replaced synthetic constants with a public-literature oxygen mass balance for C and a reduced heat balance for temperature.
- Added low/base/high sensitivity scenarios for post-combustion ratio, heat loss, and endpoint slag FeO.
- Added sample anchoring using the cumulative-oxygen snapshot recorded with the adopted sample.
- Preserves literature originals and applies site-approved overrides, then unapproved user overrides, then literature originals.
- Exposes literature, override, effective value, source IDs, and approval metadata in the coefficient settings screen.
- Carries model basis and status into the dashboard, Data Ledger, XLSX report, and CSV backup.
- Separates the app version from the backup schema version to preserve v0.1.0 backup compatibility.

### Validation boundary

The software workflow and offline artifact are tested before publication, but endpoint accuracy has not been validated against completed plant heats or an approved plant calculation sheet. The low/high outputs are sensitivity scenarios, not confidence intervals. This tool does not replace process control, safety interlocks, SOPs, tap authorization, laboratory results, or operator judgment.
