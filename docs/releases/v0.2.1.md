# 취련 코치 v0.2.1 / BOF Endpoint Coach v0.2.1

앱 버전 / App version: `0.2.1`  
백업 스키마 / Backup schema: `0.2.0` (v0.1.0 restore supported)  
계산식 / Formula: `BOF-REF-CALC 0.2.0`

## 한국어

v0.2.1은 v0.2.0 운영 흐름 감사에서 확인된 차단 결함을 수정한 초기 실사용 흐름 버전입니다.

- 합성 DEMO 자동 생성 대신 작업자 이름과 빈 작업 시작을 첫 화면에 제공
- 우측 상단 고정 팀명을 제거하고 수정 가능한 작업자 이름을 이벤트·단계 이력에 저장
- 실제 시각을 입력하는 G0→G8 수동 단계 전환과 단계별 하단 버튼 활성 규칙 추가
- G5→G6 전환 전에 C·온도가 있는 채택 샘플을 요구하고, G6 출강 후 G7→G8 완료 흐름 구현
- 샘플·분석·체크포인트·재취련·출강 저장을 막던 `null.toLocaleString()` 오류 수정
- 신규 차지·자재·재취련 입력창의 임의 현장 수치 기본값 제거
- 가짜 단계 시각과 장식용 새로고침을 제거하고 로컬 저장·외부 미연동 상태를 명시
- DEMO/G0 초안 삭제, 진행 차지 취소, 완료 차지 보관, 초기화 확인과 1회 복구 구현
- 정적 금일 현황·알림을 실제 진행 차지와 계산 확인 항목으로 교체
- 참조되지 않는 추가 강종·재료 삭제 지원
- 백업에 작업자, 단계 전환, 생명주기 필드를 보존하고 v0.1.0 복원 호환 유지

현장 정확도는 아직 검증되지 않았습니다. 실제 분석, 사내 표준, 안전 인터록, 출강 승인과 취련사의 판단을 우선하십시오.

## English

v0.2.1 fixes the blocking operational-flow defects found in the v0.2.0 audit.

- Empty first run with editable operator identity and optional synthetic DEMO
- Manual, timestamped G0–G8 transitions with stage-aware action availability
- Adopted C/temperature sample gate before G6, tap at G6, and G7→G8 completion
- Fixed non-material event submission crash
- Removed invented numeric form defaults, fabricated stage times, and decorative refresh state
- Added heat delete/cancel/archive, confirmed reset, and one-slot recovery
- Replaced static Today/Alerts content with state-derived information
- Preserved operator, stage history, and lifecycle fields in backup schema v0.2.0 while accepting v0.1.0 backups

Endpoint accuracy remains unvalidated for plant operation. The tool does not replace controls, interlocks, SOPs, laboratory results, tap authorization, or operator judgment.
