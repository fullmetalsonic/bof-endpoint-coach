## 한국어

v0.2.2는 조업 정확도를 주장하는 버전이 아니라, 작업자가 DEMO를 시작할 수 있을 정도로 수동 입력·단계 진행·저장·복구 기능을 실패 조건까지 확장 검증한 후보입니다.

- 용선·스크랩·부원료의 kg·t·g와 성분의 %·wt%·ppm 입력을 내부 표준 단위로 환산하고 원래 단위도 보존
- 미래·시작 전·단계 역행 시각, 실제 시각의 공정 단계에서 허용되지 않는 입력 차단
- 감소하는 누적 산소, 중복 차지·샘플, 빈 분석, 음수·범위 밖 조성/온도/설비값 차단
- 목표 최소·최대가 비어 있는 신규 강종에서도 대시보드가 중단되지 않도록 표시 안전성 수정
- 출강 후 부원료가 출강 전 열수지 입력을 소급 변경하던 문제 수정
- 선택형 DEMO 이력의 시작·단계·샘플 시각과 채택 샘플 정합성 수정
- 금일 현황을 진행 차지와 오늘 종료 차지로 계산하고, Data Ledger의 분석 시각은 실제 분석 완료 시각만 표시
- 백업 manifest의 필수 파일 집합·중복·해시·행 수와 복원 상태의 참조·단계·샘플·수치 정합성 검사
- 백업·복원·Excel 실패를 화면과 운영 로그에 남기고 같은 복원 파일 재선택 허용
- Playwright 조업 회귀시험을 CI에 추가

기능 검증은 통과했지만 실제 BOF 종점 C·온도 정확도는 아직 검증되지 않았습니다. 실제 분석, 사내 표준, 안전 인터록, 출강 승인과 취련사의 판단을 우선하십시오.

## English

v0.2.2 hardens the manual operating workflow for worker-run DEMO evaluation. It does not claim plant endpoint accuracy.

- Normalizes kg/t/g mass and %/wt%/ppm chemistry while preserving source values and units
- Rejects future, pre-start, reversed-stage, and stage-incompatible event timestamps
- Rejects decreasing cumulative oxygen, duplicate heat/sample IDs, empty analysis, and invalid physical ranges
- Prevents blank grade targets from crashing the dashboard
- Prevents post-tap additions from retrospectively changing the pre-tap heat balance
- Corrects synthetic DEMO timeline and adopted-sample consistency
- Shows actual completed analysis time in Data Ledger and derives Today from active and closed-today heats
- Validates backup file set, manifest hashes, row counts, references, timelines, and value ranges before restore
- Adds repeatable Playwright operational regression tests to CI

Plant accuracy remains unvalidated. The tool does not replace controls, interlocks, SOPs, laboratory results, tap authorization, or operator judgment.
