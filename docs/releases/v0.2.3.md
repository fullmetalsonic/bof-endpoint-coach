## 한국어

v0.2.3은 수동 입력형 스마트 계산기의 조작 경로를 인간공학적으로 보강한 버전입니다. 계산식과 현장 정확도를 새로 주장하는 버전이 아닙니다.

- 중앙에 `현재 해야 할 일`, 단계별 진행 순서, 완료 수, 종점 예상 상태, 다음 단계를 묶은 작업 안내판 추가
- G0 기초값부터 G8 완료까지 저장 이력에 따라 현재 작업이 실제로 바뀌는 단계별 안내 로직 추가
- 현재 권장 입력과 같은 하단 버튼에만 `지금 입력` 표시
- 아직 수행하지 않은 다음 단계 전환은 흰색 보조 버튼으로 분리해 주 행동과 시각적 우선순위 구분
- 차지 생성 뒤 기초 입력값을 수정하고 작업자·수정 시각을 이력에 남기는 기능 추가
- 입력 필드를 `필수`, `계산 핵심`, `정확도 권장`, `선택`으로 구분
- 저장·재계산·단계 이동 결과를 화면 알림으로 확인
- 상단 다음 행동, 중앙 작업, Data Ledger 확인 항목을 같은 동적 안내 기준으로 통일
- 최근 공정 입력보다 계산 시각이 과거로 보일 수 있던 최신성 표시 수정
- 한국어와 영문 모두 1920×1080, 확대 100%에서 가로·세로 넘침 없이 한 화면에 맞춤

## English

v0.2.3 improves the ergonomics of the manual smart-calculator workflow. It does not change the public formula version or claim plant accuracy.

- Adds a central work panel for the current task, stage sequence, completion count, endpoint status, and next stage
- Changes the recommended task dynamically from G0 initial inputs through G8 completion
- Highlights only the matching persistent action with `Enter now`
- Separates a not-yet-recommended stage transition as a secondary action
- Allows initial heat inputs to be corrected with operator and timestamp audit history
- Classifies fields as required, calculation core, accuracy recommended, or optional
- Confirms saves, recalculation, and stage moves with visible notices
- Aligns the header next action and Data Ledger with the same workflow state
- Fits both Korean and English dashboards within 1920×1080 at 100% zoom without horizontal or vertical overflow
