# 취련 코치 v0.3.0 / BOF Endpoint Coach v0.3.0

작성일: 2026-08-23  
상태: 로컬 배포 후보 검증 완료, GitHub Release 미게시, 이메일 미발송

## 한국어

v0.3.0은 수동 입력 중 생긴 오입력을 원본 삭제 없이 복구하고, 그 변경이 현재값·종점 참고예상·백업·보고서에 일관되게 반영되도록 만든 정정·이력 관리 버전입니다.

### 주요 변경

- 최근 분석과 전체 타임라인에서 이벤트·분석 `수정`과 `무효` 지원
- 유효·정정됨·무효 상태, 원본/대체 ID, 사유, 입력자, 실제 발생/기록 시각 보존
- G1~G6에서 정확히 한 번만 가능한 `마지막 단계 전환 취소`
- G7·G8 전용 `출강 기록 정정`
- 한 샘플의 복수 분석 결과 보존, 명시적 채택 결과 선택
- 출강 후 종점 실제값 지정과 출강 시점 C·온도 예상 오차 비교
- 입력·단계·정정 뒤 예상 스냅샷 누적
- 차지 시작 시 강종·설비·계수 프로필 고정 스냅샷
- 백업 스키마 0.3.0과 XLSX `Corrections`, `Predictions` 시트
- 모든 실제 시각 입력을 초 단위로 표시하고, 시각을 수정하지 않은 정정은 원본 ISO 시각을 그대로 보존

### 안전·품질 경계

- 공개 계산식 `BOF-REF-CALC 0.2.0`과 문헌 시나리오는 바뀌지 않았습니다.
- P·Mn·Si·S 종점 예상은 현장 승인식이 없어 계속 비활성입니다.
- 실제 BOF 종점 정확도와 현장 사용 적합성은 검증되지 않았습니다.
- 정정 이력은 인증·권한 통제가 아닙니다. 작업자 표시명은 사용자가 입력한 문자열입니다.
- 설비 제어, 안전 인터록, 표준작업, 실험실 분석, 출강 승인, 취련사 판단을 대체하지 않습니다.

## English

v0.3.0 adds a correction-ledger subsystem so manual-entry errors can be recovered without deleting originals and all affected projections, backups, and reports remain consistent.

### Highlights

- Correct or void recent and historical event/analysis records.
- Preserve active, superseded, and voided states with replacement links, reasons, operator snapshots, and timestamps.
- Undo exactly one G1–G6 stage transition; no multi-stage rewind.
- Correct tap records separately at G7/G8.
- Preserve multiple analyses per sample and explicitly adopt the result used by the reference estimate.
- Select an actual endpoint result after tapping and compare it with the tap-time C/temperature prediction snapshot.
- Freeze grade, equipment, and coefficient references per heat.
- Backup schema 0.3.0 and XLSX Corrections/Predictions sheets.

The public formula remains `BOF-REF-CALC 0.2.0`; endpoint accuracy is not plant-validated.
