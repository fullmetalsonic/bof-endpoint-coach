# 취련 코치 v0.5.0 / BOF Endpoint Coach v0.5.0

## 한국어

v0.5.0은 공개 문헌모델에서 시작해 실제 사용 오차를 안전하게 축적하고, 사람이 검토할 보정계수 후보를 만드는 학습형 종점 참고예상 버전입니다.

### 주요 변경

- C·온도·P·Mn·Si·S 여섯 항목의 종점 수치 참고예상
- 각 중간 샘플의 문헌 궤적 기대값·실측·오차 비교
- 최신 채택 분석 하나만 현재 종점에 재고정하여 다중 샘플 이중보정 방지
- 출강 직전 예상과 출강 후 확정 실제값의 6항목 오차대장
- 강종·설비·계산식·계수버전·DEMO/실제별 비교군 분리
- 실제 같은 그룹 1~9/10~29/30~49/50~69/70+ 단계형 계수추천 관문
- 70건 이상에서 앞쪽 `n−20` 학습, 최신 20건 독립 검증
- 추천값 자동 적용 금지, 설정 초안 전달·변경 사유·승인 상태 확인
- 계수 변경·복구마다 날짜형 새 버전 생성, 과거값·사유·작업자 보존
- CSV ZIP 복원 파일 9종과 XLSX 보고서 9개 시트
- 기능·UI·UX·문구·회귀 감사 화면 26개 보존, 그중 25개를 초상세 설명서에 사용

### 사용 순서

1. `BOF_Endpoint_Coach_v0.5.0.html`을 Edge 또는 Chrome에서 엽니다.
2. 작업자 표시명을 입력하고 DEMO 또는 빈 작업을 선택합니다.
3. 실제 입력 전 강종·재료·설비·계수를 검토합니다.
4. 신규 차지의 실제 G0 값을 넣고 중앙 `현재 해야 할 일`을 따릅니다.
5. 샘플 시점 누적 산소와 분석값을 기록합니다.
6. 출강 후 확정 분석을 `종점 실제값`으로 지정합니다.
7. `학습 · 계수`에서 오차와 검토용 후보를 확인합니다.
8. 교대·설정 변경 전 CSV ZIP을 백업합니다.

## English

v0.5.0 extends the offline manual-entry assistant into a governed learning loop: public-literature estimates, per-sample trajectory residuals, confirmed endpoint residuals, review-only coefficient candidates, and immutable dated coefficient history.

The release estimates C, temperature, P, Mn, Si, and S. It never auto-applies a recommendation, changes a grade target, or deploys a coefficient. DEMO and historical-version residuals are blocked from current field application. A CSV ZIP remains the integrity-checked restore format; the nine-sheet XLSX is report-only.

All plant accuracy remains unvalidated. Use this release only for synthetic DEMO and controlled shadow-operation preparation until real completed heats, independent validation, and site approval are available.
