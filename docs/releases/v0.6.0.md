# v0.6.0 — Offline learning lifecycle and verified JSON recovery

Release date: 2026-08-23

## 한국어

v0.6.0은 v0.5의 문헌기반 6성분 종점 참고예상과 현장 승인형 계수추천을, 실제로 누적·복원·설명할 수 있는 오프라인 운영 기반으로 확장한 버전입니다.

### 주요 변경

- IndexedDB v2 자동저장, 저장 상태·시각·개정 번호 표시
- 다른 창의 오래된 상태가 최신 작업을 덮어쓰지 못하도록 충돌 감지
- 중요 작업 전 내부 복구점과 보호 복구점, 20개·30일 일반 보존정책
- SHA-256·스키마·건수·참조 검증을 포함한 단일 JSON 저장·불러오기
- 현재 데이터/가져올 데이터 비교, 전체 교체 전 보호, 7일 즉시 되돌리기
- 잘못된 구형 복구점을 삭제하지 않고 복원·외부백업에서 격리
- 성분별 학습실행 해시, 포함·제외 차지, 사용 설정·계수버전, 최신·오래됨 상태
- `문헌 기본 → 최신 유효 샘플 보정 → 승인 현장보정 → 최종 참고예상` 설명
- 1920×1080 전문 업무형 화면 유지, 1280·760 재배치와 긴 입력창 고정 하단 행동바
- 28개 실제 화면을 포함한 초상세 처음사용자 설명서

### 바로 사용하기

1. `BOF_Endpoint_Coach_v0.6.0.html`을 Edge 또는 Chrome에서 엽니다.
2. 처음 실행에서 작업자 이름을 입력하고 DEMO 연습 또는 빈 작업을 선택합니다.
3. 기준 정보에서 공개 문헌 DEMO 기준을 확인한 뒤 신규 차지를 만듭니다.
4. 화면의 `지금 입력` 버튼과 G0→G8 순서에 따라 실제 발생값을 입력합니다.
5. 교대·중요 변경 전 `분석 · 리포트`에서 전체 JSON을 저장합니다.
6. 현장 데이터 사용 전 `SECURITY.md`와 초상세 설명서의 안전 경계를 확인합니다.

## English

v0.6.0 turns the v0.5 literature-based six-target endpoint reference and approval-gated coefficient recommendations into a durable offline learning workflow.

Highlights:

- IndexedDB v2 autosave with visible status, timestamp, and revision conflict detection
- Internal and protected recovery points before consequential operations
- One-file JSON backup with schema, SHA-256, count, reference, time, and value validation
- Preview-before-replace, protected pre-restore state, and seven-day immediate undo
- Reproducible training runs with dataset/run hashes, included/excluded heats, and current/stale status
- Per-element explanation from literature baseline through sample and approved field correction
- Professional 1920×1080 workflow, 1280/760 responsive states, and sticky actions in long forms
- A detailed first-user guide containing 28 verified application screenshots

Validation passed ESLint, 127 unit/integration tests, four Sites tests, and 23 end-to-end tests in each of Chromium, installed Chrome, and installed Edge. A 1,000-heat JSON round trip passed, and `npm audit` reported zero vulnerabilities.

Plant-PC policy, novice participant observation, and real BOF endpoint accuracy remain unverified. The tool does not replace plant control, safety interlocks, standard work, tap authorization, or operator judgment.
