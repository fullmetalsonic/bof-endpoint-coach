# v0.6.1 — Coefficient emergency recovery card

Release date: 2026-08-23  
Email delivery is not part of this release work.

## 한국어

v0.6.1은 IndexedDB와 전체 JSON을 모두 사용할 수 없는 최악의 상황에서, 미리 남겨 둔 사진·인쇄물·수기 기록으로 **현재 적용 보정계수 핵심 6개를 안전하게 다시 입력**할 수 있도록 v0.6.0을 보강한 버전입니다.

### 주요 변경

- C·온도·P·Mn·Si·S 현재 적용 오프셋 6개를 한 장에 표시
- 선택 학습 실행의 당시값·추천 증감·추천 후보값 18개를 더한 상세 최대 24개 보기
- 계수 프로필·계수버전·계산식·기준지문 12자리·확인코드 8자리·복구문자열 표시
- 화면 캡처, 표 복사, 복구문자열 복사, 인쇄/PDF용 레이아웃
- 문자열 붙여넣기 또는 수기 입력, 오탈자·범위·식별정보·상세값 산식 검사
- 현재 계수와 비교한 뒤 설정 초안으로만 반영하고, 일반 설정 저장으로 새 버전 생성
- 카드 복구 뒤 다시 직접 수정하거나 새 추천을 적용하면 오래된 카드 출처를 현재 출처로 남기지 않음
- JSON 백업 스키마는 `0.6.0`을 유지하면서 선택형 수동복구 출처 메타데이터를 검증·보존
- 기존 `초상세 설명서`의 새 버전 명칭을 `상세 설명서`로 변경하고 실제 화면 34개 포함
- 10~15분 발표 흐름, 화면별 대본, 30초 요약과 예상 질문·답변을 담은 발표용 설명서 추가

### 복구 경계

- 카드가 직접 복구하는 값은 핵심 6개 오프셋뿐입니다.
- 상세 18개는 사람이 학습 당시 상태를 참고하기 위한 값이며 오차대장·학습실행·데이터 해시를 만들지 않습니다.
- 카드 계수버전이 초기화된 작업공간의 현재버전과 달라도, 같은 프로필 ID·계산식·문헌 기준지문이고 확인코드가 맞으면 복구할 수 있습니다.
- 차지·이벤트·샘플·분석·종점 실제값·설정 전체·계수 이력을 복구하려면 단일 JSON이 필요합니다.
- 12자리 기준지문과 8자리 확인코드는 수기 오탈자·잘못된 카드 혼합을 찾기 위한 축약 검사값이며 전자서명이나 암호화가 아닙니다.

### 바로 사용하기

1. `학습 · 계수` 또는 `기준 정보 → 계산 · 보정 계수`에서 `비상복구 카드`를 엽니다.
2. 핵심 6개 카드의 프로필, 계산식, 기준지문, 확인코드, 부호와 소수점을 함께 기록합니다.
3. 복구가 필요하면 `수동 복구 입력`에서 문자열을 붙여넣거나 카드값을 입력합니다.
4. `값 검사하고 현재 계수와 비교`로 차이를 확인합니다.
5. `검증된 값을 계수 초안에 반영`한 뒤 설정 화면에서 변경 사유와 값을 다시 확인합니다.
6. `설정 저장`을 눌러 새 계수버전을 만든 뒤 최신 전체 JSON을 저장합니다.

## English

v0.6.1 adds an analog last-resort recovery path for the six applied endpoint offsets: C, temperature, P, Mn, Si, and S. An optional detailed view records 18 learning-reference values, but those values never recreate lost heats, residuals, training runs, or approval evidence.

Manual recovery verifies profile identity, formula, a 12-character base fingerprint, an 8-character core check code, value ranges, and optional learning equations. It then compares against current offsets and creates a settings draft. The normal settings-save workflow is still required to create a new coefficient version.

Validation passed ESLint, 137 unit/integration tests, four Sites tests, and 26 end-to-end tests in each of Chromium, installed Chrome, and installed Edge. The application remains an unvalidated public-literature reference assistant and does not replace plant control, interlocks, laboratory results, tap authorization, or operator judgment.
