## 한국어

### 핵심 변화

- 대시보드 한 줄의 선택형 `투입 코치`가 Flux·냉각재·합금·가탄재·추가 산소의 참고량과 시점을 계산합니다.
- 작업자의 수기 계획, 코치 참고안, 실제 투입을 서로 덮어쓰지 않는 별도 버전 이력으로 관리합니다.
- 투입 코치를 열거나 채택하지 않아도 G0~G8 진행을 막지 않습니다.
- Flux, Coolant/Ore, Alloy/Carburizer, Oxygen, Timing 모델과 주안·대안 조정기를 기능별 모듈로 분리했습니다.
- 문헌 시험계수로 즉시 계산하되, 실제 투입 전·후 분석이 연결되면 `실제 변화 − 예상 변화` 오차를 별도 원장에 축적합니다.
- 10/30/50/70건, 최신 20건 독립검증, 최소 10일·작업자 3명·투입량 3구간·시점 3구간을 통과한 경우에만 승인 검토 가능한 투입계수 후보가 됩니다.
- 추천 후보는 자동 적용되지 않고 설정 초안·변경 사유·사람 승인·새 버전 저장을 거칩니다.
- 핵심 투입 보정값 6개를 `BOFARC1` 문자열, 화면, 인쇄, 수기로 보관·복구하는 비상카드를 추가했습니다.
- IndexedDB, 단일 JSON, CSV·Excel, 설정 이력과 구형 v0.6 마이그레이션에 투입 코치 자료를 포함했습니다.
- 모델 오류를 해당 계산으로 격리하는 앱 오류 경계와 미저장 투입계획 초안 보존을 추가했습니다.

## English

### Highlights

- An optional one-line addition coach estimates reference amount and timing for fluxes, coolants, alloys, carburizers, and additional oxygen.
- Operator plans, coach proposals, and actual additions are separate versioned records; the coach never blocks G0–G8 progression.
- Independent flux, coolant/ore, alloy/carburizer, oxygen, and timing modules start from literature-test coefficients.
- Valid pre/post-addition results create a separate actual-minus-predicted effect residual ledger.
- Candidate gates require row count, a latest-20 holdout, time, operator, amount-band, and timing-band coverage; candidates are never auto-applied.
- A BOFARC1 emergency card preserves six applied amount, timing, and effect corrections and restores verified values into a settings draft only.
- IndexedDB, canonical JSON, CSV/Excel, settings history, and legacy v0.6 migration include the new records.

### Boundary

These are unvalidated planning references, not operating instructions or actual addition events. Plant standards, laboratory results, interlocks, tap authorization, and operator judgment always take priority. Real BOF addition accuracy remains N/A until completed-heat shadow validation.
