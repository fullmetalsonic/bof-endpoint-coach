# 취련 코치 v0.7.3 / BOF Endpoint Coach v0.7.3

릴리스일: 2026-08-24

## 한국어

### 변경 사항

- 분석 결과 창에 접힌 `추가 측정값`을 추가했습니다.
- 용존산소 `[O]`를 ppm으로 선택 기록하고 산소 프로브·분석실·기타 출처와 메모를 함께 보존합니다.
- 공란은 `미측정`, 숫자 0은 `0 ppm 측정값`으로 분리합니다.
- O 단독 분석은 이력에 저장하되 기존 채택 성분분석과 종점예상을 자동 교체하지 않습니다.
- 전체 이력에서 측정값·미측정을 확인하고 기존 수정·무효·정정 사유 흐름을 사용할 수 있습니다.
- IndexedDB, 전체 JSON, 호환 CSV, Excel에 상태·값·출처·메모를 보존합니다.
- v0.7.2 이하 백업은 용존산소 미측정으로 하위 호환 복원합니다.
- 새 화면 5장을 포함한 한영 요약·상세·발표·구두 소개·README HTML을 갱신했습니다.

### 현재 계산 경계

용존산소는 v0.7.3에서 **기록 전용**입니다. 현재 C·온도·P·Mn·Si·S 종점예상, 투입 코치, G단계 진행, 종점·투입 학습계수에는 사용하지 않습니다. 현장 데이터 분포와 승인된 식이 확보된 뒤 별도 검증으로 계산 활용 여부를 판단합니다.

## English

### Changes

- Added a collapsed optional measurement section to the analysis dialog.
- Records dissolved oxygen `[O]` in ppm with an optional probe/laboratory/other source and note.
- Blank is stored as **not measured**, distinct from a measured numeric value of 0 ppm.
- An oxygen-only analysis is preserved in the ledger without replacing the adopted chemistry analysis or changing endpoint estimates.
- Timeline correction/void workflows, IndexedDB, canonical JSON, compatibility CSV, and Excel preserve status, value, source, and note.
- Pre-v0.7.3 backups migrate the missing field as not measured.
- Updated bilingual quick, detailed, presentation, oral-introduction, and README HTML documents with current screenshots.

### Calculation boundary

Dissolved oxygen is record-only in v0.7.3. It does not affect endpoint estimates, addition coaching, stage gates, or endpoint/addition learning coefficients. Any future calculation use requires a separate field-data and approval process.
