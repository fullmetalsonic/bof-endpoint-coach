# 종점 참고예상 계수 문헌 근거 매트릭스

조사일: 2026-08-22  
상태: 공개 문헌·공식 물성자료 기반의 초기 근거 정리. 현장 승인값이 아니다.

## 1. 결론

공개 자료는 초기 계산에 실제로 사용할 수 있다. 다만 역할을 다음처럼 나눠야 한다.

| 등급 | 뜻 | 초기 버전 처리 |
| --- | --- | --- |
| A — 물리·화학량론 | 기준조건, 원자량, 반응식으로 재현 가능한 값 | 출처와 기준조건을 고정한 뒤 계산에 사용 가능 |
| B — 문헌 참고범위 | 공개 연구에서 범위와 적용 조건이 함께 제시된 값 | 단일 기본값이 아니라 저·기준·고 민감도 시나리오로만 사용 |
| C — 현장 보정 필요 | 설비, 강종, 장입, 랜스, 슬래그, 시간 등에 따라 달라지는 값 | 현장 입력 또는 이력 검증 전에는 수치 예상에 사용하지 않음 |
| D — 합성 DEMO | UI·코드 흐름 검증을 위해 만든 값 | 공개 DEMO에서만 사용하고 현장용 프로필로 복제·승격 금지 |

따라서 연구자료의 첫 번째 결과는 `숫자 하나`가 아니라 **상수, 참고범위, 현장 보정값의 경계**다.

## 2. Nm³와 산소 질량 환산

`Nm³`는 온도·압력 기준이 함께 있어야 완전한 단위다. IUPAC의 현재 표준상태는 0 °C, 100 kPa이며, 과거 및 일부 산업 관행에서는 0 °C, 101.325 kPa가 쓰인다.

산소 몰질량 31.9988 g/mol과 이상기체 몰부피를 사용하면 다음과 같다.

| 기준조건 | O₂ 환산값 | 판정 |
| --- | ---: | --- |
| 0 °C, 101.325 kPa | 약 1.4276 kg/Nm³ | 현재 DEMO의 `1.429`와 거의 일치 |
| 0 °C, 100 kPa | 약 1.4090 kg/Nm³ | IUPAC 현재 표준상태 기준 |

결론:

- `1.429 kg/Nm³`는 무조건 고정할 값이 아니라 **0 °C, 101.325 kPa로 정의했을 때만** A등급으로 쓸 수 있다.
- 설정에 `normalTemperatureC`, `normalPressureKPa`, `oxygenPurityFraction`을 추가하고 환산값은 계산해야 한다.
- 회사 계량계·PLC가 쓰는 보정 기준조건을 확인하기 전에는 서로 다른 Nm³ 값을 조용히 합치면 안 된다.

근거:

- [IUPAC Gold Book — standard conditions for gases](https://goldbook.iupac.org/terms/view/S05910)
- [NIST Chemistry WebBook — Oxygen](https://webbook.nist.gov/cgi/cbook.cgi?ID=C7782447&Mask=1)

## 3. 탄소와 산소의 화학량론

탄소가 CO 또는 CO₂가 되는 이론 반응만 보면 다음 값은 계산으로 정할 수 있다.

| 반응 | 탄소 제거량 / O₂ 질량 | O₂ 필요량 / 탄소 질량 |
| --- | ---: | ---: |
| `2C + O₂ → 2CO` | 약 0.7507 kg-C/kg-O₂ | 약 1.3321 kg-O₂/kg-C |
| `C + O₂ → CO₂` | 약 0.3754 kg-C/kg-O₂ | 약 2.6641 kg-O₂/kg-C |

현재 `carbonRemovalKgPerKgO = 0.75`는 CO만 생성되고, 탄소에 배분된 산소가 모두 반응한다는 조건의 이론 상한에 가깝다. 실제 BOF에서는 Si·Mn·P·Fe 산화, 미사용 산소, 슬래그, CO 후연소, 광석·냉각재가 공급하는 산소가 함께 존재한다. 그러므로 `0.75`를 실제 탈탄효율 계수로 쓰면 안 된다.

원소별 산소 소비를 질량수지로 분리할 때 쓸 수 있는 이론계수는 다음과 같다.

| 이상 반응 | 이론 O₂ 소비량 |
| --- | ---: |
| `Si + O₂ → SiO₂` | 약 1.1394 kg-O₂/kg-Si |
| `2Mn + O₂ → 2MnO` | 약 0.2912 kg-O₂/kg-Mn |
| `4P + 5O₂ → 2P₂O₅` | 약 1.2914 kg-O₂/kg-P |
| `2Fe + O₂ → 2FeO` | 약 0.2865 kg-O₂/kg-Fe |

이 값은 반응식의 화학량론이며 실제 산화량 자체는 아니다. 실제로 얼마나 산화되는지는 초기·종점 성분, 슬래그 FeO, 철손실, 교반과 조업 조건이 필요하다.

문헌의 산소수지 구조는 다음 항을 분리한다.

```text
필요 O₂ = Σ(산화 원소량 × 원소별 O₂ 소비계수)
          + 미사용 배가스 O₂
          + CO 후연소 O₂
          − 광석·산화물에서 공급된 O₂
```

따라서 현재의 고정 절대값 `otherOxygenKg`는 아래 항으로 나누는 것이 맞다.

1. Si·Mn·P·Fe 등 원소별 산화 산소량
2. 슬래그/철손실과 연결된 산소량
3. 미사용 배가스 산소량
4. CO 후연소 산소량
5. 광석·산화물 냉각재 등 승인된 외부 산소원이 공급한 유효 산소량

재료에 산소 원자가 포함됐다는 이유만으로 전부 탈탄용 산소로 계산하지 않는다. 재료 조성, 산화물 형태, 환원 가능 범위와 반응 경로가 정의된 항만 `외부 산소원`으로 인정한다.

탄소 제거량을 역산할 때는 아래 두 방식 중 하나만 선택한다.

- `PCR 포함 방식`: C 이외 산화와 미사용 산소만 제외한 C 관련 산소에 `βC(PCR)`를 적용한다.
- `후연소 분리 방식`: CO 후연소 산소까지 별도로 제외한 뒤 CO 화학량론 `0.7507 kg-C/kg-O₂`를 적용한다.

후연소 산소를 빼고 다시 `βC(PCR)`를 적용하면 같은 영향을 두 번 반영하므로 금지한다.

- [BOF 종점 탄소 예측 리뷰 — 산소수지식](https://www.degruyterbrill.com/document/doi/10.1515/htmp-2020-0098/html?lang=en)
- [Hybrid Method for Endpoint Prediction in a BOF — 탄소/산소수지](https://www.mdpi.com/2075-4701/12/5/801)

## 4. CO 후연소비와 산소수지 시나리오

`Hybrid Method` 연구는 문헌 범위로 PCR(post-combustion ratio) 0.10~0.22를 검토하고 해당 데이터셋에서 0.15를 선택했다. `General heat balance` 연구의 330 t 복합취련 전로 35차지는 PCR 0.10~0.14였고 계산에는 0.12를 사용했다.

판정:

- `0.10~0.22`는 B등급 문헌 민감도 범위로 기록할 수 있다.
- `0.15` 또는 `0.12`를 다른 설비의 기본 PCR로 확정하면 안 된다.
- PCR은 탄소 제거량과 반응열 모두에 영향을 주므로 C 계산과 온도 계산이 같은 PCR 시나리오를 사용해야 한다.
- 논문·현장마다 PCR의 분자·분모와 공기 유입 보정 기준이 다를 수 있으므로, 정의식과 가스 기준을 값과 함께 저장한다.

## 5. 열수지

공개 연구가 제시하는 기본 구조는 다음과 같다.

```text
용선의 현열 + C·Si·Mn·P·Fe 등의 산화반응열
= 용강·슬래그·배가스의 현열
 + 스크랩·광석의 승온/용해열
 + 열손실
```

이 구조에서는 다음을 각각 계산한다.

- 용선·스크랩·용강·슬래그·배가스의 온도별 열용량 적분
- 스크랩의 상변화와 잠열
- C→CO/CO₂, Si→SiO₂, Mn→MnO, P→P₂O₅, Fe→FeO 반응열
- 재료별 투입 온도와 조성
- 슬래그·배가스 온도 가정
- 설비·대기시간·장입비에 따른 열손실

따라서 `산소 1 Nm³당 반응열`, `모든 스크랩 1 kg당 열`, `모든 Flux 1 kg당 열`을 각각 한 값으로 두는 현재 방식은 연구 기반 열수지를 충분히 표현하지 못한다.

### 문헌 참고범위

`General heat balance for oxygen steelmaking`은 330 t 복합취련 전로 35차지에서 총 열입력 대비 열손실을 1.3~5.9%로 역산했다. 논문의 적용 조건은 용선 Si 0.43~0.53%, C 4.4~4.5%, PCR 0.12와 특정 스크랩/용선비를 포함한다.

| 항목 | 문헌값 | 초기 정책 |
| --- | ---: | --- |
| 총 열입력 대비 열손실 | 1.3~5.9% | B등급 민감도 범위. 단일 기본값 금지 |
| 위 연구의 평균 근사 | 3.5% | 해당 조건 설명용. 범용 기본값 금지 |
| PCR | 0.10~0.14 관측, 0.12 계산 | 해당 35차지 사례값 |

열역학 물성은 NIST-JANAF처럼 온도 의존 Cp·엔탈피·상변화 자료를 제공하는 원 자료에서 가져와야 한다. 다만 용강·슬래그의 실제 조성별 열역학은 단순한 순물질 합보다 복잡하므로 최종적으로 현장 검증이 필요하다.

근거:

- [General heat balance for oxygen steelmaking](https://doi.org/10.1007/s42243-020-00491-0)
- [NIST-JANAF Thermochemical Tables](https://janaf.nist.gov/)
- [NIST Chemistry WebBook — CO](https://webbook.nist.gov/cgi/cbook.cgi?ID=C630080&Mask=1)

## 6. 샘플 이후 보정

NPTEL은 중간 온도·금속/슬래그 성분을 정적 계산에 넣는 방식을 반동적 모델로 설명한다. 종점 탄소 예측 리뷰에는 서브랜스 이후 탄소를 반응속도식으로 갱신하는 예가 제시된다.

```text
−dC/dt = k(C − Cs)
```

그러나 `k`는 반응속도, 랜스, 유량, 교반, 탄소 구간 등에 의존한다. 공개 문헌은 현재 구현의 `γC = 0.108 kg-C/Nm³-O₂`, `0.025 °C/Nm³-O₂`, `0.5 °C/min`을 범용값으로 뒷받침하지 않는다.

판정:

- 최신 채택 샘플을 정적값보다 우선하는 구조는 연구 근거가 있다.
- 샘플 이후 선형 보정계수는 C등급이며 현장 이력 또는 승인 계산표가 필요하다.
- 이력이 없을 때는 샘플값, 이후 실제 이벤트, 문헌 시나리오별 상·하한을 구분해 보여 주고 정확도 범위를 임의 생성하지 않는다.

## 8. 이력 전 초기 계산에 적용할 정책

### 바로 적용 가능

- Nm³ 기준조건과 산소 순도 입력 후 산소 질량을 계산한다.
- 화학량론 계수로 초기 C·Si·Mn·P와 목표/가정 종점량의 산소 요구량을 항별 계산한다.
- 광석·산화물 냉각재 중 반응 경로가 승인된 재료의 유효 산소 공급량을 별도로 계산한다.
- 각 계산 항과 출처, 가정값을 결과 옆에 표시한다.

### 문헌 시나리오로만 적용 가능

- PCR 0.10~0.22
- 총 열입력 대비 열손실 1.3~5.9%

두 범위는 해당 연구의 설비·장입 조건과 함께 저장하고, `문헌 저/기준/고 시나리오`로 표시한다. 중앙값을 현장 승인값처럼 표시하지 않는다.

### 현장값 없이는 활성화 금지

- 실제 철 산화량·슬래그 FeO·금속 손실
- 미사용 산소와 실제 PCR
- 용강 수율
- 샘플 이후 탈탄·온도 변화율
- 온도 시간손실 계수
- 예측 불확실성/신뢰구간

## 9. 초기 숫자 출력 형태

이력이 없더라도 아래 형태의 **물리 기반 참고범위**는 만들 수 있다.

```text
문헌·화학량론 참고 예상
중심 시나리오: 0.0xx %C / 1,6xx °C
가정 범위: PCR 0.10~0.22, 열손실 1.3~5.9%
미승인 입력: Fe 산화/슬래그 손실, 용강 수율
상태: 현장 미보정 · 출강 판정 사용 금지
```

단, 미승인 입력이 결과를 지배하면 숫자를 억지로 만들지 않고 `시나리오 입력 필요`로 표시한다. 이 단계의 숫자는 정확도 예측이 아니라 **가정 변화에 따른 민감도 계산**이다.

## 10. 구현 연결 권고

1. `oxygenEfficiency`와 고정 `otherOxygenKg`를 원소별 산소수지 모듈로 대체한다.
2. `carbonRemovalKgPerKgO`를 사용자 보정계수가 아닌 CO/CO₂ 화학량론 함수로 바꾼다.
3. `heatPerNm3OxygenKj` 방식 대신 원소별 반응열·재료별 엔탈피·열손실 비율을 분리한다.
4. DEMO 고정 불확실성을 신뢰범위처럼 표시하지 않는다.
