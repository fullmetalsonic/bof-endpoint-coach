# 종점 참고 예상 초기 계산 구조 조사

조사일: 2026-08-22  
상태: 공개 자료 기반 설계 조사. 실제 강종별 계수·목표·허용오차를 정한 문서가 아니다.

## 1. 결론

수동 입력형 초기 버전은 전로의 모든 반응을 실시간으로 푸는 동적 제어 모델이 아니라, 다음 세 겹의 **참고 계산 구조**로 잡는 것이 타당하다.

```text
정적 기준 계산(취련 전 입력)
  + 중간 샘플·실제 이벤트 보정(취련 중 수동 입력)
  + 검증된 이력 보정(충분한 현장 이력 이후)
```

공개 자료는 물질·열수지 기반의 정적 모델이 출발점이 될 수 있고, 취련 중 온도·성분 측정값이 들어오면 반동적 보정이 가능하다고 설명한다. 그러나 연속 동적 모델에는 배가스·연속 계측 등이 필요하므로 v0의 수동 입력 범위를 넘는다.

## 2. 취련사가 입력하거나 확인할 수 있는 변수

아래는 공개 자료에 반복적으로 나타나는 변수 중, 수동 입력 도구에서 현실적으로 기록 가능한 항목을 구분한 것이다. `필수`는 실제 계산을 위한 현장 승인 전 임시 분류이며, 화면의 모든 항목을 강제 입력하자는 뜻은 아니다.

| 구분 | 변수 | v0 입력 방식 | 역할 |
| --- | --- | --- | --- |
| 초기 조건 | 용선량·스크랩량, 용선 온도, 용선 C/Si/Mn/P 등 | 차지 시작 전 수동 입력 또는 보유 분석값 입력 | 정적 물질·열수지의 출발점 |
| 실제 조업 | 취련 시작·종료 시각, 실제 누적 산소량, 산소 유량 구간 | 시각 포함 수동 이벤트 | 산소 투입량·경과시간 반영 |
| 실제 조업 | 랜스 높이 구간, 저취 N2/Ar 교반가스 구간 | 설비/작업자가 확인 가능할 때만 선택 입력 | 반응 속도와 혼합 조건의 보조 설명값 |
| 부원료 | 석회·돌로마이트·광석·냉각재·합금철 등 실제 투입량·시각 | 재료 기준값과 연결한 수동 이벤트 | 물질·열수지 및 조업 보정 |
| 중간 확인 | 샘플 채취 시각, 채택 분석값, 온도 | 샘플/분석 이벤트 | 정적 예상의 반동적 보정 기준 |
| 결과 | 실제 종점/출강 분석·온도, 재취련 여부 | 완료 시 입력 | 이력 비교·그림자 정확도 검증 |

배가스 조성·온도, 슬래그 조성, 랜스 냉각수, 음향 계측 등은 연구용 동적 모델에 유용하지만, 회사 시스템 연동이 없는 v0의 필수 입력으로 넣지 않는다. 수동으로 안정되게 기록할 수 없으면 `선택/향후 연동`으로만 둔다.

## 3. 초기 계산 모듈 제안

### A. 정적 기준 계산 — 취련 전/초기

- **목적**: 초기 원료·성분·온도·계획 부원료·예정 산소량이 목표 강종 기준과 논리적으로 맞는지 확인한다.
- **근거 구조**: 금속 원소, 산소, 탄소, 플럭스의 물질수지와 열수지.
- **출력**: 입력 완결성, 단위/성분 기준 충돌, 물질·열수지 계산 가능 여부, 승인 계수 적용 여부.
- **주의**: 슬래그·배가스·수율·열손실 등 현장 계수가 승인되지 않으면 종점 수치를 만들어 내지 않고 `계산 불가: 승인 계수 없음`을 표시한다.

### B. 반동적 참고 보정 — 샘플 또는 실제 이벤트 후

- **목적**: 채택된 중간 성분·온도와 그 이후 실제 산소·부원료·시간 기록을 반영해, 정적 계산보다 최신인 참고 범위를 만든다.
- **입력 우선순위**: 채택 분석값 → 실제 발생 이벤트 → 계획 이벤트 → 이력 참고값.
- **출력**: 실제 분석값, 예상에 사용한 이후 이벤트 목록, `계획값 포함` 여부, 예상 불가 사유.
- **주의**: 샘플 이후 변화량을 수치로 계산하려면 산소 효율·반응 속도·재료 수율 같은 현장 보정 계수가 필요하다. 계수가 없을 때는 다음 검사 시점과 누락 입력만 보여 주고 수치 예측은 하지 않는다.

### C. 이력 보정 — 충분한 데이터와 승인 후

- **목적**: 같은 강종군·설비/조업 조건군의 완료 이력으로 정적/반동적 계산의 잔차를 보정한다.
- **방식**: 유사 차지 중앙값 같은 단순 기준선과 후보 규칙을 비교하고, 시간순 독립 검증과 그림자 예상 뒤에만 적용한다.
- **출력**: `참고 예상(규칙 버전)`과 범위, 사용 이력 기간·건수·누락/제외 사유.
- **주의**: 새 차지 이력이 들어왔다는 이유만으로 자동 재학습·자동 배포하지 않는다.

## 4. 초기 화면에서 계산해야 할 것과 보류할 것

| 구분 | 초기 버전에서 제공 | 현장 계수·이력 검증 뒤 제공 |
| --- | --- | --- |
| 안전한 계산 | 단위 환산, 투입 질량/성분 입력 검증, 산소·시간·투입 이벤트 누적, 필수 입력 완결성 | 종점 C·온도·P 등의 수치 예상 |
| 기준 비교 | 강종별 목표 범위와 채택 분석값 비교 | 예측 오차·적중률에 근거한 신뢰도 범위 |
| 시간 경과 | 실제/계획 이벤트와 경과시간 표시, 다음 샘플/확인 필요 알림 | 반응 속도 계수를 사용한 연속 종점 갱신 |
| 이력 | 유사 사례와 중앙값·분포 범위 | 승인된 이력 보정 모델 |

따라서 초기 버전의 가장 안전한 숫자 출력은 **실측 분석값·설정된 목표 범위·유사 완료 차지의 참고 범위**다. 종점 예상 수치는 B 또는 C 모듈의 현장 계수가 승인되고 그림자 검증을 통과한 항목부터 하나씩 추가한다.

## 5. 사용자 질문의 ‘초기 기준선’ 의미

`초기 기준선`은 목표값이 아니라, 새 계산식이 정말 도움이 되는지를 판단하기 위한 비교 상대다. 초기에는 다음 두 가지를 함께 둔다.

1. **유사 완료 차지 중앙값/분포**: 같은 비교군의 과거 실제 종점 결과.
2. **최신 채택 샘플값**: 현재 차지에서 마지막으로 확인된 실제 분석값.

후보 계산식이 이 두 기준보다 오차·편향·예상 불가율에서 낫지 않으면 수치 예측으로 승격하지 않는다. 목표 범위는 별도의 강종 기준값으로 유지하며, 기준선과 섞지 않는다.

## 6. 수집이 더 필요한 현장 정보

공개 자료로 제어변수 목록과 계산 구조는 정할 수 있지만, 아래 값은 회사별로 달라 공개 수치로 대체할 수 없다.

- 실제 전로 방식(상취/복합취련), 사용 가능한 조작 항목과 기록 방식
- 재료별 실제 조성·수분·수율 및 적용 기준 버전
- 산소 효율·열손실·슬래그/배가스 관련 보정 계수
- 강종별 목표·허용오차·샘플 단계·출강 판정 절차

이 값들은 설정 화면에 입력·버전 관리하도록 하고, 비어 있으면 해당 계산 모듈은 숫자를 출력하지 않는다.

## 7. 참고한 공개 자료

- NPTEL, [Process Control BOF Steelmaking — semi-dynamic/dynamic model](https://archive.nptel.ac.in/content/storage2/courses/113104059/lecture20/20_4.htm): 정적 모델에 중간 온도·성분 측정을 더한 반동적 제어와, 연속 배가스 계측을 쓰는 동적 제어를 구분한다.
- Metals, [Hybrid Method for Endpoint Prediction in a Basic Oxygen Furnace](https://www.mdpi.com/2075-4701/12/5/801): 금속·산소·탄소·플럭스 물질수지와 열수지로 종점 T/C/P를 추정하는 구조를 제시하며, 모델은 생산 조건별로 달라질 수 있음을 명시한다.
- Metallurgical and Materials Transactions B, [Using Machine Learning for Robust Target Prediction in a Basic Oxygen Furnace System](https://link.springer.com/article/10.1007/s11663-020-01853-5): 용선/스크랩/용선 분석·온도, 산소량, 부원료, 취련 시간, 랜스 위치 등의 입력과 현장 데이터 편향·일반화 한계를 설명한다.
- Processes, [Incorporation of Control Parameters into a Kinetic Model for Decarburization During BOF Steelmaking](https://www.mdpi.com/2227-9717/13/10/3048): 산소 유량·랜스 높이·용선량·플럭스 투입량을 반응 속도에 영향을 주는 제어변수로 다룬다.
