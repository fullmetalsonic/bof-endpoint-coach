# 전로 취련 기술 조사 — 초기 HTML 도구 설계용

조사일: 2026-08-22  
대상: 전로(BOF/BOS) 취련의 공개 기술 자료. 특정 제철소의 조업 표준, 실제 투입량, 랜스 패턴, 목표값은 포함하지 않는다.

전체 수집 목록은 [자료 카탈로그](catalog/자료카탈로그_2026-08-22.md)와 [국내·해외 색인](catalog/국내해외_색인.md)에 분리 보관한다.

## 결론 요약

1. BOF의 목표는 단순히 탄소를 낮추는 것이 아니라, 목표 성분·온도·출강량을 맞추면서 재취련과 철 손실을 줄이는 것이다.
2. 공정은 빠르고 비선형적이다. 따라서 v0에서 한 번의 입력으로 "정답 추출 시각"을 단정하면 안 된다.
3. 공개 문헌은 공정제어를 정적(static), 반동적(semi-dynamic), 동적(dynamic) 모델로 구분한다. 수동 입력뿐인 v0은 정적/반동적 보조에 머물러야 한다.
4. 슬래그의 염기도·산화성·용해 상태는 탈인과 정련에 중요하다. 그러나 유효 범위는 설비·강종·원료·현장 표준에 의존하므로 공개 수치를 그대로 권고값으로 쓰면 안 된다.
5. 입력 이력은 분석 수신 시각만이 아니라 **샘플 채취 시각, 투입 시각, 재취련 시각, 추출 시각**을 분리해야 한다.

## 1. 공정의 기본 흐름과 도구와의 연결

공개 자료는 전로를 내화물 라이닝 용기에 용선·스크랩·Flux를 장입하고 산소를 취입해 불순물을 산화·정련하는 공정으로 설명한다. 산소 산화 반응의 열은 스크랩 용해에도 관여하며, 석회·돌로마이트 등 Flux는 슬래그 형성·정련에 쓰인다.

도구 반영:

- `장입 → 취련/투입 → 샘플 채취 → 분석 수신 → 재취련 여부 → 추출`을 독립 이벤트로 기록한다.
- 계산 화면은 목표 C·온도뿐 아니라 사용자가 관리하는 P·Mn·S 등 목표와 현재 상태를 나란히 보여준다.
- 입력 가능한 정보가 없을 때 추정치로 채우지 않는다.

- [미국 EPA — Basic Oxygen Process 설명](https://nepis.epa.gov/Exe/ZyPURL.cgi?Dockey=910183FS.TXT)
- [POSCO 냉연강판 제조공정 자료](https://www.posco.co.kr/homepage/servlet/FileDownLoad?fileCategory=prdMda&fileNum=43)

## 2. 왜 수동 v0은 정적/반동적 보조여야 하는가

NPTEL의 BOF 공정제어 강의는 정적 모델을 입·출력의 물질수지와 열수지로 설명하며, 용선·스크랩·Flux·산소 요구량·슬래그량 등을 예측 대상으로 든다. 이어서 중간 온도·금속/슬래그 성분 측정으로 정적 예측을 보정하는 방식을 반동적 모델로 구분한다. 동적 모델에는 연속 배가스 조성·온도 같은 연속 측정이 요구된다.

도구 반영:

- v0 계산기는 `등록된 가정값 + 사용자가 직접 입력한 현재값`만 사용한다.
- 샘플 분석을 새로 입력하면 이전 계산을 덮어쓰지 말고, 새 시점의 계산/권고를 별도 이력으로 남긴다.
- 누적 산소량·경과 시간은 입력 가능할 때만 참고 신호로 쓴다.
- 배가스, 서브랜스, 랜스 높이·유량 같은 실시간 연속 데이터가 없으므로 동적 endpoint 예측을 표방하지 않는다.

근거:

- [NPTEL — Process Control BOF Steelmaking: 모델 목적과 구분](https://archive.nptel.ac.in/content/storage2/courses/113104059/lecture20/20_2.htm)
- [NPTEL — 반동적/동적 모델과 연속 측정](https://archive.nptel.ac.in/content/storage2/courses/113104059/lecture20/20_4.htm)
- [MDPI, 2022 — BOF endpoint hybrid model](https://www.mdpi.com/2075-4701/12/5/801)

## 3. 슬래그·탈인 관련 기록 항목

공개 교육자료는 슬래그가 불순물 흡수, 산화/환원 잠재력 제어, 재산화 방지, 열손실 완화 등에 관여한다고 설명한다. 탈인은 산화성·염기성 슬래그와 연관되며, 초기 단계의 온도 상승과 슬래그 형성 속도도 관계가 있다.

도구 반영:

- 슬래그 실분석을 자동으로 받을 수 없다면, v0은 `슬래그 분석 없음`을 정상 상태로 허용한다.
- 사용자가 확인 가능한 부원료 투입 이벤트, 초기 Si/P 정보, 샘플 분석 P, 재취련 여부를 우선 기록한다.
- 염기도·FeO의 보편 수치를 자동 투입 권고로 변환하지 않는다. 현장 승인값이 있을 때만 기준값으로 등록한다.

근거:

- [NPTEL — Slag in Steelmaking](https://archive.nptel.ac.in/content/storage2/courses/113104059/lecture4/4_3.htm)
- [NPTEL — 탈인 조건](https://archive.nptel.ac.in/content/storage2/courses/113104059/lecture8/8_5.htm)
- [NPTEL — 취련 중 조성·온도 변화와 슬래그 형성](https://archive.nptel.ac.in/content/storage2/courses/113104059/lecture12/12_3.htm)

## 4. 추출 포인트의 표시 원칙

종점(end-point) 탄소·온도 예측은 다양한 센서·모델을 활용해도 어려운 문제이며, 공개 리뷰도 데이터의 충분성·대표성·자기적응을 과제로 든다. 따라서 첫 버전은 특정 분 단위의 추출 명령을 만들지 않는다.

v0의 허용 표시 예:

- `분석 결과 대기: 마지막 채취 HH:MM / 수신 HH:MM`
- `목표 범위 비교 가능: 최신 분석값 기준`
- `재샘플 검토: 최신 분석의 채취 시각 이후 공정 이벤트가 있음`
- `추출 검토: 최신 입력값이 등록된 목표 범위 안에 있음`  
  단, 반드시 `현장 표준·설비 상태·작업자 판단 확인 필요`를 함께 표시한다.

v0의 금지 표시 예:

- `지금 즉시 추출`
- `산소를 N분 더 취입`
- `부원료 N kg을 반드시 투입`

근거:

- [endpoint carbon prediction review, 2020](https://doi.org/10.1515/htmp-2020-0098)
- [steeluniversity — Blow Theory 학습 목표](https://hub.steeluniversity.org/catalog/module/92)

## 5. 이력 데이터가 나중에 만드는 가치

공개 BOF 자료는 물질/열수지의 가정과 입력 데이터 정확도가 예측에 중요하다고 설명한다. 따라서 첫 버전의 가장 중요한 산출물은 복잡한 AI가 아니라, 같은 형식으로 축적된 차지 이력이다.

필수에 가까운 이력:

- 차지 식별자·강종군·진행 상태
- 목표 성분/온도 범위
- 투입 종류·중량·시각
- 샘플 ID, **채취 시각**, 분석 결과 **수신 시각**
- 분석 성분·온도와 실제 추출 시각
- 재취련/재샘플 여부와 이유
- 당시 사용한 기준값 버전과 계산 결과

분석 방법(정식 도입 전 후보):

- 강종군별 목표 대비 C·P·온도 편차 분포
- 최신 분석의 채취 시각부터 추출까지 경과 시간
- 재샘플/재취련 발생률과 입력 누락률
- 기준값 변경 전후의 결과 비교. 단, 원료·설비 조건 차이를 함께 확인한다.

근거:

- [NPTEL — 정적 모델의 물질·열수지 가정](https://archive.nptel.ac.in/content/storage2/courses/113104059/lecture20/20_3.htm)
- [steeluniversity — Converter process control 과정](https://steeluniversity.org/courses/man0302mp-basic-oxygen-steelmaking-converter-process-control/)

## 6. 안전·운영 경계

이 도구는 안전 결정을 계산하지 않는다. 공용 PC에서 쓰는 화면은 안전 인터록처럼 보이면 안 되고, 표준작업·작업허가·현장 책임자의 지시보다 우선할 수 없다. 용강 공정에서 물이나 오염물 유입은 심각한 위험을 만들 수 있으므로, 도구가 추천을 이유로 기존의 자재 확인·안전 절차를 생략하게 해서는 안 된다.

근거:

- [영국 HSE — 용융금속과 물 오염 폭발 위험](https://www.hse.gov.uk/moltenmetals/safety-topics.htm)

## 7. 향후 조사 우선순위

공개 자료만으로 해결할 수 없는 다음 항목은 현장 인터뷰·정식 데이터 접근이 필요하다.

1. 현장에서 실제로 쓰는 이벤트 명칭과 순서
2. 한 차지에서 취련사가 30초 안에 입력할 수 있는 최소 항목
3. 현재 분석값을 확인하는 화면·시점과 샘플 ID 규칙
4. 강종군별 목표값을 어느 수준까지 기밀 없이 그룹화할 수 있는지
5. 실적 판단에 사용할 지표와 기준 기간
6. CSV 저장 위치, 접근 권한, 보존 기간, 반출 가능 여부

## 자료의 한계

- 위 자료는 공정 원리와 모델의 분류를 확인하는 공개 자료다. 특정 현장의 최적 투입량·랜스 조건·목표 성분은 제공하지 않는다.
- 일부 교육·논문 자료의 사례 수치와 성능 수치는 특정 설비·데이터·운영 조건에만 해당한다. v0의 기본값으로 사용하지 않는다.
- 정식 기능 설계 전, 사내 표준작업과 안전·보안·품질 담당자의 검토가 필요하다.
