# 투입 코치 문헌 근거와 초기 계산 계약

상태: **v0.7.0~v0.7.2 구현 기준**  
기준일: 2026-08-24  
적용 범위: Flux, 냉각재·광석, 합금철·가탄재, 조건부 산소, 투입 잔차학습

## 1. 결론

초기 투입 코치는 보편적인 단일 투입량 표를 복사하지 않는다. 공개 문헌에서 확인 가능한 것은 `물질수지 구조`, `열수지 구조`, `영향인자`, `회수율을 포함한 합금 계산식`, `시간지연과 현장 보정 필요성`이다. 따라서 다음 세 층을 분리한다.

1. 화학량론·질량보존으로 계산할 수 있는 항
2. 공개 문헌 범위를 이용한 DEMO 시나리오 항
3. 사업소가 직접 입력하고 승인해야 하는 현장 한도·효율·회수율 항

DEMO·합성자료는 기능 검증에는 사용하지만 현장 승인값과 학습 후보로 승격하지 않는다.

## 3. v0.7.0 계산 계약

### 3.1 Flux 참고량

염기도를 `R = CaO / SiO₂` 질량비로 정의한다. 현재 예상 슬래그의 CaO와 SiO₂가 각각 `C₀`, `S₀`, 선택한 Flux의 CaO·SiO₂ 질량분율이 `c`, `s`, 목표 염기도가 `Rₜ`라면 추가량 `x`는 다음 물질수지로 계산한다.

```text
(C₀ + c·x) / (S₀ + s·x) = Rₜ
x = (Rₜ·S₀ - C₀) / (c - Rₜ·s)
```

- 분모가 0 이하이거나 필요한 양이 0 이하이면 숫자 권고를 만들지 않는다.
- 저·기준·고 슬래그 시나리오와 목표 염기도 최소·최대를 조합해 투입량 범위를 만든다.
- 현장 최소·최대 한도가 있으면 그 안으로만 제한한다. 한도와 계산범위가 겹치지 않으면 `목표 충돌`로 표시한다.
- DEMO 기본 염기도 범위는 화면·계산 흐름 시험용이며 실제 강종에는 사용자가 설정한 범위가 필요하다.

### 3.2 조건부 산소

산소 참고량은 기존 종점 모델의 `계획 총산소 - 실제 누적산소`를 그대로 실제 명령으로 바꾸지 않는다. 다음 조건을 모두 만족할 때만 잔여 산소 시나리오를 표시한다.

- 최신 채택 샘플에 C와 누적 산소가 있음
- 산소 유량이 0보다 큼
- 계획 총산소와 현장 승인 최소·최대 추가산소가 있음
- 현재 단계가 승인 단계 안에 있음

산소는 Flux·냉각재의 대체재가 아니며 종점 C·온도 충돌을 함께 표시한다.

## 4. v0.7.1 계산 계약

### 4.1 냉각재·광석

재료 조성에 포함된 산화물의 산소 질량은 다음 화학량론으로 계산한다.

```text
FeO 내 O 질량 = FeO 질량 × 15.9994 / 71.8444
Fe₂O₃ 내 O 질량 = Fe₂O₃ 질량 × 47.9982 / 159.688
산소 당량 Nm³ = 유효 O 질량 / 설정 기준 산소밀도
```

모든 산화물 산소가 욕 반응에 쓰인다고 가정하지 않는다. 초기판은 계산된 산소 질량을 `이론상 상한`으로만 표시하며 실제 산소 대체량이나 산소 credit으로 사용하지 않는다. 현장 검증된 산소이용률이 생기기 전까지 광석 투입량과 추가 산소량을 서로 자동 상쇄하지 않는다.

온도 보정 참고량은 예상 과열량과 용강 유효열용량으로 필요한 제거열을 구한 뒤 재료별 유효냉각열로 나눈다.

```text
필요 제거열 kJ = 예상 용강량 kg × 0.823 kJ/(kg·°C) × 과열 °C
냉각재 참고량 kg = 필요 제거열 / 유효냉각열 kJ/kg
```

`0.823`은 현재 열수지의 Fe 현열 기울기와 맞춘 계산상 값이다. 재료별 유효냉각열은 조성·수분·입도·용해·환원상태에 따라 달라지므로 설정값과 출처를 반드시 표시한다.

### 4.2 합금철·가탄재

S50의 질량수지식을 사용한다. 목표 성분 증가량이 `ΔX` wt%, 예상 용강량이 `M`, 합금의 X 함량이 `wX` wt%, 회수율이 `ηX`라면 다음과 같다.

```text
필요 합금량 kg = M × ΔX / (wX × ηX)
동반성분 증가 wt% = 합금량 × 동반성분 wt% × 해당 회수율 / M
```

- 회수율이 없으면 100%로 숨겨 계산하지 않고 `계산 보류` 또는 DEMO 시험값으로 표시한다.
- 같은 재료의 C·Si·Mn·P·S 동반성분이 목표 최대를 넘길 가능성을 함께 확인한다.
- 합금 투입은 즉시 균질화된 것으로 단정하지 않고 재료별 혼합·용해 대기시간을 시간범위에 반영한다.

## 5. v0.7.2 학습·승격 계약

### 5.1 저장 단위

각 행은 다음 키로 분리한다.

```text
강종 | 설비 | 재료 | 목적 | 투입모델버전 | 계수버전 | FIELD/DEMO
```

원본 계획, 그림자 제안, 실제 투입, 전후 샘플, 확정 종점, 정정·무효 상태를 연결한다. 원본을 덮어쓰지 않고 소스 정정 뒤 기존 학습실행을 `stale`로 유지한다.

### 5.2 후보 생성 관문

- 10건 미만: 원장만 표시
- 10~29건: 편향 방향만 표시
- 30~49건: 임시 후보를 계산하되 승인 불가
- 50~69건: 독립 검증자료 대기
- 70건 이상: 앞 50건 학습, 최근 20건 시간순 검증

건수 외에 다음을 모두 확인한다.

- 실제 FIELD 자료이며 현재 계수버전과 일치
- 정정·무효·결측·여러 조작이 겹친 오염 행 제외
- 실제량/코치 중앙값 비율이 낮음(<0.9)·중간(0.9~1.1)·높음(>1.1)의 3개 구간에 분포
- 서로 다른 조업일 10일 이상, 기록 작업자 3명 이상
- 시각을 학습할 때 승인 시간구간의 적어도 3개 구간에 분포
- 최근 20건에서 MAE가 감소하고 절대 편향이 증가하지 않음
- 후보가 현장 승인 최소·최대 범위 안에 있음

후보는 설정 초안으로만 이동하고 변경 사유와 작업자 승인을 거쳐 새 계수버전이 된다. 자동 적용·강화학습·현장 한도 밖 탐색은 하지 않는다.

## 6. 모델 상태 문구

| --- | --- |

| `문헌 시험` | 공개 문헌 구조와 DEMO 계수로 계산, 현장 정확도 N/A |

## 7. 구현하지 않는 주장

- 이 범위는 설비 제어시스템이 아니다.
- 문헌 시나리오 범위를 통계적 신뢰구간으로 부르지 않는다.
- 실제 차지가 없는데 정확도가 향상됐다고 표시하지 않는다.
- Flux 결과로 실제 탈인 성능을 검증하려면 종점 성분뿐 아니라 가능하면 슬래그 분석·투입품질이 필요하다.
- 냉각재의 유효냉각열과 산소이용률, 합금 회수율은 사업소·재료·시점 의존값이므로 자동 현장값으로 승격하지 않는다.
