# 취련 코치 v0 시각 규칙 초안

상태: 시안 검토 중. HTML 구현 기준으로 확정된 것은 아니다.

## 선택한 방향

- 첨부된 Data Ledger 계열처럼 **한 화면에서 차지 흐름·목표 비교·최근 분석·입력 확인·적용 기준을 모두 읽는 전문 업무 화면**을 유지한다.
- 지나친 미니멀화로 최근 분석 표·우측 근거 패널·상단 차지 요약을 제거하지 않는다.
- 단, 이모티콘·장식 아이콘·그림문자·아이콘만 있는 버튼은 쓰지 않는다. 이벤트 버튼은 텍스트로만 표시한다.

## 오프라인 수동 입력 경계

- 화면의 값은 취련사 또는 분석 결과에서 수동으로 입력한 값이다.
- `실시간`, `데이터 수신`, `PLC/HMI`, `AI`, `모델`, `자동 추천`, `설비 상태` 표현을 사용하지 않는다.
- 시점은 `샘플 채취 시각`, `분석 결과 입력 시각`, `마지막 저장 시각`으로 표시한다.
- 예상값은 승인된 기준과 수동 입력이 충분할 때만 `참고 예상(입력값 기준)`으로 표시한다.

## 색상 체계

| 용도 | 권장 색 | 의미 |
| --- | --- | --- |
| 기본 배경 | `#F7F8FA` 또는 흰색 | 장시간 업무 화면의 안정된 바탕 |
| 본문 | `#1F2933` | 높은 가독성 |
| 구분선/표 | `#D7DCE3` | 카드 남용 대신 표 구조를 만드는 선 |
| 기본 동작/선택 | `#1554B8` | 현재 게이트, 주요 텍스트 버튼 |
| 목표 범위 내 | `#1F7A4D` | 승인된 목표 범위와 범위 내 상태 |
| 확인 필요 | `#B7791F` | 입력 누락·시점 확인·상한/하한 접근 |
| 목표 이탈 | `#C53B3C` | 실제 분석값의 목표 이탈만 표시 |

색은 상태 보조 수단이며, 텍스트·수치·기준선과 항상 함께 쓴다.

## 글꼴·숫자 규칙

- 기본 글꼴: `Pretendard`, 없으면 `Noto Sans KR`, 마지막으로 시스템 산세리프.
- 본문: 15~16px / 행간 1.45 이상.
- 표 헤더·보조 정보: 12~13px.
- 화면 제목: 22~26px, 섹션 제목: 18~20px.
- 숫자·시간·차지 ID는 tabular figures를 사용해 표에서 세로가 흔들리지 않게 한다.
- 굵기는 400/500/600 위주로 제한하고, 큰 검은색 굵은 글자 남용을 피한다.

## 표·레이아웃 규칙

- 상단: 차지 ID, 강종군, 현재 게이트, 경과 시간, 수동 입력 기준의 다음 확인 항목을 한 줄 요약.
- 좌측: G0~G8 텍스트 단계 목록. 현재 단계만 파란 배경/선으로 강조.
- 중앙: 출강 검토 요약 → 품질 범위 막대 표 → 최근 샘플/분석 표 순서.
- 우측: `입력 시점`, `확인 필요`, `적용 기준`의 세 패널.
- 하단: 텍스트만 있는 여섯 개 이벤트 버튼. 아이콘을 붙이지 않는다.
- 모서리 반경은 4~6px, 그림자는 쓰지 않거나 최소화한다. 카드 안의 카드 구조는 피한다.

## 품질 범위 막대 규칙

- 현재 실제 분석값은 채워진 원, 참고 예상값은 빈 원으로 표시한다.
- 목표 최소/최대 기준선과 목표 범위의 색을 같이 표시한다.
- 실제값이 목표 범위를 벗어나면 막대 끝을 자르지 말고 바깥 방향과 수치를 보인다.
- 기본 품질 후보는 C·온도·P·S·Mn·Si 여섯 개다. 실제 화면에는 강종군에서 활성화된 항목만 보인다.
- 강종 특화 항목은 표 아래의 `성분 상세`에서 펼치며, 목표·한계가 승인된 항목만 범위 막대를 쓴다.

## 금지 사항

- 네온·그라데이션·유리 질감·과한 그림자
- 관제실 흉내를 내는 가짜 실시간 그래프와 스트리밍 표시
- 의미 없는 KPI 카드·게이지·점수
- 자동 제어 또는 작업 지시로 오해될 수 있는 문구
