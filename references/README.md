# 외부 자료 보관 정책

이 폴더는 외부 기술 자료의 **목록과 허용된 공개 파일**을 관리하기 위한 자리다.

- 전체 목록과 각 자료의 링크·활용도는 `../docs/research/catalog/자료카탈로그_2026-08-22.md` 및 CSV에 있다.
- 유료, 로그인 필요, 저작권·재배포 조건이 불분명한 자료는 원문을 내려받지 않는다. 서지와 원문 링크만 기록한다.
- `open-downloads/`에는 재배포·로컬 보관이 명시적으로 허용된 공개 자료만 넣는다. 현재는 비어 있다.
- 외부 자료는 설계 검토용이며 회사의 표준작업·품질기준·안전기준을 대체하지 않는다.
